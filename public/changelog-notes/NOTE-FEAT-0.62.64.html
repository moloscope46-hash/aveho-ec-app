🐛 Fix bug (1)

Fix accent titre noir sur noir

🎨 dans le PageHead premium (PageHero) : l'accent (genre 'préventive' sur 'Maintenance') était rendu avec color: mainColor (#185FA5 bleu sombre par défaut) → invisible sur fond .bg-dark. Solution : accent passe en couleur amber AVEHO #EF9F27 avec textShadow 0 1px 2px rgba(0,0,0,.3) pour le relief. Universellement lisible sur fond sombre. Appliqué partout via sed dans app/ui.js (2 occurrences PageHead premium + legacy)
