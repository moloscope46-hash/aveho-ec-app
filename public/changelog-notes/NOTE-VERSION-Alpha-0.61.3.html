🚛 1. Module Flotte véhicules

Page /magasin/flotte — CRUD complet des véhicules :

  • Cards par véhicule : icône type (utilitaire/camion/voiture/scooter/vélo), immatriculation, marque/modèle, chauffeur, capacité kg/m³, kilométrage, carburant
  • Statuts : disponible, en tournée, maintenance, hors service
  • Échéances : prochain entretien, CT, assurance avec alertes 30 jours en bandeau
  • 4 stat tiles : Total / Disponibles / En tournée / Maintenance
  • Modal édition ultra-complet : marque, modèle, type, carburant, capacités, échéances, assurance, chauffeur, notes

🗺 2. Module Tournées de livraison

📋

Liste tournées

Cards avec progression % + statut + véhicule/chauffeur. Filtres date + statut. 4 stat tiles.

➕

Création tournée

Workflow 3 étapes : infos + véhicule/chauffeur + sélection DI à livrer (DI validées de v_di_a_livrer).

🗺

Carte Leaflet

Markers numérotés ordonnés + polyline entre étapes + popups. CartoDB tiles. Auto-fit bounds.

Détail tournée /magasin/tournees/[id] :

  • Header avec progression %, statut, dates
  • Carte Leaflet 400px avec tous les points (étabs + dépôts)
  • Boutons workflow : Démarrer / Terminer / Annuler la tournée
  • Étapes ordonnées avec boutons "Démarrer" / "Terminer" individuels
  • Lien direct vers la DI source de chaque étape

🔄 Workflow logistique complet

#ÉtapeActeur
1Crée des véhicules dans /magasin/flotteMagasin admin
2Crée user magasin avec rôle "Utilisateur Magasin" pour chauffeurEC admin
3EC émet DI/transferts/SAV → magasin valideEC + Magasin
4Va sur /magasin/tournees/nouvelle → coche les DI à livrerChauffeur/magasin
5Tournée créée avec étapes ordonnées + carteAuto
6Jour J : "Démarrer tournée" → suit la carte étape par étapeChauffeur
7À chaque étape : "Démarrer" (arrivée) → "Terminer" (départ)Chauffeur
8"Terminer la tournée" → statistiques mises à jourChauffeur
