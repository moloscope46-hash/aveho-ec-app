Étape 3 : envelopper la barre de filtres existante dans <FoldableFilters searchValue={search} onSearchChange={setSearch} searchPlaceholder=... activeFiltersCount={N} onResetAll={...} storageKey=patients>{...filtres existants...}</FoldableFilters>. Comment utiliser AddressAutocomplete dans une modal de création

💡 étape 1 : import AddressAutocomplete from "../../components/AddressAutocomplete". Étape 2 : remplacer l input adresse classique par <AddressAutocomplete value={form.adresse} onChange={(label, full) => setForm({...form, adresse: label, cp: full?.cp || form.cp, ville: full?.ville || form.ville, code_insee: full?.insee, latitude: full?.lat, longitude: full?.lng})} placeholder=Adresse postale />. Quand l user sélectionne une suggestion : adresse+cp+ville+insee+lat+lng tous remplis automatiquement

Comment utiliser useEditLock dans une modal d édition

💡 étape 1 : import { useEditLock } from "../../lib/useEditLock". Étape 2 : en haut du composant modal const { locked, lockedBy, takeover } = useEditLock("patient", patient?.id, !!patient). Étape 3 : si locked, afficher banner : if (locked) return <div className="av-edit-lock-banner"><i className="ti ti-lock lock-icon" /><div className="lock-text"><div className="lock-title">Édition en cours par {lockedBy.nom}</div><div className="lock-detail">Vous pouvez attendre ou reprendre la main</div></div><button onClick={takeover}>Reprendre</button></div>. Le lock est release automatiquement au unmount
