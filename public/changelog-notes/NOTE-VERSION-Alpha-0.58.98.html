🔌 Côté technique

Quand "★ Tous" est sélectionné, l'event av-current-context-change est dispatché avec batimentId: null (pas ""). Les pages qui filtrent par batiment_id doivent vérifier if (batimentId) avant d'appliquer WHERE batiment_id = ...

// Pattern dans BatimentServiceSwitcher
function changeBat(id) {
  setBatId(id);
  localStorage.setItem(STORAGE_BAT, id);   // peut être ""
  setSvcId("");                            // reset service en cascade
  window.dispatchEvent(new CustomEvent("av-current-context-change", {
    detail: { batimentId: id || null, serviceId: null, equipeId: null }
  }));
}
