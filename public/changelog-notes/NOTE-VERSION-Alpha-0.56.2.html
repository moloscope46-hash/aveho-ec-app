🎯 Le concept

Avant : page /scan/qr était un placeholder vide ("à venir"). Maintenant : scanner fonctionnel qui ouvre la caméra arrière du téléphone, décode QR codes et codes-barres, et identifie automatiquement le type de contenu pour proposer la bonne action.

Couvre 4 cas d'usage Aveho : carte Vitale (NIR), matériel médical (GS1/UDI), liens internes Aveho (étiquettes patient/matériel), codes EAN (produits consommables).

📷 Composant QrScanner.js

Techniquement

  • Dynamic import de html5-qrcode dans useEffect — la lib (~150 Ko) n'est chargée qu'à la demande, pas au démarrage de l'app
  • Caméra arrière prioritaire sur mobile : regex /back|arrière|rear|environment/i sur le label
  • Sélecteur de caméra si plusieurs disponibles
  • qrbox responsive : 70% du min(viewport width, height) — s'adapte mobile / desktop
  • Fallback scan depuis fichier : upload d'une image (PNG, JPG) si la caméra n'est pas accessible
  • Cleanup : stop + clear automatiques au unmount
  • autoStop par défaut : arrête après le 1er scan

Props : { onResult, onError, active, autoStop } — réutilisable dans d'autres pages plus tard (ex : scan code-barre sur fiche matériel).

⚡ Actions contextuelles

Chaque type déclenche des actions différentes :

Vitale (NIR détecté)

  • Bouton "Chercher ce patient" → /patients?q=NIR
  • Bouton "Nouveau patient avec ce NIR" → /patients?new=1&nir=...
  • ⚠️ Avertissement "Le NIR seul ne suffit pas à identifier formellement le patient"

GS1/UDI (matériel)

  • Tableau des Application Identifiers avec libellés (GTIN, Lot, Péremption…)
  • Bouton "Chercher dans le matériel" → /materiels?gtin=...

EAN

  • Bouton "Chercher matériel par EAN" → /materiels?ean=...

URL Aveho interne

  • Redirection automatique vers le path interne (800ms de délai)
  • Utile pour les étiquettes physiques sur matériel/dossiers patients

⚠️ Limites connues

  • HTTPS obligatoire pour accéder à la caméra (navigator.mediaDevices). En local http://localhost marche aussi, mais pas en HTTP sur LAN.
  • Permission caméra : si l'user la refuse au navigateur, le fallback fichier reste utilisable.
  • Vrai format Vitale (DGE-MSS, TLV cryptographique) non décodé — on détecte juste la présence d'un NIR dans le contenu. Pour décoder une vraie carte Vitale il faudrait un lecteur PC/SC physique.
  • Historique en state React seul — perdu au rafraîchissement (peut être étendu en localStorage si demandé).
