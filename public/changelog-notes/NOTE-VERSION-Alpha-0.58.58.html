🎯 Drag&drop des champs du formulaire Crud

Le composant Crud (utilisé dans 20+ pages : tags matériel, étiquettes patient, articles catalogue, dépôts, zones, magasins, etc.) supporte maintenant le réordonnancement des champs du formulaire d'édition par drag&drop. Le nouvel ordre est persisté par table dans localStorage (clé av-crud-fields-${"{table}"}).

⚙️ Logique technique

// 0.58.58 - app/crud.js
const fieldsStorageKey = `av-crud-fields-${table}`;
const [fieldOrder, setFieldOrder] = useState(null);
const [fieldsEditMode, setFieldsEditMode] = useState(false);
const [draggedFieldKey, setDraggedFieldKey] = useState(null);

// Réconciliation au mount
useEffect(() => {
  const stored = JSON.parse(localStorage.getItem(fieldsStorageKey) || '[]');
  const currentKeys = fields.map(f => f.key);
  const validStored = stored.filter(k => currentKeys.includes(k));
  const missing = currentKeys.filter(k => !validStored.includes(k));
  setFieldOrder([...validStored, ...missing]);
}, [fieldsStorageKey, fields?.length]);

// orderedFields = applique le fieldOrder
const orderedFields = fieldOrder
  ? fieldOrder.map(k => fields.find(f => f.key === k)).filter(Boolean)
  : fields;

// Handler drop : splice from/to
function handleFieldDrop(e, targetKey) {
  setFieldOrder(prev => {
    const arr = [...prev];
    const fromIdx = arr.indexOf(draggedFieldKey);
    const toIdx = arr.indexOf(targetKey);
    arr.splice(fromIdx, 1);
    arr.splice(toIdx, 0, draggedFieldKey);
    return arr;
  });
}

// Rendu : draggable activé seulement en mode édition
{orderedFields.map((f) => (
  <div className='fld'
       draggable={fieldsEditMode}
       onDragStart={fieldsEditMode ? (e) => handleFieldDragStart(e, f.key) : undefined}
       onDrop={fieldsEditMode ? (e) => handleFieldDrop(e, f.key) : undefined}
       style={{
         opacity: draggedFieldKey === f.key ? 0.4 : 1,
         borderTop: dragOverFieldKey === f.key ? '2px solid #7CC8C8' : '2px solid transparent',
         transform: dragOverFieldKey === f.key ? 'translateY(-2px)' : 'none',
       }}>
    {fieldsEditMode && <span style={{ cursor: 'grab' }}>⋮⋮</span>}
    <label>{f.label}</label>
    <input disabled={fieldsEditMode} ... />
  </div>
))}

🎨 Détails UX irréprochables

  • Mode édition explicite via bouton 'Réorganiser' (icône ti-arrows-up-down) → 'Terminer' (icône ti-check) — pas de drag accidentel
  • Bandeau d'instruction en mode édition expliquant la mécanique (teal + dashed + icône info)
  • Inputs disabled pendant le drag (évite saisie accidentelle pendant qu'on bouge un champ)
  • Bouton 'Enregistrer' disabled + label changé en 'Termine d'abord le réordonnancement' (évite confusion)
  • Bouton 'Réinit.' visible uniquement si l'ordre a été modifié (icône ti-restore rouge)
  • Reset automatique du mode édition au close du modal ou après save (pas de fuite d'état)
  • Réconciliation auto : si on ajoute un nouveau champ dans le code, il s'ajoute à la fin ; si on en retire un, il disparaît
