useRealtimeNotifs : check SLA escalade

⏰ nouvelle fonction checkSLA séparée du check normal. Logique

  1. Fetch interventions non résolues
  2. Pour chaque, calcule ageHours = now - created_at
  3. Compare à SLA_HEURES[urgence] (Critique=4h, Élevée=24h, Normale=72h, Faible=168h)
  4. Si ageHours > slaHours ET pas déjà alerté (Set en mémoire) ET (technicien assigné=moi OU admin sur non-assigné) → notify type warning ou urgent selon taux dépassement
  5. Log dans notifs_log type=sla_depasse. Fréquence : 30s initial puis toutes les 5 min (séparé du check 60s)
