Utilisation du mode hors-ligne

🚀 exemple typique chauffeur

  1. Le matin avant de partir, ouvre la tournée du jour → données mises en cache IndexedDB automatiquement
  2. Dans le tunnel ou zone blanche, l'indicateur passe en orange 'Hors ligne'
  3. Le chauffeur peut continuer à valider les étapes : signature, scan, photos → tout est queued localement
  4. Au retour en zone connectée, l'indicateur passe en bleu 'Synchronisation...' puis vert 'X actions envoyées'. Zéro perte de données, expérience seamless. API exposée : cacheTournee(data), getCachedTournee(id), queueOperation(table, action, data), smartWrite(supabase, table, action, data), syncPendingOperations(supabase)
