📝 Comment utiliser les nouveaux composants

1. KpiCard

import { KpiCard } from "../components/ui-premium";

<KpiCard
  label="DI à traiter"
  value={42}
  previous={38}        // → calcul trend +11% automatique
  icon="ti-tools"
  variant="terra"      // teal | blue | terra | amber | navy | violet | success
  sparkline={[12,15,8,22,30,28,35,42]}
  onClick={() => router.push('/interventions')}
/>

2. Toast (notifications)

import { toast } from "../components/ui-premium";

// Helpers shortcuts
toast.success("Sauvegardé !", "Vos modifications sont enregistrées.");
toast.error("Erreur réseau", "Impossible de se connecter au serveur.");
toast.warning("Attention", "Action irréversible.");
toast.info("Mise à jour disponible");

// Avec action callback
toast.info("Nouveau message", "De Cédric Mignot", {
  actionLabel: "Voir",
  onAction: () => router.push("/messages")
});

3. EmptyState

import { EmptyState } from "../components/ui-premium";

<EmptyState
  icon="ti-tools"
  variant="teal"
  title="Aucune intervention"
  message="Tu n'as pas encore d'intervention en cours."
  actionLabel="Créer une intervention"
  onAction={() => router.push("/interventions/new")}
  secondaryLabel="Voir l'aide"
  onSecondary={() => openHelp()}
/>

4. Skeleton (loaders)

import { Skeleton, SkeletonGrid } from "../components/ui-premium";

// Pendant un loading
{loading ? <SkeletonGrid count={4} cols={4} /> : <KpiCardGrid kpis={data} />}

// Ligne de texte
<Skeleton w="60%" h={14} />

// Avatar
<Skeleton variant="circle" size={40} />
