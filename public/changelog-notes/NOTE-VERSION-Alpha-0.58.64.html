🚨 3. FIX 404 pharmacies en prod (table absente)

Symptôme : console Vercel polluée par GET /pharmacies?... 404 (Not Found) + relation "pharmacies" does not exist.

Cause : le SQL migration-0.58.57-pharmacies-depots-batiment.sql n'a pas encore été exécuté en prod.

Fix appliqué :

  • Détection de l'erreur 42P01 / PGRST205 / 'does not exist'
  • setShowPharmacies(false) + flag localStorage av-pharmacies-table-missing = "1"
  • Le toggle Pharmacies dans /carte est caché tant que le flag est présent
  • Flag retiré automatiquement dès que la requête réussit (après l'exécution du SQL)

Plus aucun spam d'erreurs console + UX propre en attendant l'application du SQL.

// app/carte/page.js (0.58.64)
if (error) {
  // 0.58.64 : table absente → masque le toggle proprement (pas d'erreur console)
  if (error.code === "PGRST205" || error.code === "42P01" || /not found|does not exist/i.test(error.message || "")) {
    setShowPharmacies(false);
    try { localStorage.setItem("av-pharmacies-table-missing", "1"); } catch {}
  }
  setPharmacies([]);
} else {
  setPharmacies(data || []);
  try { localStorage.removeItem("av-pharmacies-table-missing"); } catch {}
}

// Toggle conditionnel
{(typeof window === "undefined" || localStorage.getItem("av-pharmacies-table-missing") !== "1") && (
  <Panel>...Toggle Pharmacies...</Panel>
)}
