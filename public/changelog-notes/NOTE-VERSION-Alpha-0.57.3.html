📦 Fix 2 — Nouveau module lib/exportData.js (CSV natif sécurisé)

~370 lignes de génération CSV native sans dépendance externe. Caractéristiques :

1. Protection contre l'injection CSV

Excel évalue les caractères =, +, -, @ en début de cellule comme des formules. Un nom de patient comme =cmd|'/c calc.exe'!A1 pourrait exécuter un payload à l'ouverture du fichier CSV. Préfixage automatique avec une apostrophe :

function csvEscape(value) {
  if (value == null) return "";
  let s = String(value);
  // Protection contre l'injection CSV (=, +, -, @ au début)
  if (/^[=+\-@\t\r]/.test(s)) {
    s = "'" + s;
  }
  if (/[",;\r\n]/.test(s)) {
    s = '"' + s.replace(/"/g, '""') + '"';
  }
  return s;
}

2. RFC 4180 conforme

  • Entourage automatique par guillemets si la valeur contient ,, ;, ", ou retour à la ligne
  • Double-guillemets internes (échappement)
  • Séparateur de ligne \r\n (CRLF)

3. BOM UTF-8 pour Excel français

function downloadText(content, filename, mimeType = "text/csv;charset=utf-8") {
  // BOM UTF-8 pour qu'Excel français reconnaisse l'encodage
  // (sinon accents cassés : "élève" devient "élève")
  const BOM = "\uFEFF";
  const blob = new Blob([BOM + content], { type: mimeType });
  // ... download via blob URL
}

4. Séparateur ; par défaut

Compatible Excel français qui utilise ; comme séparateur (la virgule étant utilisée pour les décimales). Configurable via options.csvSeparator.

5. Multi-fichiers pour exportBilan

Là où xlsx faisait 1 fichier avec 6 feuilles, le CSV génère 6 fichiers .csv + 1 INDEX.csv avec méta. L'utilisateur peut les ouvrir en parallèle dans Excel.

🐛 Fix 4 — Warning build "workspace root"

Le build affichait à chaque fois :

⚠ Warning: Next.js inferred your workspace root, but it may not be correct.
   We detected multiple lockfiles and selected the directory of
   /home/claude/package-lock.json as the root directory.

Cause : présence de lockfiles à plusieurs niveaux (ancien lockfile dans /home/claude/ + nouveau dans /home/claude/aveho-ec-app/).

Fix dans next.config.js :

const path = require("path");

module.exports = {
  reactStrictMode: true,
  // 0.57.3 : silence le warning workspace root
  outputFileTracingRoot: path.join(__dirname),
};

Build : 0 warning maintenant.
