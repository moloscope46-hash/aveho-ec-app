🔀 PageTransition entre routes

Nouveau composant client qui détecte le changement de pathname via usePathname() de next/navigation et déclenche une animation fade + slide-up 280ms sur chaque transition de route. Intégré globalement dans app/layout.js.

// app/components/PageTransition.js
import { usePathname } from 'next/navigation';

export default function PageTransition({ children }) {
  const pathname = usePathname();
  return (
    <div
      key={pathname}
      style={{
        animation: 'av-page-enter 280ms cubic-bezier(.2, .8, .2, 1)',
      }}
    >
      {children}
    </div>
  );
}

// app/globals.css
@keyframes av-page-enter {
  from { opacity: 0; transform: translateY(8px); }
  to   { opacity: 1; transform: translateY(0);    }
}

✅ Zéro dépendance ajoutée (pas de framer-motion). CSS pur + state React.
