3. Page Statistiques NOUVEAU

Nouvelle page /statistiques dans le menu Espace Collectivité. Cinq visualisations agrégées sur les 6 derniers mois :

  • Interventions par mois — graphe en barres (rouge)
  • Transferts par mois — graphe en barres (bleu)
  • Répartition des statuts DI — donut (Nouvelle / En cours / Résolue / Annulée)
  • Top 5 matériels en DI — barres horizontales avec %
  • Stock par dépôt — graphe en barres (vert)

Choix technique : SVG natif, pas de lib externe

J'ai écrit les composants BarChart et DonutChart à la main en SVG, sans embarquer recharts (~300 Ko), chart.js (~250 Ko) ou d3 (~270 Ko). Le bundle reste léger et les graphes sont 100% personnalisables avec les couleurs Aveho. Si tu as besoin de visualisations plus complexes plus tard (heatmaps, scatter plots, etc.), on pourra évaluer l'ajout d'une lib à ce moment-là.

4. Import CSV NOUVEAU

Sur toutes les listes utilisant le composant Crud (articles, matériels, dépôts, stock, établissements), un nouveau bouton Import CSV apparaît à côté du bouton Nouveau. Le workflow :

  1. Choisir un fichier .csv (séparateur ; ou , auto-détecté)
  2. Une modale s'ouvre avec un mapping visuel : chaque champ Aveho à gauche, le sélecteur de colonne CSV à droite, et un exemple de la première ligne
  3. Auto-mapping initial : les colonnes dont le nom correspond exactement au libellé Aveho sont pré-sélectionnées
  4. Bouton "Importer N lignes" — insertion par batches de 100 dans Supabase
  5. Message de succès, rechargement de la liste

Parser CSV robuste

Le helper lib/importCsv.js gère :

  • BOM UTF-8 (les fichiers générés par Excel)
  • Auto-détection du séparateur (; vs ,)
  • Guillemets autour des valeurs avec ; ou retours à la ligne
  • Échappement "" à l'intérieur des guillemets

5. Mode foncé NOUVEAU

5.1 Toggle dans Paramètres → Apparence

Nouvelle section Apparence sur la page Paramètres avec deux gros boutons :

  • 🌞 Mode clair — par défaut
  • 🌙 Mode foncé — fond #0e1620, panneaux #1a2434, texte #e8edf2

Le choix est mémorisé en localStorage (aveho_theme) et appliqué via l'attribut data-theme="dark" sur <html>.

5.2 Couverture des composants

Plus de 25 sélecteurs CSS surchargent automatiquement les couleurs en mode foncé : panneaux, tableaux, inputs, modales, cloches, recherche globale, KPIs, filtres avancés, etc. Les accents typés (DI rouge, transfert bleu, etc.) restent inchangés — le mode foncé est volontairement sobre.

5.3 Limites assumées

Quelques zones secondaires (page édition hiérarchie, vue plan d'établissement) peuvent encore avoir des styles en dur non couverts — je les passerai en revue si tu en signales. Tout le coeur fonctionnel est couvert.

6. Filtres avancés Patients NOUVEAU

Bouton Filtres avancés à côté du bouton Nouveau patient. Au clic, un panneau s'ouvre avec 4 filtres combinables :

  • Nom / Prénom — recherche libre dans nom et prénom
  • Service — liste déroulante des services de l'établissement
  • Chambre — filtrée par service si déjà sélectionné
  • État — Présent / Sorti

Un indicateur "N sur M patients affichés (filtres actifs)" apparaît au-dessus du tableau quand des filtres sont actifs. Bouton Effacer pour tout remettre à zéro.

L'approche est appliquée à Patients en 0.7 ; si tu veux l'étendre à Matériels, Articles, etc., dis-le moi.

7. Réorganisation des widgets NOUVEAU

Le dashboard personnalisable de la 0.6 évolue : dans le panneau "Personnaliser", chaque widget est maintenant accompagné de deux flèches ↑↓ pour le déplacer dans l'ordre voulu.

Pourquoi pas du drag-drop ?

Le drag-drop HTML5 natif est galère sur mobile (long-press conflictuel avec le scroll) et nécessiterait une lib (react-dnd, dnd-kit, ~50 Ko). Les flèches ↑↓ donnent un contrôle 100% prévisible sur tous les appareils, sans bibliothèque externe. Si tu testes et préfères le drag-drop, je pourrai migrer en 0.8.

Stockage

La clé localStorage aveho_dashboard stocke maintenant { active: {kpis: true, ...}, order: ["kpis", "raccourcis", ...] }. La rétrocompatibilité avec le format 0.6 (juste les actives) est préservée.

10. Procédure de mise à jour depuis Alpha 0.6

Bonne nouvelle : aucun script SQL à exécuter cette fois. La 0.7 n'ajoute aucune table ni colonne.

  1. Sauvegarde ton dossier C:\aveho-ec-app.
  2. Décompresse le nouveau zip par-dessus.
  3. Dans PowerShell :
    cd C:\aveho-ec-app
npm install
npm run dev
  4. Tests à faire :
    • Va sur /statistiques : tu dois voir 5 graphes (au moins avec un peu de données pour que ça parle)
    • Sur Articles ou Matériels, clique Import CSV et essaie avec un petit fichier de 3 lignes
    • Va dans Paramètres → Apparence → clique Mode foncé : toute l'app passe en foncé
    • Sur Patients, clique Filtres avancés et combine recherche + service
    • Sur l'accueil, clique Personnaliser et déplace un widget vers le haut/bas
  5. Mise en ligne :
    git add .
git commit -m "Aveho EC Alpha 0.7"
git push
