🌙 Fix mode sombre

Cédric : "LES TUILLES AVEC LES DATA DE COULEUR ALÉATOIRES — les écritures noir sur noir se voient pas". Cause : les inline styles forçaient color: "#142131" (noir) qui restait noir en dark, illisible sur le fond sombre du panel.

Avant / Après

❌ AVANT (dark)

Texte noir sur fond sombre teal
N° série illisible aussi

✅ APRÈS (dark)

Texte clair sur fond sombre teal
N° série lisible (muted)

🛠 Les règles CSS ajoutées

/* Cibles inline styles courants des nouvelles cartes */
html[data-theme="dark"] [style*="color: #142131"],
html[data-theme="dark"] [style*="color:#142131"]{
  color: var(--aveho-text) !important;  /* clair */
}

html[data-theme="dark"] [style*="color: #5a6878"]{
  color: var(--aveho-muted) !important;
}

html[data-theme="dark"] [style*="background: #fff"]:not(.tb-icon){
  background: var(--aveho-panel) !important;
  color: var(--aveho-text) !important;
}

/* Fonds gris très clairs → fond sombre */
html[data-theme="dark"] [style*="#fafbfc"],
html[data-theme="dark"] [style*="#f7fafa"]{
  background: #1f2a3a !important;
}

/* Borders très claires → sombre */
html[data-theme="dark"] [style*="border:1px solid #e3e9ee"]{
  border-color: var(--aveho-line) !important;
}

🔍 Recherche article avec ajout au panier

Click sur le bouton vert ouvre un panneau de recherche :

  • Input recherche avec autofocus
  • Affiche les 30 premiers articles par défaut (ou filtre par libellé/code)
  • Ligne par article avec prix HT + bouton Ajouter vert
  • Ajout au panier global avec chambre_id et chambre_nom en méta (pour traçabilité)
  • Le badge panier de la TopBar s'incrémente instantanément via l'event av-cart-change
