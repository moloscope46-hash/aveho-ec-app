🔔 2. Notification objectif équipe atteint

Quand un membre de l'équipe atteint 100% d'un objectif partagé, un toast festif s'affiche automatiquement. Le widget détecte les nouveaux atteints via un snapshot localStorage des goals déjà vus comme atteints (pas de doublon).

🎯
Objectif atteint !
Hugo Martin a atteint son objectif "Articles écrits" (Équipe Sud-Ouest).
// 0.58.59 - Détection + dispatch event + toast
const SEEN_KEY = 'av-team-goals-achieved-seen';
const seenSet = new Set(JSON.parse(localStorage.getItem(SEEN_KEY) || '[]'));
const newlyAchieved = enriched.filter(g => g.current >= g.target && !seenSet.has(g.id));

if (newlyAchieved.length > 0) {
  newlyAchieved.forEach(g => {
    window.dispatchEvent(new CustomEvent('av-team-goal-achieved', {
      detail: { goalLabel: g.label, ownerName: g.ownerName, teamName: g.team?.nom }
    }));
  });
  // Marque comme vus pour éviter doublons à la prochaine visite
  enriched.filter(g => g.current >= g.target).forEach(g => seenSet.add(g.id));
  localStorage.setItem(SEEN_KEY, JSON.stringify([...seenSet]));
}

// Listener global → toast festif
window.addEventListener('av-team-goal-achieved', (e) => {
  toast.success('🎯 Objectif atteint !',
    `${e.detail.ownerName} a atteint son objectif "${e.detail.goalLabel}".`,
    { duration: 6000 });
});
