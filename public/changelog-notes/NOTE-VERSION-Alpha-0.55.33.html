🤝 4. Action "Rattacher à un établissement"

  1. Clic bouton vert "Rattacher à un étab" dans une tuile RPPS
  2. Modale s'ouvre avec la liste de Mes établissements + Partenaires (icônes différenciées)
  3. Sélection (bordure verte) → clic "Rattacher"
  4. En backend :
    • Cherche si le praticien existe déjà dans partenaires_rpps (par RPPS)
    • Si non, l'ajoute avec classification auto (Médecin→prescripteur, IDE/Kiné/Sage→intervenant)
    • Appelle link_partenaire_rpps_to_etablissement qui ajoute l'étab à etablissement_ids[] du partenaire RPPS (sans doublon via @>)
  5. Confirmation : "Marie DUPONT est désormais rattachée à EHPAD Les Tilleuls."

👤 5. Action "Transformer en utilisateur"

Popup "Voulez-vous envoyer une invitation ?"

  • Email du nouvel utilisateur (pré-rempli depuis RPPS si disponible)
  • Rôle attribué (sélecteur des rôles de la structure) *requis*
  • Section "Informations à pré-remplir" avec checkboxes sur chaque champ disponible :
    • ☑ Prénom : "Marie"
    • ☑ Nom : "DUPONT"
    • ☑ Téléphone : "0123456789"
    • ☑ N° RPPS : "10000000001"
    • ☑ N° ADELI : "751234567"
    • ☑ Profession : "Médecin"
    • ☑ Spécialité : "Cardiologie"
    • ☑ Mode d'exercice : "Libéral"
    • ☑ Adresse postale : "12 rue X, 75011 Paris"

Tous cochés par défaut (si la donnée existe). L'utilisateur décoche ce qu'il ne veut pas envoyer.

Au clic "Envoyer l'invitation"

  1. Construit le payload selon les checkboxes
  2. INSERT dans invitations avec origine = 'rpps_annuaire'
  3. Fallback : retry sans champs RPPS si SQL 0.55.29 pas passé
  4. Appel invite-user Edge Function pour envoyer le mail (avec bloc violet RPPS si renseigné)
  5. Confirmation avec le lien d'inscription
