Résumé

La 0.27.0 finalise vraiment le mode hors-ligne en activant le cache de lecture (livré inutilisé en 0.26) sur les 3 pages les plus consultées en mobilité, et en livrant une UX complète pour la résolution des conflits.

Mode hors-ligne désormais transparent et auto-géré. Une utilisatrice peut consulter et modifier des patients/interventions/achats en zone blanche, revenir en zone couverte, et si un collègue a modifié les mêmes données entre-temps, elle peut comparer les versions et choisir champ par champ ce qu'elle garde. Aucune perte de données silencieuse.

Modale ConflictResolver

Déclenchement

Quand un UPDATE en queue échoue pour cause de conflit (détecté par la 0.26 via updated_at), un bouton orange " Résoudre" apparaît dans la modale "Actions en attente". Clic → ouvre ConflictResolver.

3 modes

  1. Compare (par défaut) : affiche un tableau avec les champs en conflit, "Ma version" (bleu) vs "Version actuelle" (orange)
  2. Merge : pour chaque champ en conflit, 2 boutons côte à côte ; l'utilisateur clique celui qu'il veut garder. Le bouton sélectionné devient plein, l'autre devient discret
  3. 3 actions disponibles depuis le mode Compare :
    • Forcer ma version (bouton bleu) : applique mon update sans check de timestamp
    • Garder version actuelle (bouton orange) : abandonne ma modif, retire de la queue
    • Fusionner manuellement (bouton violet) : passe en mode Merge

Cas particuliers gérés

  • Ligne supprimée par un autre user : message rouge "Élément introuvable" + bouton "Retirer de la queue"
  • Aucun conflit réel (timestamps différents mais mêmes valeurs) : message vert + bouton "Retirer"
  • Comparaison tolérante : null vs "" considérés identiques, string "42" vs number 42 identiques

Procédure d'application

  1. Pas de SQL.
  2. Décompresser le zip par-dessus C:\aveho-ec-app\.
  3. npm install + tests + dev : 
    cd C:\aveho-ec-app
npm install
npm test       # 194 passed
npm run dev
  4. Test cache offline :
    • Aller dans /patients, charger la page (cache se remplit)
    • F12 → Network → Offline
    • Refresh (F5) → la liste s'affiche depuis le cache, bandeau jaune "Données obsolètes"
    • Décocher Offline → bandeau disparaît au prochain load
  5. Test conflit avec résolution :
    • Navigateur 1 : charger un patient, F12 → Offline → modifier sa chambre
    • Navigateur 2 (toujours online) : modifier le même patient (médecin traitant)
    • Navigateur 1 : remettre online → sync auto échoue avec message "Conflit"
    • Cliquer le bandeau orange → modale "Actions en attente"
    • Cliquer "Résoudre" sur la ligne en conflit → modale ConflictResolver s'ouvre
    • Voir les 2 versions côte à côte → choisir "Fusionner manuellement"
    • Pour chaque champ : cliquer ma version ou version actuelle
    • "Appliquer la fusion" → la queue se vide, base à jour avec le mix choisi
