📞 1. Composant ContactActions — appel / mail / GPS

3 boutons compacts contextuels

  • 🔵 Appeler (tel:) — bleu, ouvre l'app de téléphone (mobile) ou Skype/Teams (PC)
  • 🟢 Mail (mailto:) — vert, ouvre le client de messagerie par défaut
  • 🟠 GPS — ambre, ouvre un popup de choix d'application

S'affichent uniquement si la donnée existe (pas de bouton GPS si pas d'adresse, etc.). Le composant ne s'affiche pas du tout si rien n'est défini.

Popup choix GPS (5 options)

  • 🔵 Google Maps — maps.google.com/dir/?api=1&destination=...
  • ⚪ Apple Plans — maps.apple.com/?daddr=...
  • 🔷 Waze — waze.com/ul?ll=...&navigate=yes
  • 🟢 OpenStreetMap — openstreetmap.org/?mlat=...&mlon=#map=18/...
  • ⚫ Copier l'adresse — clipboard.writeText pour coller ailleurs

Utilise les coordonnées GPS (lat/lng) si disponibles pour précision maximale, sinon l'adresse encodée URI.

🔌 2. Intégration partout (sans duplication)

ContactActions est intégré dans :

  • Tuiles RppsSearch (utilisé dans /annuaire-rpps, modale /utilisateurs, modale /partenaires-rpps) — donc tous les résultats RPPS ont les actions
  • Cartes /partenaires-rpps — sous les badges PRESCRIPTEUR/INTERVENANT
  • Cartes /etablissements-partenaires — avec coordonnées lat/lng en bonus pour GPS précis

Tous les clics sur les boutons ont un stopPropagation pour ne pas déclencher l'ouverture de la modale parente.

🏥 3. Création partenaire par FINESS / SIRENE

Dans /etablissements-partenaires → bouton "Ajouter un partenaire" → en haut de la modale (mode création uniquement) :

┌─────────────────────────────────────────────┐
│  ⚡ Remplir automatiquement                  │
│                                              │
│  ┌──────────────────┐  ┌──────────────────┐ │
│  │ 🏥 FINESS         │  │ 🏢 SIRENE         │ │
│  │ Hôpital, EHPAD…   │  │ Société, SIRET…   │ │
│  └──────────────────┘  └──────────────────┘ │
│                                              │
│  ℹ Sélectionnez un résultat pour pré-remplir │
└─────────────────────────────────────────────┘

FINESS (santé) : tape un nom d'hôpital, d'EHPAD ou un n° FINESS. Réutilise app/FinessSearch.js existant.

SIRENE (entreprises) : tape un nom de société, un SIRET (14) ou un SIREN (9). Réutilise app/SireneSearch.js existant.

Au clic sur un résultat → pré-remplit automatiquement nom, type, finess, siret, siren, adresse, cp, ville, téléphone. Le user peut éditer ensuite manuellement.

Composants déjà existants réutilisés sans duplication.
