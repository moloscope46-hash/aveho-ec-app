ℹ Info / Tâche restante (2)

Requête SQL pour audit des établissements

📋 SELECT id, nom, type, ville, cp, structure_id, est_partenaire, est_had, finess, siret, capacite, latitude, longitude, actif, created_at FROM etablissements WHERE structure_id = 'TON_STRUCTURE_ID' ORDER BY type, nom;. Pour avoir toute la hiérarchie complète avec bâtiments + services : SELECT e.nom AS etab, e.type, e.ville, b.nom AS batiment, s.nom AS service, s.code FROM etablissements e LEFT JOIN batiments b ON b.etablissement_id = e.id LEFT JOIN services s ON s.batiment_id = b.id WHERE e.structure_id = 'TON_STRUCTURE_ID' ORDER BY e.nom, b.nom, s.nom;. Pour compter les patients par étab : SELECT e.nom, COUNT(p.id) AS nb_patients FROM etablissements e LEFT JOIN patients p ON p.etablissement_id = e.id WHERE e.structure_id = 'TON_STRUCTURE_ID' GROUP BY e.id, e.nom ORDER BY nb_patients DESC;
