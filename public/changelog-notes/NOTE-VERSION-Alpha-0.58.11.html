🐛 HOTFIX GlobalSearch

Bug observé en prod dans tes logs : taper ced= dans la barre de recherche envoyait or=(numero.ilike.%ced=%25,type.ilike.%ced=%25) à Supabase → 400 Bad Request car le = est interprété comme séparateur PostgREST. Le fix sanitize les caractères qui cassent .or() : =, virgule, parenthèses, étoile.

// 0.58.11 - sanitize avant query PostgREST
if (activeFilter) filterType = activeFilter;
const safeSearch = searchTerm.replace(/[=,()*]/g, '').trim();
if (!safeSearch) { setResults([]); setLoading(false); return; }
const term = `%${safeSearch}%`;

📑 Animations slide horizontal entre tabs

Nouveau composant <TabPanel active={activeTab}> + class utility .av-tab-content + keyframe av-tab-slide-in : opacity 0 + translateX(20px) → opacity 1 + translateX(0) sur 280ms. Intégré dans /parametres (3 tabs) et /profil (4 tabs).

// CSS
@keyframes av-tab-slide-in {
  from { opacity: 0; transform: translateX(20px); }
  to   { opacity: 1; transform: translateX(0); }
}

// Usage
{activeTab === 'general' && (
  <div key='general' className='av-tab-content'>
    <Panel>...</Panel>
  </div>
)}
