Chantiers livrés

1. Téléchargement HTML des notes de version

  • 67 notes HTML (NOTE-VERSION + NOTE-HOTFIX + NOTE-DIAGNOSTIC) copiées dans public/changelog-notes/
  • Chaque version dans le changelog a maintenant un bouton "HTML" avec icône download à droite de la date
  • Attribut download sur le lien pour forcer le téléchargement plutôt que l'ouverture inline
  • Couleur du bouton assortie au type (vert/orange/bleu selon version courante/hotfix/majeure)
  • Champ noteFile ajouté à chaque entrée de versions-data.js avec le nom du fichier

2. Recherche sophistiquée avec catégories thématiques

  • 17 thèmes définis avec icône + couleur dédiée :
    🛡 RGPD & Consents 🛒 Achats & Commandes 📱 PWA & Offline 🎨 UX & Design 🔍 Audit & Logs 🔔 Notifs & Annonces 🛡 Sécurité & Droits 👤 Patients 🔧 Maintenance & DI ⚡ Perf & Qualité 📡 Realtime 📊 Stats & Dashboards ↔️ Transferts & Matériel 🔍 Recherche 🖥️ Infrastructure 📖 Documentation
  • Catégorisation automatique : chaque version est analysée par mots-clés et tagguée avec 1 à N thèmes
  • Filtres multi-select : on peut cocher plusieurs thèmes (logique OR — affiche les versions qui touchent à au moins UN des thèmes cochés)
  • Compteurs par thème en temps réel (ex: "Notifs & Annonces (24)")
  • Chips de thème cliquables sur chaque version : clic sur un chip → ajoute/retire le filtre directement
  • Recherche enrichie : la recherche scanne aussi les labels de thèmes (taper "rgpd" filtre toutes les versions du thème)
  • Voir moins/plus : si une version a > 5 chantiers, affichage tronqué avec bouton "Voir les N autres"
  • Bouton "Réinitialiser" qui efface filtre + recherche + thèmes en un clic

3. Bannière annonces — refonte complète

Position adaptative

  • Desktop (≥ 768px) : sticky en haut, sous la TopBar (comportement précédent)
  • Mobile (< 768px) : fixed en BAS de page avec respect du safe-area-inset-bottom (notch iOS, barre Android)
  • Détection responsive : listener resize qui bascule entre les 2 modes
  • Animation slide-in à l'arrivée (depuis haut sur desktop, depuis bas sur mobile)

Design visuel

  • Gradient subtil sur le fond (au lieu d'aplat) selon le niveau
  • Icône circulaire 38px avec accent color (au lieu de simple icône)
  • Bordure colorée de 3px en haut sur mobile (séparateur visuel fort)
  • Shadow forte (vers le haut sur mobile, vers le bas sur desktop)
  • 3 niveaux distincts :
    • info → dégradé bleu clair, accent #185FA5
    • warning → dégradé orange pâle, accent #EF9F27
    • critique → dégradé rouge pâle, accent #c0392b

Carousel si plusieurs annonces

  • Boutons ← → de navigation à droite
  • Compteur "1/3" avec pill colorée à côté du titre
  • Dots indicateurs en bas de la bannière (style swipe iOS) — le dot actif est étiré

Actions enrichies

  • Bouton "Détails" (desktop only, si message > 80 char) → ouvre un modal complet
  • Menu kebab (3 points) avec dropdown :
    • 👁 Voir détails (ouvre le modal)
    • 🕐 Me rappeler dans 1h (snooze persistant localStorage)
    • 📅 Demain (snooze 24h)
    • ❌ Ne plus afficher (dismiss définitif via annonces_dismissees)
  • Croix fermer rapide à droite

Modal détails

  • Avatar circulaire grand format (48px) avec icône niveau
  • Titre + niveau en uppercase
  • Message complet avec white-space: pre-wrap (préserve les retours à la ligne)
  • Métadonnées : période d'affichage + auteur
  • 3 boutons d'action : Rappel 1h · Ne plus afficher · Fermer

Snooze persistant

  • localStorage key aveho_annonces_snooze = { annonceId: timestampExpiration }
  • Au chargement, l'annonce est filtrée si snoozedMap[id] > Date.now()
  • Permet de "reporter" une annonce sans la dismisser définitivement
  • Auto-réapparaît à la prochaine session passé le délai

Procédure d'application — PowerShell

  1. Décompresser le zip 0.52.3 par-dessus C:\aveho-ec-app\ — il inclut le dossier public/changelog-notes/ avec les 67 notes HTML.
  2. Installer + lancer : 
    cd C:\aveho-ec-app
Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
npm install
npm run dev
  3. Tester :
    • Téléchargement HTML : sur /changelog, cliquer le bouton "HTML" à droite d'une version → le fichier NOTE-VERSION-Alpha-0.X.html se télécharge
    • Filtres thèmes : sur /changelog, cliquer "RGPD & Consents" → ne reste que les 13 versions du thème · cliquer aussi "Achats" → 13 + autres versions Achats (logique OR)
    • Recherche : taper "rgpd" → filtre les versions du thème + celles qui mentionnent RGPD dans titre/chantiers
    • Chips de thème : sur une version, cliquer un chip thème → ajoute ce thème au filtre
    • Voir plus : sur la 0.50 (5+ chantiers), cliquer "Voir les N autres" → expand
    • Bannière mobile : ouvrir DevTools → mode responsive → largeur < 768px → la bannière apparaît en BAS de la page (animation slide-up)
    • Carousel : créer 2-3 annonces dans /annonces → la bannière affiche "1/3" avec boutons ← → et dots
    • Modal détails : créer une annonce avec un message long (> 80 char) → bouton "Détails" apparaît → modal s'ouvre
    • Snooze : menu kebab → "Me rappeler dans 1h" → l'annonce disparaît, réapparaîtra dans 1h (testable en clear localStorage)
