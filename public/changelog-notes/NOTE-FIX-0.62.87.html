🐛 Fix bug (1)

FIX CRITIQUE caméra

📷 html5-qrcode échouait silencieusement sans déclencher le popup natif de demande de permission caméra du navigateur. Cause : Html5Qrcode.getCameras() n''appelle pas explicitement navigator.mediaDevices.getUserMedia donc le navigateur ne sait pas qu''il doit demander la permission. Fix dans QrScanner : appel à requestCameraPermission(facingMode: environment) AVANT le chargement de html5-qrcode. Si refusé → status denied + message clair. Le popup de permission s''affiche maintenant à chaque fois que tu actives le scan QR/barcode

ℹ Info / Tâche restante (2)

ScanBarcode (composant alternatif)

✅ utilise déjà navigator.mediaDevices.getUserMedia directement → permission déjà demandée correctement, pas de fix nécessaire. Le bug ne touchait QUE QrScanner (basé sur html5-qrcode). Composants impactés et fixés : /scan, /mobile/scan-bs, /mobile/scan-ordo, /magasin/scan + tout endroit utilisant <QrScanner>
