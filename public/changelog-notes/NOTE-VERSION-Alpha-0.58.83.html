📝 Configuration dans Profil

Va dans /profil onglet Profil → nouvelle panel teal "Mon téléphone" :

  • Input type=tel en police mono
  • Bouton "Enregistrer" NeonButton teal
  • Stockage : auth.user.user_metadata.telephone_perso via supabase.auth.updateUser()
  • Pas besoin de table SQL — c'est dans Supabase Auth metadata, chiffré server-side

🔍 Comportement intelligent

Le FAB est caché sur :

  • /login, /choix-mode, /connexion (pas pertinent avant auth)
  • Toutes les pages d'impression : /depots/[id]/qr, /patients/[id]/qr, /print/* (gênant pendant impression)
  • Pas affiché si auth.ready false ou pas d'user
