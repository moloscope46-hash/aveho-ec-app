🩹 D'abord : fix bloquant /materiels

Le Promise.all avec 6 requêtes échouait dès qu'UNE colonne/table était absente (typiquement patients.chambre ancienne, ou tags_materiel). Toutes les autres pertes en cascade → relReady jamais à true → page bloquée sur return null. Remplacé par tryFetch individuel, chaque requête a son catch + fallback []. Force setRelReady(true) même en cas d'erreur globale.

🎯 Le workflow complet (en 5 étapes)

1
Tu crées tes dépôts dans /depots
Hiérarchie Bâtiment → Service → Chambre. Bouton + Emplacement pour créer des sous-emplacements (casiers, étagères) sans nouvelle table SQL — juste un parent_depot_id auto-référence.
2
Tu cliques Imprimer QR sur chaque dépôt
Ça ouvre /depots/[id]/qr = page A4 portrait avec gros QR 500×500, nom, code, type, pictos des 4 actions. Ctrl+P ou bouton Imprimer → tu colles physiquement sur l'étagère / porte / mur.
3
Sur le terrain, tu scannes le QR avec ton téléphone
Le QR renvoie vers /scan/depot/[id] = landing page avec le dépôt affiché en couleur + 4 grandes tuiles d'action :
Voir matériels
Liste filtrée sur ce dépôt
Inventaire
Scan + comptage + écarts
Transfert
Démarre workflow 2-scan
Ranger ici
Scan matériel → assign auto
4
📋 Inventaire — tu scannes, ça compte, ça écarte
/inventaire/[depot_id] = page complète avec barre de progression X/Y trouvés.
Chaque scan : (1) cherche dans la liste théorique → coche · (2) si pas trouvé, cherche en DB → intrus si d'un autre dépôt · (3) beep aigu = OK, beep grave = inconnu.
Sections affichées : Manquants (rouge), Intrus (violet). Bouton Valider l'inventaire → enregistre date + nb écarts sur le dépôt.
5
↔ Transfert 2-scan automatique
Depuis /depots ou le landing du dépôt source, click Transfert → source mémorisée en localStorage.
Tu scannes le QR du dépôt destination → landing affiche "Transfert en cours · Valider ICI ?".
Click Valider → insert dans transferts + update materiels.depot_id + flag cree_par_scan=true. Apparait dans la liste /transferts.

🗄 SQL minimal (que des ALTER)

-- migration-0.58.79-workflow-scan-inventaire.sql
ALTER TABLE materiels ADD COLUMN IF NOT EXISTS emplacement TEXT;
ALTER TABLE depots
  ADD COLUMN IF NOT EXISTS parent_depot_id UUID,
  ADD COLUMN IF NOT EXISTS inventaire_dernier TIMESTAMPTZ,
  ADD COLUMN IF NOT EXISTS inventaire_dernier_par UUID,
  ADD COLUMN IF NOT EXISTS inventaire_ecarts_count INTEGER;
ALTER TABLE transferts ADD COLUMN IF NOT EXISTS cree_par_scan BOOLEAN DEFAULT false;
-- + recreate vue v_depots_hierarchie avec parent
