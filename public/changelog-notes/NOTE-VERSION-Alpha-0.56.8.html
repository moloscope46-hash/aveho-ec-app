🎯 Le concept

Tu as enregistré X prescriptions depuis 0.56.3. Mais sans page dédiée pour les explorer, c'est juste un tas de lignes. Cette version te donne :

  • Une vue d'ensemble immédiate de toute l'activité prescriptive (8 KPI : total, lignes, DCI uniques, prescripteurs, patients, OCR, RPPS vérifiés, tokens IA)
  • Une recherche multi-critères puissante (9 filtres combinables : nom prescripteur, RPPS, médicament, DCI, type, source, statut, dates)
  • Des top 15 médicaments et prescripteurs avec stats croisées (patients uniques, dates)
  • Un histogramme mensuel sur 12 mois avec graphique en barres
  • Un export CSV Excel-compatible (BOM UTF-8, séparateur ;) avec option médicaments concaténés

🔍 Recherche multi-critères

9 filtres combinables, tous optionnels :

FiltreTypeExemple
Prescripteur (nom)ILIKE fuzzy"Dupont" matche "DUPONT", "dupont", "Dupont-Martin"
RPPSexact10100123456
MédicamentILIKE fuzzy (via lignes)"DOLIPRANE" matche "DOLIPRANE 1000 mg", "doliprane"
DCIILIKE fuzzy (via lignes)"PARACETAMOL"
Typeexactbizone / hospitalière / sécurisée / etc.
Sourceexactocr / manuelle / import
Statutexactactive / archivée / annulée
Date début≥2025-01-01
Date fin≤2025-12-31

Les recherches sur médicament/DCI passent d'abord par prescriptions_lignes (avec ilike + set deduplication des IDs) puis filtrent les prescriptions correspondantes. C'est rapide grâce aux index GIN trigramme créés sur les noms.

📊 8 KPI dashboard

  • Total prescriptions (mis en évidence violet)
  • Lignes (méds) — somme des médicaments prescrits, tous patients confondus
  • DCI uniques — molécules distinctes (avec fallback nom commercial si DCI null)
  • Prescripteurs uniques — préférence RPPS, fallback nom case-insensitive
  • Patients — patients distincts ayant reçu au moins 1 prescription
  • Via OCR — prescriptions créées par scan d'ordonnance
  • RPPS vérifiés — prescriptions dont le RPPS du prescripteur a été validé contre l'annuaire ANS
  • Tokens IA — tokens IN + OUT consommés au total pour les OCR

Période couverte affichée : première date → dernière date.

🏆 Top médicaments + prescripteurs

Top médicaments (15)

Classement par nb_prescriptions. Préfère la DCI (UPPER-case) pour regrouper toutes les variantes commerciales (DOLIPRANE 1000, DOLIPRANE 500, etc. → tous comptés comme PARACETAMOL). Badge vert "DCI" si DCI fournie, sinon nom commercial. Barre de progression proportionnelle au #1.

Top prescripteurs (15)

Classement par nb_prescriptions. Groupe par nom case-insensitive. Affiche RPPS + spécialité + nb patients uniques + nb lignes + dernière date d'activité. Badge vert "Vérifié" si au moins une prescription a un RPPS validé ANS (agrégation via bool_or).

📈 Tendances 12 mois

Histogramme en barres avec gradient violet sur 12 mois (utilise generate_series + LEFT JOIN pour inclure les mois vides à 0, évitant les trous dans le graphique). Sous le graphique, tableau détaillé avec nb_prescriptions + nb_lignes + nb_patients_uniques + nb_ocr par mois.

💾 Export CSV

2 boutons d'export qui apparaissent uniquement quand il y a des résultats :

  • Export CSV — 19 colonnes (date, patient nom+prénom+dossier, étab, prescripteur+RPPS+spé, vérif RPPS+source, type, durée, renouvelable+nb, source, statut, notes, date création)
  • Export + médicaments — ajoute 2 colonnes : "Médicaments (liste)" avec concat nom + dosage + posologie en pipe (|), et "Nb lignes"

Le CSV est généré avec :

  • BOM UTF-8 en tête (Excel l'utilise pour détecter l'encodage et afficher les caractères accentués correctement)
  • Séparateur ; (Excel France attend ça par défaut)
  • CRLF entre lignes (compatible Excel Windows)
  • Échappement des quotes (doubles "" comme la norme RFC 4180), retour-ligne, et séparateur
  • Limite 5000 lignes par export (sécurité mémoire)

Téléchargement automatique côté front : appel API → blob → URL.createObjectURL → lien temporaire simulé → URL.revokeObjectURL. Le fichier porte un nom daté : prescriptions-archive-YYYY-MM-DD.csv.
