🔐 1. Modal validation SIRET

Modifier le SIRET d'un groupement est un changement structurant qui impacte la facturation, les conventions AMC/SESAM-Vitale, les accréditations. Une modal de confirmation en variant danger liste désormais ces impacts avant validation.

⚠ Modification du SIRET
Vous modifiez le SIRET du groupement. Ancien SIRET : 12345678901234 Nouveau SIRET : 98765432109876 ⚠ Ce changement est structurant et peut impacter : • La facturation et les liens AMC/SESAM-Vitale • Les conventions et accréditations • L'historique des certifications Voulez-vous vraiment continuer ?
// 0.58.53 - app/collectivite/page.js
async function saveFiche() {
  const oldSiret = fiche?.siret || '';
  const newSiret = form.siret?.trim() || '';
  
  if (newSiret !== oldSiret) {
    const ok = await dialogs.confirm({
      title: 'Modification du SIRET',
      message: `Ancien SIRET : ${oldSiret}\nNouveau SIRET : ${newSiret}\n\n⚠ Impact :\n• Facturation et AMC/SESAM-Vitale\n• Conventions et accréditations\n• Historique des certifications`,
      okLabel: 'Confirmer le changement',
      okColor: '#c0392b',
      variant: 'danger',
    });
    if (!ok) return;
  }
  // ... save
}
