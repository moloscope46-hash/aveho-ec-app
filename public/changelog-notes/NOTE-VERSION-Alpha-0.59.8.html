🩹 D'abord : Fix erreur SQL

Tu as eu en applicant 0.59.5 :

Cause : la vue v_magasin_di s'appuie sur des tables qui n'existent pas chez toi. Le fichier fix-demandes-internes-0.59.8.sql les crée toutes (demandes_internes + lignes + bons_livraison) + recrée la vue. Applique-le AVANT de pusher 0.59.8.

✅ 2. Bouton "Confirmer la réception" côté EC

Sur /demandes-internes/[id] en mode EC, si statut=livree → nouveau panneau bleu avec :

  • Bouton ✓ Confirmer la réception → passe DI en `cloturee` + set `recue_at` + `recue_par` + notif magasin
  • Bouton Voir / Réimprimer BL → réouvre la fenêtre print du BL
  • Numéro BL affiché en chip bleu

🔄 Cycle complet avec notifications

EC crée DI → INSERT notification magasin
   ↓
Magasin Valide → INSERT notif EC "DI validée"
   ↓
Magasin Génère BL → INSERT notif EC "BL XXX émis · Confirme à réception"
   → fenêtre print BL s'ouvre
   ↓
EC reçoit notif → click → arrive sur DI livrée
   → Bouton "Confirmer la réception"
   ↓
Click "Confirmer" → DI cloturee + INSERT notif magasin "DI réceptionnée"
   ↓
Cycle terminé ✓
