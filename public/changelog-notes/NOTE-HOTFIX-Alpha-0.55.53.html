❌ Le bug critique

Les invitations ne partent plus mais l'app annonçait "Invitation envoyée" sans warning. Tu te demandais pourquoi tes invités ne recevaient rien.

Cause technique

supabase.functions.invoke() ne throw PAS en cas d'erreur côté Edge Function. Il retourne {data, error} et l'ancien code attrapait seulement les exceptions JS via try/catch — donc les erreurs Resend étaient silencieuses.

// AVANT (silencieux si Resend KO)
try {
  await supabase.functions.invoke("invite-user", {...});
  // ✓ Toujours considéré "ok" même si Resend a refusé
} catch (e) {
  logger.warn("Email non envoyé", e);  // jamais atteint
}

✅ La correction

1) Capture {data, error} côté app

const { data: invokeData, error: invokeErr } = await supabase.functions.invoke(...);
if (invokeErr) {
  // FunctionsHttpError contient un readableStream qu'on doit lire
  const reader = invokeErr.context.body.getReader();
  const text = new TextDecoder().decode((await reader.read()).value);
  const json = JSON.parse(text);
  mailWarning = `Mail NON envoyé : ${json.error}`;
}

2) Popup invitation : bandeau rouge si KO

Si mailWarning présent dans createdInviteLink :

  • Header passe de vert ✓ à ambre ⚠ "Invitation créée — mail NON envoyé"
  • Bandeau rouge avec la raison Resend exacte
  • Conseil : "Copie le lien ci-dessous et envoie-le manuellement (SMS, WhatsApp, mail perso). L'invitation Aveho est bien créée en base, seul l'email automatique a échoué"

3) Edge Function v2 — diagnostic complet

Décode les erreurs Resend courantes en messages humains :

Code diagnosticCauseSolution
missing_resend_keyRESEND_API_KEY absentSupabase → Settings → Edge Functions → Secrets
resend_test_mode_restrictedMode test : seul l'email proprioVérifier domaine sur resend.com/domains + secret RESEND_FROM
resend_invalid_keyClé révoquée/expiréeRégénérer sur resend.com/api-keys
resend_rate_limitQuota 3000/mois dépasséAttendre ou upgrade plan

Retour enrichi {ok, diagnostic, error, resend_status, resend_body, from_address, to, duration_ms, resend_id?}.

4) Nouveau secret RESEND_FROM

Configurable dans Supabase Secrets. Par défaut "Aveho EC <onboarding@resend.dev>" (limité au compte test). Recommandé : "Aveho EC <noreply@tondomaine.fr>" après vérification du domaine.

🔬 Nouvelle page /admin/mail-diagnostic

Test l'envoi d'invitation à un email donné et affiche tout le détail :

  • Résultat OK/KO coloré (vert/rouge)
  • Code diagnostic en mono
  • HTTP status Resend
  • From / To utilisés
  • Durée envoi
  • Resend ID si succès (pour suivi dans dashboard Resend)
  • Body brut Resend dépliable
  • Panneau pédagogique en bas : 5 causes courantes + solution exacte + liens vers resend.com/api-keys et resend.com/domains

Accès : menu Administration → Diagnostic envoi mail (rouge mail-cog).
