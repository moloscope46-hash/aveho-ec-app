Mode hors-ligne chauffeur

🛠️ table sync_queue créée. Implémentation côté client à faire : (a) en mode offline, intercepter les writes Supabase et les pousher dans sync_queue avec action insert/update/delete + données serialisées. (b) à la reconnexion, lire toutes les rows statut=pending, les rejouer dans l'ordre temporel sur Supabase, marquer synced ou conflict si erreur. (c) IndexedDB pour cache lecture tournée complète (étapes + clients + matériels) au démarrage de la tournée. Recommandation : utiliser une lib comme idb-keyval pour simplifier IndexedDB
