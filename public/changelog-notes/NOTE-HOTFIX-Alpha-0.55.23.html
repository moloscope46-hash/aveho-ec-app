🎯 Fix 1 — Centrage final du badge version

Symptôme : Sur tes captures, le badge "v0.55.21" était toujours visuellement décalé vers le bas par rapport au texte "aveho".

Cause

Le .logo est un <span> qui héritait du line-height par défaut (~1.5). Donc même si la TopBar fait display:flex; align-items:center;, le centre visuel du texte "aveho" et le centre de la box du span ne coïncidaient pas — la baseline tirait le rendu vers le bas.

Fix

.logo {
  font-size: 21px;
  font-weight: 500;
  letter-spacing: 2px;
  cursor: pointer;
  display: inline-flex;     /* nouveau */
  align-items: center;       /* nouveau */
  line-height: 1;            /* nouveau — coupe l'espace ascender/descender */
  height: 24px;              /* nouveau — hauteur fixe */
  flex-shrink: 0;
}
.version-badge {
  ...
  height: 24px;              /* même hauteur que le logo */
}

Maintenant les 2 éléments ont la même hauteur exacte (24px) et leur centre vertical coïncide.

🔔 Fix 2 — Feedback détaillé sur autorisation notif/géoloc

Symptôme : Quand tu cliquais sur "Autoriser" pour les notifs, Edge affichait un message "Notifications bloquées" sans qu'on comprenne pourquoi, et la modale ne donnait aucun retour.

Cause

Edge et Chrome ont un mode "Quiet permission requests" (par défaut sur les sites peu visités) qui bloque automatiquement les demandes de permission sans afficher le prompt classique. L'API Notification.requestPermission() retourne immédiatement "default" sans rien demander.

Et si l'user avait déjà refusé une fois, l'API retourne directement "denied" et on ne peut PLUS demander à nouveau via JS — il faut aller dans les paramètres du navigateur.

Fix UX

On affiche maintenant un message inline coloré après chaque clic sur "Autoriser", selon le résultat retourné par l'API :

RésultatCouleurMessage
granted🟢 Vert"Notifications autorisées !" + envoi d'une notif de test immédiate
denied🔴 Rouge"Notifications bloquées par le navigateur. Cliquez sur l'icône de cadenas/info dans la barre d'adresse → Permissions → Notifications → Autoriser."
default (Quiet mode)🟡 Orange"Le navigateur a bloqué la demande. Cliquez sur l'icône cloche ou cadenas dans la barre d'adresse pour autoriser manuellement."

Idem pour la géolocalisation avec adaptation au PositionError.code :

  • code === 1 (PERMISSION_DENIED) → rouge avec instructions cadenas
  • autres → orange avec message générique

Notif de test au succès

if (result === "granted") {
  new Notification("Aveho EC", {
    body: "Vous recevrez désormais les alertes importantes ici",
    icon: "/icons/icon-192.png",
  });
}

Comme ça l'user voit immédiatement une vraie notif système → preuve concrète que c'est actif.

Affichage du feedback

  • Sur desktop : encart coloré dans le popover juste après la description
