❌ Le bug critique

Dans les logs prod Vercel, plusieurs requêtes /api/sirene retournaient HTTP 502 Bad Gateway :

GET /api/sirene?q=matériel médical&limit=25&lat=47.3582&lng=0.9943
→ 502 Bad Gateway

GET /api/sirene?q=orthopédie&limit=25&lat=47.3894&lng=0.6732
→ 502 Bad Gateway

La carte ne pouvait pas afficher les résultats SIRENE — recherche libre cassée.

La cause

  • Aucun maxDuration côté route Next.js → Vercel utilise la valeur par défaut (10s sur plan Hobby, 60s sur Pro)
  • Aucun AbortController côté code → la requête vers recherche-entreprises.api.gouv.fr n'avait pas de timeout
  • Quand l'API gouv mettait >10s à répondre (requête lourde avec geo + filtres), Vercel killait → 502

✅ La correction

Route /api/sirene robustifiée

  • maxDuration = 30 et dynamic = "force-dynamic" exportés
  • AbortController interne 25s (avant le 30s Vercel pour avoir le temps de répondre proprement)
  • Plus JAMAIS de 502 : toutes les erreurs (timeout, network, HTTP not-ok) sont catchées et retournent HTTP 200 avec ok: false + message explicite
  • Format unifié : { ok, count, results, error?, duration_ms, timeout? }
  • Limite max remontée de 20 → 50 (le user demandait limit=25, ignoré silencieusement avant)
  • Message pédagogique en cas de timeout : "Timeout SIRENE >25s — la requête est trop lourde, essaie avec plus de critères"
  • User-Agent "Aveho-EC/0.55" pour traçabilité
  • Support commune (nom de ville) en plus de code_postal

/api/finess aussi

maxDuration 30s + dynamic force-dynamic ajoutés pour éviter le même bug en cascade.

👁 Page /scan/ocr (générique)

Page d'OCR libre — utile pour tout document que l'OCR bulletin spécifique ne traite pas :

  • Prescriptions médicales
  • Factures fournisseurs
  • Courriers patient
  • Photos de matériel avec étiquettes texte
  • Captures d'écran avec texte

Workflow

  1. Drag & drop ou clic pour parcourir / capture caméra mobile
  2. Aperçu image
  3. Bouton ambré "Extraire le texte"
  4. Claude Vision renvoie le texte brut conservant la structure (sauts de ligne, paragraphes, tableaux)
  5. Textarea éditable + bouton "Copier" dans le presse-papier
  6. Tokens IN/OUT affichés pour audit coût

Différence avec /scan/bulletin-situation

Bulletin → JSON structuré 40+ champs + création patient. Générique → juste le texte brut, à toi d'en faire ce que tu veux.
