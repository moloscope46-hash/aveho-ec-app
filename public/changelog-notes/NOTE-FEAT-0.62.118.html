Hook useEditLock

🔒 (lib/useEditLock.js) : empêche 2 utilisateurs d éditer simultanément la même ressource. Sur ouverture d une modal d édition, tente de poser un lock dans table edit_locks (resource_type, resource_id, user_id, locked_at). Refresh auto toutes les 30s tant que la modal ouverte. Auto-expire après 2 min sans refresh. Release au unmount + beforeunload. Mode dégradé silencieux si table absente. Retourne { locked, lockedBy, checking, takeover, ownLock }. Si locked=true : afficher banner av-edit-lock-banner avec nom du user qui édite + bouton Reprendre la main (takeover force)

ℹ Info / Tâche restante (2)

Comment utiliser FoldableFilters dans une page

💡 remplacer le bloc filtres existant par <FoldableFilters searchValue={search} onSearchChange={setSearch} activeFiltersCount={N} onResetAll={...} storageKey=patients>{...filtres existants...}</FoldableFilters>. Les filtres avancés (statut, type, équipe, etc.) restent dedans, repliés par défaut. Le search est toujours visible. Le badge compteur affiche le nombre de filtres actifs (>0). Le bouton refresh rouge apparait dès qu un filtre est actif
