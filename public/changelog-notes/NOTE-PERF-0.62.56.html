🤖 Backend / Frontend (2)

Next.js performances dans `next.config.js`

⚡

  1. compress: true — gzip côté Next (en plus de Vercel)
  2. productionBrowserSourceMaps: false — pas de sourcemaps en prod (gain de plusieurs MB sur les bundles)
  3. modularizeImports.lodash — transforme import { x } from 'lodash' en import x from 'lodash/x' au build (tree-shake natif)
  4. experimental.optimizePackageImports: ['recharts', 'd3', 'lucide-react', '@supabase/supabase-js'] — tree-shaking optimisé sur ces 4 packages lourds (réduction estimée 200-400 KB sur le bundle initial)
  5. images.formats: ['image/avif', 'image/webp'] + minimumCacheTTL: 60 — sert les images en formats modernes avec cache
📁 Fichiers concernés : next.config.js

Lazy load des composants d'export PDF/CSV

📦 dans DashboardWidgets.js. Avant : import TeamStatsPdfExport from './TeamStatsPdfExport' (static, toujours dans le bundle même quand inutilisé). Après : const TeamStatsPdfExport = dynamic(() => import('./TeamStatsPdfExport'), { ssr: false, loading: () => null }). Idem pour TeamGoalsSnapshotsExport. Ces composants ne sont rendus que quand le user clique sur 'Exporter PDF' ou 'Exporter CSV' — pas la peine de les charger d'office. Gain estimé : ~30 KB sur le chunk dashboard (et chargement à la demande au click)

📁 Fichiers concernés : DashboardWidgets.js

🐛 Fix bug (1)

Fix contraste titres : noir sur noir invisible

🎨 . Le PageHead premium (0.62.45) avait color: #142131 (navy) qui devenait illisible sur fond .bg-dark (qui est très sombre : radial gradient #244a55 → #18202c → #0f1b28). Solution : titre passe en blanc par défaut (color: #fff + textShadow: 0 1px 2px rgba(0,0,0,.2) pour relief), subtitle en rgba(255,255,255,.75), border-bottom en rgba(255,255,255,.08). Classes CSS ajoutées : .av-page-hero, .av-page-hero-title, .av-page-hero-sub. Override pour fond clair (panel blanc) : .panel .av-page-hero-title { color: #142131 !important } + équivalents pour subtitle et border. Aussi fix legacy : .bg-dark .h1 { color: #fff }, .bg-dark .eyebrow { color: rgba(255,255,255,.6) }, .bg-dark .sub { color: rgba(255,255,255,.7) }. Tous les titres sont enfin lisibles partout
