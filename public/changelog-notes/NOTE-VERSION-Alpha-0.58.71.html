Chaque changement d'état est automatiquement tracé dans materiel_mouvements via trigger PostgreSQL.

🔄 Table `materiel_mouvements` + trigger PostgreSQL

Trigger SQL track_materiel_changes() AFTER UPDATE qui auto-insère un mouvement à chaque modification d'état/patient/dépôt — aucun code applicatif à écrire, c'est garanti côté base.

↓ ENTRÉE ↑ SORTIE ↔ TRANSFERT 🔧 SAV ENVOI 🔧 SAV RETOUR 🗑 REBUT 👤 RÉAFFECTATION ✏ CHGT ÉTAT 
CREATE OR REPLACE FUNCTION track_materiel_changes()
RETURNS TRIGGER AS $$
BEGIN
  IF (NEW.etat IS DISTINCT FROM OLD.etat) THEN
    INSERT INTO materiel_mouvements (structure_id, etablissement_id, materiel_id, type,
      etat_avant, etat_apres, source)
    VALUES (NEW.structure_id, NEW.etablissement_id, NEW.id, 'changement_etat',
      OLD.etat, NEW.etat, 'systeme');
  END IF;
  -- + réaffectation patient + changement dépôt
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
