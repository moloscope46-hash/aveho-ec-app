🎯 Le concept

Tu prends en photo une ordonnance médicale → Claude Vision lit l'écriture (même manuscrite) et extrait automatiquement :

  • Prescripteur : nom, prénom, RPPS, spécialité, adresse, téléphone, FINESS
  • Métadonnées : date, type (ordonnance / bizone ALD / médicaments d'exception / sécurisée / hospitalière), durée du traitement, renouvellements
  • Médicaments structurés : nom commercial, DCI déduite, forme, dosage, voie, posologie complète, prises/jour, durée en jours, quantité à délivrer, commentaire ALD/à jeun/etc.

Tu vérifies, tu sélectionnes le patient, tu valides → prescription créée en base avec ses médicaments + ordonnance archivée dans Storage privé.

📋 Workflow

1. UploadImage (JPG, PNG, WebP, HEIC) ou PDF
2. OCR IAClaude Vision extrait le JSON structuré
3. VérificationÉdition prescripteur + médicaments
4. Patient & créationSélection patient + insertion BDD + archivage

🗄 Architecture base de données

Table prescriptions (en-tête)

1 prescription = 1 ordonnance. Contient le prescripteur, les méta-données, l'archivage du fichier source, et l'audit OCR (tokens, confiance, texte brut conservé).

Table prescriptions_lignes (N médicaments)

1 ligne = 1 médicament prescrit. Champs : nom commercial, DCI, forme, dosage, voie, posologie libre ET structurée (qte_par_prise + unite_prise + prises_par_jour + duree_jours), quantité à délivrer, renouvelable, commentaire (ALD, à jeun, contexte).

Bucket prescriptions-scannees

Privé, 10 Mo max, MIME image/* + PDF. Convention de path à 3 niveaux : {structure_id}/{patient_id}/{prescription_id}/{ts}-{filename}. Permet de ranger naturellement plusieurs ordonnances par patient.

12 policies RLS

4 sur prescriptions + 4 sur prescriptions_lignes (via FK) + 4 sur storage.objects. Toutes isolent par structure_id via membres_structure → user_id = auth.uid().

🤖 Prompt Claude Vision

Le prompt force un retour JSON pur (pas de markdown) avec règles précises :

  • Conversion auto durée : "1 mois" → 30 jours, "3 mois" → 90, "1 semaine" → 7
  • Conversion posologie : "matin midi soir" → 3 prises/jour, "x3" → 3, "un demi" → 0.5
  • Auto-détection type : bizone (2 zones), securisee (papier vert filigrané), medicaments_exception (mention explicite), hospitaliere, sinon ordonnance simple
  • ALD/non-ALD : si bizone, chaque médicament reçoit le commentaire "ALD" ou "non-ALD"
  • Pas d'invention : préférer null à une valeur incertaine
  • Confiance globale retournée par Claude lui-même : haute, moyenne, faible

⚠️ Limites connues

  • Écriture manuscrite illisible : Claude est très bon mais pas magique — confiance "faible" retournée si l'image est de très mauvaise qualité, alors vérifier manuellement
  • DCI : Claude essaie de déduire la DCI à partir du nom commercial (DOLIPRANE → PARACETAMOL), mais pas toujours fiable — on stocke null si pas sûr
  • Bizone : tous les médicaments sont mis dans le même tableau, distingués par le commentaire "ALD"/"non-ALD" — pour une vraie séparation visuelle il faudrait scinder en deux sections (peut être ajouté en 0.56.X+)
  • Pas d'auto-link RPPS : le RPPS du prescripteur n'est pas automatiquement vérifié contre l'annuaire ANS (à ajouter dans une version future si besoin)
