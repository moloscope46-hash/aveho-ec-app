✂️ Fix — Sub-set CSS auto-généré

Création d'un script Node ES modules qui :

  1. Scanne récursivement app/, lib/, public/changelog-notes/ pour trouver toutes les classes ti-NAME utilisées dans le code (JS, JSX, HTML, CSS)
  2. Lit le CSS source @tabler/icons-webfont/tabler-icons.css pour extraire les codepoints (content: "\eaXX") correspondants
  3. Génère app/tabler-icons-subset.css avec uniquement :
    • Le bloc @font-face initial
    • La classe générique .ti
    • Les ~322 classes d'icônes utilisées (filtrant les faux positifs comme "ti-x-circle" qui matche regex "ti-x")
  4. Copie les fonts .woff2 / .woff / .ttf depuis node_modules/@tabler/icons-webfont/fonts/ vers public/tabler-icons/ pour les servir depuis le même domaine que l'app (cache HTTP optimal par Vercel + brotli)

🔧 Le script (scripts/build-tabler-icons-subset.mjs)

// 1. Scanner toutes les utilisations "ti-NAME" dans le code
async function scanIcons(dir, found = new Set()) {
  const entries = await fs.readdir(dir, { withFileTypes: true });
  for (const e of entries) {
    if (e.name === "node_modules" || e.name === ".next") continue;
    const full = path.join(dir, e.name);
    if (e.isDirectory()) {
      await scanIcons(full, found);
    } else if (e.name.endsWith(".js") || ...) {
      const src = await fs.readFile(full, "utf-8");
      const matches = src.match(/ti-[a-z0-9-]+/g) || [];
      for (const m of matches) {
        if (m.length >= 4) found.add(m);
      }
    }
  }
  return found;
}

// 2. Lire le CSS source + extraire les codepoints des icônes utilisées
const tablerCss = await fs.readFile(TABLER_CSS, "utf-8");
const blockRe = /\.([a-z0-9-]+):before\s*\{\s*content:\s*"\\([a-f0-9]+)";\s*\}/g;
let match;
while ((match = blockRe.exec(tablerCss)) !== null) {
  if (usedIcons.has(match[1])) {
    lines.push(`.${match[1]}:before { content: "\\${match[2]}"; }`);
  }
}

// 3. Adapter les paths fonts pour pointer vers /tabler-icons/ (public)
let outputCss = lines.join("\n");
outputCss = outputCss.replace(/url\("\.\/fonts\//g, 'url("/tabler-icons/');

// 4. Copier les fonts dans public/tabler-icons/
const woff2Files = await fs.readdir(TABLER_FONTS_DIR);
for (const f of woff2Files) {
  if (f.endsWith(".woff2") || f.endsWith(".woff") || f.endsWith(".ttf")) {
    await fs.copyFile(...);
  }
}

⚠️ À retenir pour les futures versions

Quand on ajoute une nouvelle icône dans le code (par exemple <i className="ti ti-magic-wand" />), il faut régénérer le subset :

node scripts/build-tabler-icons-subset.mjs

Sinon l'icône n'apparaîtra pas (la classe .ti-magic-wand:before n'existe pas dans le subset). C'est facile à détecter en visuel mais à intégrer dans le workflow de release.

Option pour CI : ajouter une étape node scripts/build-tabler-icons-subset.mjs avant npm run build dans vercel.json. Mais pas critique pour le moment.
