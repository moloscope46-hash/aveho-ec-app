🩹 D'abord : fix bloquant services.icone 400

Le composant BatimentServiceSwitcher demandait services?select=id,nom,icone mais la colonne icone n'existe pas sur ta table services. Le 400 venait du REST API Supabase (pas une exception JS, donc try/catch ne capte pas). Résultat : composant cassé + cascade React #310 sur les pages qui l'utilisent.

Fix : select('id, nom') direct, sans icone. Fallback structure_id si batiment_id absent. Plus de 400 dans la console.

🏠 Nouvelle page /chambres

Cards par chambre avec icône type colorée (Simple/Double/Médicalisée/Isolement), badges téléphone vert/rouge, code d'accès, nb lits, hiérarchie Bâtiment {'>'} Service. Modal d'édition rapide pour saisir téléphone + code + type + notes. Liste des patients présents dans la chambre avec leur tél perso direct.
