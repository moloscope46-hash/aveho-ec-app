🗄 SQL / Migration (1)

`migration-0.62.21-v-collaborateurs-ULTRA-DEFENSIF.sql`

🚨 la migration 0.62.20 plantait ERROR 42703: column m.id does not exist. Fix radical : on TEST chaque colonne individuellement via information_schema.columns avant de l'inclure dans le SELECT. Boucle FOREACH c IN ARRAY candidate_cols qui construit dynamiquement la liste de colonnes existantes. Plus jamais aucune erreur 42703 possible. Bonus : SELECT diagnostic à la fin qui liste TOUTES les vraies colonnes de membres_structure
