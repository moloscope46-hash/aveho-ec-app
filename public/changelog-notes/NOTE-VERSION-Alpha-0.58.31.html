➕ 3. Bouton "Créer un établissement" en header (admin)

Visible si rôle admin. Redirige vers /etablissements?create=1 qui détecte le param et ouvre automatiquement la modale de création avec recherche FINESS. URL est nettoyée après ouverture pour ne pas re-déclencher au reload.

// app/etablissements/page.js
import { useSearchParams } from 'next/navigation';
const searchParams = useSearchParams();

useEffect(() => {
  if (searchParams?.get('create') === '1') {
    openCreateFiness();
    // Nettoie l'URL pour ne pas réouvrir au reload
    const url = new URL(window.location.href);
    url.searchParams.delete('create');
    window.history.replaceState({}, '', url);
  }
}, []);
