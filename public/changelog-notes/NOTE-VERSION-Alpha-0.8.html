3. Tri des colonnes NOUVEAU

Sur toutes les listes utilisant le composant Crud (Articles, Matériels, Dépôts, Zones, Stock, etc.), les en-têtes du tableau sont maintenant cliquables pour trier la liste par cette colonne.

  • Premier clic sur une colonne : tri ascendant (icône )
  • Second clic sur la même colonne : tri descendant (icône )
  • Les colonnes non triables peuvent être marquées avec skipSort: true dans leur définition

Comparaison numérique si les deux valeurs sont des nombres, sinon comparaison string sans casse (locale française). Les valeurs null sont toujours envoyées en fin de liste.

Comportement combiné avec les filtres

Le tri est appliqué après le filtrage. Si tu filtres les Matériels en "Maintenance" puis tu tries par libellé, la pagination repart à la page 1 et tu vois la première page des matériels en maintenance triés alphabétiquement.

4. Pagination NOUVEAU

Quand une liste dépasse 50 lignes, une barre de pagination apparaît sous le tableau :

┌─────────────────────────────────────────────────────────────┐
│ < Précédent      Page 1 sur 4 — 173 ligne(s)      Suivant > │
└─────────────────────────────────────────────────────────────┘

Quand la liste fait 50 lignes ou moins, aucune barre n'apparaît — pas de pollution visuelle inutile.

Choix techniques

  • 50 lignes/page : compromis entre tout afficher (lent au-delà de 200 lignes) et trop découper
  • Pagination côté client sur les données déjà chargées. Reste rapide jusqu'à quelques milliers de lignes. Si tu atteins 10k+ lignes, on basculera sur une pagination serveur avec range() Supabase
  • Changer de filtre, de tri ou d'établissement remet la pagination à la page 1

5. Filtres avancés étendus (composant AdvFilters) NOUVEAU

En 0.7 j'avais codé les filtres avancés directement dans la page Patients. La 0.8 sort cette logique dans un composant réutilisable app/AdvFilters.js, et l'applique aux pages Articles et Matériels.

Pages couvertes

PageFiltres disponibles
Patients (0.7)Nom/Prénom, Service, Chambre, État
Articles (0.8)Recherche (réf+libellé), Famille
Matériels (0.8)Recherche (libellé+S/N+parc+lot), État

API du composant

<AdvFilters
  fields={[
    { key: "q", label: "Recherche", type: "text",
      searchKeys: ["libelle", "num_serie"], placeholder: "Libellé, série…" },
    { key: "etat", label: "État", type: "select", options: ["Dispo", "Maintenance"] },
  ]}
  values={filters}
  onChange={setFilters}
/>

Intégration dans Crud

Le composant Crud accepte une nouvelle prop filterFields. Quand elle est définie, le bouton "Filtres avancés" apparaît automatiquement et le filtrage s'applique avant le tri et la pagination. C'est pourquoi étendre les filtres à une nouvelle page CRUD ne demande maintenant que 5 lignes de configuration.

6. Export PDF Statistiques NOUVEAU

Bouton Export PDF en haut à droite de la page Statistiques. Au clic, capture les 5 graphes visibles à l'instant et ouvre une fenêtre d'impression avec une mise en page A4 propre.

Approche technique

Plutôt que de regénérer les graphes (et risquer une désynchro avec ce que l'utilisateur voit à l'écran), je sérialise les SVG existants du DOM et les réinjecte dans le HTML d'impression. Tu imprimes ce que tu vois.

  • Page d'impression avec en-tête Aveho (eyebrow + titre + sous-titre avec date)
  • 5 blocs de graphes avec break-inside: avoid pour éviter les coupures en milieu de graphe
  • SVG en max-width: 100%; height: auto pour s'adapter au format A4
  • Pied de page avec date de génération

7. Recherche fulltext historique NOUVEAU

Nouveau champ de recherche dans la toolbar de la page Historique. Cherche dans toutes les colonnes en même temps :

  • Email utilisateur
  • Action (creer, modifier, supprimer, valider…)
  • Entité (patient, transfert, intervention…)
  • ID de l'entité concernée
  • Tout le contenu du JSON details (numéro de transfert, libellé patient, statut, etc.)

Filtrage côté client sur les 200 lignes déjà chargées — instantané. La recherche se combine avec les filtres existants (action, entité, période).

Exemple d'usage

Tu cherches qui a modifié le transfert TRF-1042 ? Tape "1042" dans la recherche : tu vois toutes les lignes qui mentionnent ce numéro, dans n'importe quelle colonne.

10. Procédure de mise à jour depuis Alpha 0.7

Aucun script SQL. Migration simple :

  1. Sauvegarde ton dossier C:\aveho-ec-app.
  2. Décompresse le nouveau zip par-dessus.
  3. Dans PowerShell :
    cd C:\aveho-ec-app
npm install
npm run dev
  4. Tests rapides :
    • Va sur la page Articles : clique sur l'en-tête "Libellé" → la liste se trie
    • Recliquer une seconde fois → tri inversé
    • Sur Matériels, clique Filtres avancés → tu vois recherche + état
    • Si tu as plus de 50 articles : la pagination apparaît en bas
    • Sur Statistiques, clique Export PDF → fenêtre d'impression avec les graphes
    • Sur Historique, tape "TRF" dans la recherche → seuls les évènements transferts apparaissent
  5. Mise en ligne :
    git add .
git commit -m "Aveho EC Alpha 0.8"
git push
