UX — Comportement

  1. Au chargement de la carte, l'overlay est vide (aucune catégorie active)
  2. L'utilisateur clique une catégorie → chip devient pleine + couleur
  3. Refresh automatique appelle /api/finess?bbox=...&categories=...&limit=300
  4. Les marqueurs apparaissent (ronds 28px avec emoji catégorie)
  5. Au clic sur un marqueur : popup avec nom, catégorie, adresse, téléphone, FINESS
  6. Pan/zoom de la carte → refresh auto debounced 800ms (la bbox change → nouveaux résultats)
  7. Compteur en haut : "12 résultats affichés"
  8. Bouton "Masquer tout" pour reset

⚙️ Chantier 2 — API FINESS : filtre bbox

La route /api/finess accepte maintenant un nouveau paramètre bbox :

GET /api/finess?bbox=44.5,1.4,44.7,1.7&categories=pharmacie,maison_sante&limit=300

# Format bbox : lat_sud,lng_ouest,lat_nord,lng_est

Côté serveur, le proxy traduit en filtres tabular-api officiels :

geoloc_4326_lat__greater=44.5
geoloc_4326_lat__less=44.7
geoloc_4326_long__greater=1.4
geoloc_4326_long__less=1.7

Le limit est maintenant capé à 500 (au lieu de 20) pour permettre l'affichage d'une zone dense.

Test direct sur Figeac (bbox 44.5,1.4,44.7,1.7) avec code 620 (pharmacies) : retourne 2 pharmacies (Pineau à Cœur de Causse, Floranty à St Germain du Bel Air). ✓

Nouvelles catégories ajoutées au mapping

Pour l'overlay carte, 3 nouvelles entrées dans CATEGORY_CODES :

  • pharmacie → ["620"] (uniquement officines)
  • maison_sante → ["603"] (MSP)
  • centre_sante → ["124"]

Les 5 autres réutilisent les groupes existants (ehpad, hopitaux, ssr_psy, handicap, pharma_lpp).

⚠ Note importante — Limites de FINESS pour la "ressource santé"

L'utilisateur a demandé "infirmiers, centres et autres infos" via FINESS. Tests effectués :

  • ✅ Pharmacies : 38 530 dans FINESS
  • ✅ Maisons de santé : 1 115 dans FINESS
  • ✅ Centres de santé : 3 395 dans FINESS (multidisciplinaires)
  • ❌ Cabinets infirmiers libéraux individuels : 0 dans FINESS
  • ❌ Cabinets médicaux libéraux individuels : pas dans FINESS

Les infirmiers, médecins, kinés en exercice libéral individuel sont dans le RPPS (Répertoire Partagé des Professionnels de Santé), pas dans FINESS. RPPS est accessible via une autre API (annuaire.sante.fr / data.gouv).

Pour cette version, on intègre uniquement ce que FINESS peut fournir : structures collectives (pharmacies, MSP, centres de santé, EHPAD, hôpitaux…). L'intégration RPPS sera l'objet d'une future version si besoin.

🐛 Chantier 3 — Fix complémentaire carte (display:none)

Bug latent identifié

Le div carte-leaflet-container avait display: leafletReady ? "block" : "none". Quand Leaflet essayait de mesurer ses dimensions sur un élément en display:none, clientWidth=0 → la map se créait mais sans rendu visible.

Fix

La div est maintenant toujours en display:block avec une hauteur fixe (600px). Le loader Leaflet est en position:absolute; inset:0; z-index:5 par-dessus pendant le chargement.

Couplé au fix 0.55.8 (race condition mapRef), ça garantit que :

  1. Le div existe avec une vraie taille dès le rendu initial
  2. mapRef.current est dispo immédiatement
  3. Leaflet peut mesurer correctement et créer sa map
  4. Le loader disparaît dès que leafletReady = true
