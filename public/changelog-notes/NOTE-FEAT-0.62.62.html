CSS UI ENCORE PLUS BEAU

  1. Stagger fade-in** : enfants directs des grilles [class*=grid] > .panel arrivent en cascade animation av-fade-up 400ms cubic-bezier avec délai 40ms par index (jusqu'à 8). Effet 'wow' à chaque page load. **
  2. Boutons primary glow + shine : pseudo-élément ::before avec gradient blanc 25% qui traverse au hover (left -100% → 100% en 600ms). Effet 'reflet lumineux'.
  3. Active state tactile : :active → translateY(1px) scale(.98) en 60ms, feedback haptique visuel.
  4. Effet ripple sans JS : button[data-ripple=true]:active::after étend un cercle blanc 40% jusqu'à 300px en 600ms.
  5. Cards 3D : data-3d=true hover → translateY(-4px) scale(1.005) + double shadow (navy + teal glow).
  6. Glow utility classes** : av-glow-teal/amber/coral (le coral pulse avec av-pulse-glow 2s infinite)

Utilisation
