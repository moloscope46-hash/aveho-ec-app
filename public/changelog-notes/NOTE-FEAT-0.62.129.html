ThemeProvider branché dans layout.js

🎨 injecté au plus haut du body avant tout le reste. Boot le thème personnalisé dès le mount

  1. Charge depuis localStorage immédiatement (instantané)
  2. Si user connecté, fetch structures.theme_json en async et applique (priorité haute). Les CSS variables --aveho-* sont injectées au :root. Effet : ouvre l app sur n importe quelle page, le thème personnalisé est appliqué dès le premier paint

NotifBellEnhanced (app/components/NotifBellEnhanced.js)

🔔 wrapper qui combine la cloche TopBar (bouton avec compteur badge animé) avec le nouveau NotifCenter (panel 420px à onglets). Click cloche → toggle le panel. Click outside → ferme. Refresh count auto toutes 30s + au close du panel. Animations : bell-shake 4s loop si non-lu, pulse-badge 2s sur badge compteur, fade-in 200ms sur panel. Remplace NotifBell legacy dans TopBar. Effet : la cloche garde l UX qu on connait + ouvre le centre de notifs enrichi 4 onglets

SmartInput activé sur /signalements

🤖 remplace l input titre simple par <SmartInput contextKey="signalement.titre">. Effet : à chaque saisie, l user voit suggérées les valeurs déjà saisies précédemment (ex: Lit instable, Bouton appel cassé). Sauvegarde en localStorage par contextKey. Algo de tri : count×10 + bonus si utilisé dans dernier 24h

WorkflowApproval intégré sur /achats

✅

  1. Affichage du composant dans la modal d édition (uniquement si demande existante avec id). Stepper visuel des étapes + action panel pour user autorisé
  2. Bouton Lancer workflow d approbation visible aux managers (isManager) : crée automatiquement 2 étapes (niveau 1 Cadre de santé + niveau 2 Direction) avec confirm. Cherche les roles correspondants via roles.find(r => r.nom === ...). Status pending pour chaque step

FirstLoginTour (app/components/FirstLoginTour.js)

  1. localStorage av-first-login-tour pas marqué done
  2. auth.user.created_at < 24h. 6 étapes : TopBar bienvenue → Badge rôle → NotifBellEnhanced → Dashboard widgets → Ctrl+K + Shift+Esc → Bonne découverte. Auto-start avec délai 1.5s pour laisser l UI se monter. Branché dans layout.js
