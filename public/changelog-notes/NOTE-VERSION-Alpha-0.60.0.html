🗄 1. SQL — 6 nouveaux objets DB

-- Table bilans_sav (templates)
CREATE TABLE bilans_sav (id, magasin_id, structure_id, code, nom,
  description, duree_estimee_min, icone, couleur, actif);

-- Table bilans_sav_points (5 points par bilan typiquement)
CREATE TABLE bilans_sav_points (id, bilan_id, ordre, libelle,
  type_controle ENUM('oui_non','mesure','texte','photo'),
  unite, valeur_min, valeur_max, est_obligatoire);

-- Table bilans_sav_articles (M:N rattachement)
CREATE TABLE bilans_sav_articles (bilan_id, article_id);

-- ALTER demandes_internes
ALTER TABLE demandes_internes
  ADD type_demande TEXT DEFAULT 'di',  -- 'di' | 'sav' | 'transfert'
  ADD bilan_sav_id UUID,
  ADD article_concerne_id UUID,
  ADD panne_description TEXT,
  ADD depot_source_id UUID;

-- Table sav_executions (résultats des contrôles)
CREATE TABLE sav_executions (id, demande_id, bilan_id, point_id,
  resultat, valeur_mesure, commentaire, photo_url);

-- Table droits étab → magasin
CREATE TABLE etablissements_magasins_droits (etablissement_id, magasin_id,
  droit_commande, droit_sav, droit_transfert);

📋 2. /magasin/bilans-sav — Création de bilans

🩺
Bilan annuel concentrateur O2
BSV-O2-001 · ⏱ 30 min
Bilan de contrôle obligatoire annuel sur tous les concentrateurs d'oxygène.
1 Pression sortie O2 (mesure, 2-5 bar)
2 Concentration O2 mesurée (mesure, 85-100%)
3 Niveau sonore acceptable (oui/non)
4 État du filtre (oui/non + photo)
5 Test alarme manque O2 (oui/non)
3 articles rattachés

Le magasin crée des bilans avec leurs points de contrôle (généralement 5), chaque point avec son type (✓/✗, 📏 mesure avec unité+min/max, 📝 texte, 📷 photo) et flag obligatoire. Rattachement multi-articles via grid checkboxes.

📋 3. /sav/nouvelle — EC crée une demande

3 panels guidés :

  1. Article concerné : sélecteur dans le catalogue de la structure, indique si rattaché au catalogue magasin
  2. Bilan SAV : automatiquement filtré par les bilans rattachés à l'article. Si aucun spécifique → tous les bilans actifs. Click pour sélectionner card avec icône+couleur
  3. Panne : description obligatoire, priorité normale/urgente, magasin destinataire, commentaire libre

Submit → INSERT demandes_internes avec type_demande='sav', statut='nouvelle'. Visible côté magasin dans /mobile/magasin et /magasin onglet 'SAV reçues'.

🔄 Cycle SAV complet

1️⃣ Magasin crée bilans SAV (5 points par bilan)
       ↓
2️⃣ Magasin rattache bilans aux articles
       ↓
3️⃣ EC va sur /sav/nouvelle
       → Sélectionne article (ex: concentrateur)
       → Bilans rattachés à cet article apparaissent en priorité
       → Décrit la panne + priorité
       → Submit
       ↓
4️⃣ User magasin (en mode Action Mobile) reçoit notif + badge SAV rouge
       → Tap SAV → page détail
       → Voit panne_description + bilan attaché + 5 points
       → Décide : Valider / Refuser
       → (0.60.1) Exécute le bilan : saisit chaque point (mesure/oui-non/photo)
       ↓
5️⃣ Rapport SAV généré → notif EC
