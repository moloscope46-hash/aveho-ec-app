📦 Les 5 features livrées

✅ 1. Checkbox "Est fournisseur Aveho"

Dans /etablissements-partenaires : nouvelle case à cocher (bloc teal) à la fin du formulaire avec libellé descriptif. Détection URL ?new=1&fournisseur=1 pré-coche automatiquement. Sauvegarde dans est_fournisseur.

🔍 2. Autocomplete "Article catalogue magasin"

Dans /articles édition : composant autocomplete avec debounce 200ms, filtre par est_catalogue_magasin=true, recherche libellé/reference/code, max 15 résultats. Sélectionné → affiché en chip avec ×. Sauve dans article_magasin_id.

🏪 3. Création article depuis vue Magasin

Section teal dans le form avec checkbox "Article du catalogue magasin Aveho". URL ?new=1&magasin=1 (bouton "Ajouter un article" sur /magasin → catalogue) pré-coche automatiquement est_catalogue_magasin=true.

✓ ❌ 📦 4. Page détail DI avec validation/refus/BL

Nouvelle page /demandes-internes/[id] : affiche détail DI + lignes. En mode Magasin, panneau actions teal :

  • Statut nouvelle → boutons Valider ou Refuser (motif obligatoire dans textarea)
  • Statut validée → bouton Générer le BL (crée dans bons_livraison ou pose numero_bl sur DI, statut → livrée)
  • Autre → message contextuel avec motif refus ou n° BL

🆕 5. Rôle "🏬 Utilisateur Magasin" + auto-redirect

Nouveau rôle dans /collaborateurs (teal #5a8f8f). À l'ouverture de /choix-mode après login, requête le rôle du user : si = utilisateur_magasin, force le mode Magasin et redirige direct vers /magasin sans popup.

🔄 Workflow complet

1️⃣ Admin marque un membre comme "Utilisateur Magasin" dans /collaborateurs
       ↓
2️⃣ Au prochain login, il atterrit auto sur /magasin (court-circuit popup)
       ↓
3️⃣ Il crée des articles catalogue depuis 'Ajouter un article'
       → est_catalogue_magasin pré-coché grâce à URL ?magasin=1
       ↓
4️⃣ Les EC peuvent rattacher leurs articles à un article catalogue
       via l'autocomplete dans /articles édition
       ↓
5️⃣ Les EC créent des partenaires fournisseurs (case cochée)
       → ils apparaissent dans /magasin → onglet Partenaires
       ↓
6️⃣ Les DI envoyées au magasin apparaissent dans /magasin → onglet DI
       → user magasin clique sur une DI
       → page détail → Valider / Refuser / Générer BL
