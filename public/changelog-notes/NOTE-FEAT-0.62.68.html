🗄️ module HAD complet

  1. Table had : nom, code, finess, type (généraliste/pédiatrique/périnatale/oncologie), adresse complète, responsable (nom + tel + email), capacite_lits, zone_intervention, latitude/longitude pour carte, rayon_intervention_km (défaut 30), logo_url, notes, actif
  2. 5 tables rattachements : had_etablissements (partenaire/prescripteur/support), had_vehicules, had_garages (est_principal), had_depots (est_principal), membres_had (role : medecin_coordo/cadre_ide/ide/aide_soignant/kine/secretaire/chauffeur)
  3. Colonnes ajoutées : had_id sur demandes_internes + patients + etablissements, adresse_domicile/cp_domicile/ville_domicile/latitude/longitude sur patients (pour cartes intervention domicile), est_had flag sur etablissements
  4. Vue v_had_stats : HAD avec stats agrégées (nb_collaborateurs, nb_vehicules, nb_garages, nb_etablissements, nb_depots) pour cards UI
  5. RLS : SELECT public authenticated + ALL pour la structure
  6. Démo 3 HAD : HAD du Lot (HAD-46, 35 lits, généraliste, Saint-Céré), HAD Cantal Causses (HAD-15, 22 lits, Saint-Flour), HAD Pédiatrique Sud (HAD-PED, 15 lits, Cahors). Rattachements démo : HAD du Lot partenaire de EHPAD Tilleuls + FAM Causse + prescripteur Clinique Bel Air
  7. 5 patients SSIAD basculés en HAD avec adresses domicile + coordonnées GPS pour démontrer cartes patient
