🤖 Backend / Frontend (7)

useRealtimeNotifs (lib/useRealtimeNotifs.js)

🔔 hook global qui détecte en realtime 3 événements clés et déclenche notifications natives + sons

  1. DI urgentes nouvelles : interventions where urgence in (Critique, Élevée) créées depuis le dernier check → notify type urgent
  2. Workflow approbations en attente pour moi : workflow_steps pending where approver matches user_id, role_id, ou admin → notify type info
  3. Signalements critiques : signalements where criticite in (Critique, Haute) → notify type warning. Check initial puis toutes les 60s. Branché dans TopBar via useRealtimeNotifs(true)

safeSave (lib/safeSave.js)

📡 wrapper haut-niveau pour écritures avec fallback offline. Détecte

  1. si !isOnline() → enqueue direct
  2. Erreur retournée matchant /network|fetch|timeout|failed/i → enqueue
  3. Exception du même type → enqueue. Toast info : Mode hors-ligne, action mise en file. Sera synchronisée à la reconnexion. Compatible avec lib/offlineQueue.js existant (Alpha 0.25.0). À utiliser pour les saves critiques où la résilience offline est importante

TopCollaborateursWidget

📊 Top 5 collaborateurs les + actifs sur 30j. Compte interventions par technicien_user_id. Affichage avec médailles emoji 🥇🥈🥉 puis numéros + barres progress + count actions. Empty state si pas encore d activité

TempsMoyenResolutionWidget

📊 durée moyenne des interventions résolues sur 30j (calcul (date_resolution - created_at) en heures, filtre outliers < 30j). 3 chiffres : moyenne dans card centrale gradient (32px), min (vert) et max (rouge) en grid 2 colonnes. fmtDuration : <1h=minutes, <24h=heures, >24h=jours. Empty state si aucune résolution

SmartSelect (app/components/SmartSelect.js)

🤖 composant combobox combinant input texte + dropdown options + suggestions historique

  1. Affiche les options passées en prop + entries d historique localStorage non doublonnées
  2. Filtre en temps réel à la frappe
  3. allowCustom prop pour autoriser saisie libre
  4. Distingue dans le dropdown : options vs historique avec icônes différentes (ti-list teal vs ti-history gris)
  5. Sauvegarde auto des valeurs saisies dans localStorage par contextKey
  6. Navigation clavier complète

Page /parametres/workflows

📋 interface admin complète pour gérer les templates

  1. Liste : grid cards 320px avec icône+couleur+nom+type ressource (badge coloré) + description + steps en chips (1. Cadre de santé, 2. Direction...)
  2. Modal création/édition : nom, description, type ressource (4 options), icône input + couleur color picker
  3. Builder d étapes : ronds numérotés gradient + input role_label + bouton trash. Bouton +Ajouter une étape dashed teal. Reorder automatique step_order au remove

PlanningCalendar drag&drop

📅 refonte MonthGrid avec gestion drag&drop HTML5

  1. Events draggable : draggable={true} + onDragStart sets dataTransfer.setData(application/json, JSON.stringify(event)). cursor: grab
  2. Days droppable : onDragOver preventDefault + change background. onDragLeave restore. onDrop calcule nouvelle date (préserve heure originale) + update DB selon préfixe id (intv-→interventions, evt-→planning_events, tour-→tournees)
  3. Toast success Déplacé au + reload page pour refresh complet
