Résumé

La 0.30.0 livre le dashboard collectif RGPD tant attendu pour les DPO et la direction. Une vue d'ensemble lisible et exportable de l'état de conformité de la collectivité, avec graphiques natifs (zéro dépendance JS lourde ajoutée) et export PDF prêt pour reporting.

De la donnée brute aux décisions actionnables. Avant la 0.30, les consentements étaient consultables un par un dans /consentements. Maintenant, /statistiques-rgpd répond directement aux questions du DPO : "combien d'expirations dans 30j ?", "quel établissement a le meilleur taux de signature ?", "quelles finalités sont les plus refusées ?", "comment évolue la conformité mois après mois ?".

1. Vues SQL d'agrégation

v_stats_rgpd_global

Compteurs globaux pour KPIs : actifs, refus, archives, total, signés ce mois / mois dernier (pour tendance), taux de refus calculé, vérifications QR (valides / invalides).

v_stats_rgpd_par_mois

12 derniers mois × structure (génération via generate_series), avec compteurs signés / refusés / archivés. Utilisée pour le graphique mensuel.

v_stats_rgpd_par_etab

Par établissement : signés, refus, archivés, à renouveler dans 30j, déjà expirés. Trié par nb_signes desc.

v_stats_rgpd_expirations

4 tranches : 30j, 31-60j, 61-90j, déjà expirés.

v_stats_rgpd_finalites

Popularité des finalités via jsonb_array_elements_text(finalites_acceptees). Combien de fois chaque finalité a été acceptée.

2. Composants graphiques SVG natifs

Stratégie : pas de dépendance externe (Recharts, Chart.js…). Tous les graphes sont en SVG natif, légers et maîtrisés. 4 composants exposés dans app/Charts.js :

<BarChart>

<BarChart 
  data={[
    { label: "30j", value: 12, color: "#EF9F27" },
    { label: "31-60j", value: 8, color: "#7CC8C8" },
  ]}
  height={180}
/>

Barres verticales avec valeur au-dessus, label en-dessous, tooltips natifs SVG (<title>).

<StackedBarChart>

Barres empilées avec légende auto. Utilisé pour le graphique mensuel signés (vert) / refusés (rouge).

<DonutChart>

Anneau avec total au centre + légende latérale avec valeurs et pourcentages. Calculs trigonométriques natifs pour les arcs SVG.

<Gauge>

Petite jauge horizontale fine. Réutilisée pour le taux de refus, le taux de vérifs QR valides, et le top finalités.

3. Page /statistiques-rgpd

Restriction admin

La page n'est accessible qu'aux utilisateurs avec :

  • Permission gerer_roles
  • OU permission manage_collectivite
  • OU rôle système admin
  • OU rôle nommé Administrateur

Sinon : message "Cette page est réservée aux administrateurs."

Sections affichées

  1. 6 KPIs globaux en KpiRow : Consentements actifs, Refus, Taux de refus %, Signés ce mois, Archivés, Vérifications QR
  2. Panneau Tendance : ce mois vs mois dernier avec icône trending-up/down et % d'évolution
  3. Évolution mensuelle : StackedBarChart 12 mois (signés vert + refus rouge)
  4. Répartition globale : DonutChart signés / refus / archivés + légende
  5. Indicateurs qualité : 2 jauges (taux refus, % vérifs QR valides) + note "< 10% habituel"
  6. Expirations à venir : BarChart 30j/31-60j/61-90j/expirés + encart rouge si déjà expirés
  7. Performance par établissement : tableau avec colonnes signés / refus / archivés / à renouveler / expirés (couleurs conditionnelles)
  8. Top finalités acceptées : 10 jauges avec libellés mappés depuis FINALITES

4. Export PDF brandé

Chargement dynamique de jsPDF

Pour rester cohérent avec la stratégie existante (lib/consentPdf.js), jsPDF est chargé depuis le CDN au moment de l'export, pas bundlé. Pas d'ajout de dépendance lourde au package.json.
