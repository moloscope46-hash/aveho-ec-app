📋 1. SQL — refonte articles + table TVA paramétrable

Migration MASSIVE : nouvelle table tva_taux avec comptes comptables complets + ALTER TABLE articles avec ~50 nouvelles colonnes pour transformer la table en vrai référentiel catalogue PSAD/FBM.

CREATE TABLE IF NOT EXISTS tva_taux (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  structure_id UUID NOT NULL,
  code TEXT NOT NULL,            -- "NORMAL", "REDUIT", ...
  libelle TEXT NOT NULL,
  taux NUMERIC(5,2) NOT NULL,
  -- COMPTA
  compte_vente TEXT,             -- ex: "707100"
  compte_achat TEXT,             -- ex: "607100"
  compte_tva_collectee TEXT,
  compte_tva_deductible TEXT,
  code_analytique TEXT,
  est_defaut BOOLEAN, actif BOOLEAN,
  UNIQUE (structure_id, code)
);

ALTER TABLE articles
  -- Codes-barres
  ADD COLUMN code_barre TEXT, code_barre_type TEXT,
  ADD COLUMN code_lpp TEXT, code_acl TEXT, code_ucd TEXT,
  -- Logistique
  ADD COLUMN unite TEXT DEFAULT 'unité', conditionnement INTEGER DEFAULT 1,
  ADD COLUMN poids_g NUMERIC(10,2), volume_ml NUMERIC(10,2),
  ADD COLUMN longueur_cm NUMERIC, largeur_cm NUMERIC, hauteur_cm NUMERIC,
  -- Tarifs
  ADD COLUMN prix_achat_ht NUMERIC(10,4), prix_vente_ht NUMERIC(10,4),
  ADD COLUMN prix_vente_ttc NUMERIC(10,4),
  ADD COLUMN tva_taux_id UUID REFERENCES tva_taux(id),
  ADD COLUMN tva_pct NUMERIC(5,2), marge_pct NUMERIC(5,2),
  -- Tracabilité
  ADD COLUMN gere_lot BOOLEAN, gere_serie BOOLEAN, gere_peremption BOOLEAN,
  -- Rattachements
  ADD COLUMN fournisseur_principal_id UUID,
  ADD COLUMN etablissement_partenaire_id UUID,
  ADD COLUMN pharmacie_id UUID REFERENCES pharmacies(id),
  ADD COLUMN fabricant TEXT, marque TEXT, modele TEXT,
  -- Classifications DM
  ADD COLUMN classe_dm TEXT, sterile BOOLEAN, usage_unique BOOLEAN,
  ADD COLUMN dispositif_medical BOOLEAN;
  -- + 25 autres colonnes...

📑 4. Modal d'édition à 7 onglets

  • Général : référence, libellé, famille, classe DM, description, notes internes, flags (actif/DM/stérile/usage unique)
  • Codes-barres : code-barre principal + bouton Générer EAN13 avec aperçu SVG + type + LPP/ACL/UCD
  • Logistique : unité, conditionnement (+libellé), poids, volume, L/l/H, qté carton/palette, stock min/max, délai appro
  • Tarifs & TVA : PA HT / PV HT / devise / select TVA paramétrable + calcul TTC + marge LIVE
  • Tracabilité : 3 cards toggles (🏷 lot / 🔢 série / ⏱ péremption) + durée de vie standard
  • Rattachements : marque/modèle/fabricant + étab partenaire + pharmacie + count matériels avec lien
  • Compta : override comptes vente/achat/analytique + récap des comptes hérités du taux TVA
