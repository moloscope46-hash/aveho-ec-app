🔁 Le popup choix-mode s'affiche maintenant à chaque loginAvant : bypassé dès qu'un mode était mémorisé · Après : toujours visible + bandeau "Continuer" rapide

Date : 6 juin 2026 Version : v0.58.90-alpha SQL : aucun Type : Fix UX

🐛 Le problème

Quand tu cliquais "Démarrer en Logiciel" dans le profil (ou ailleurs), localStorage mémorisait av-launch-mode='desktop'. À toutes les connexions suivantes, l'app détectait ce mode et te redirigeait direct sur /accueil sans afficher le popup. Cédric voulait que le popup soit toujours visible à chaque login pour pouvoir basculer rapidement entre les 2 modes.

🔧 Le fix

// app/login/page.js
- router.push("/vue-globale");
+ router.push("/choix-mode");  // popup choix mode après login

// app/accueil/page.js
- useEffect → redirige vers /choix-mode si pas de mode  (DÉSACTIVÉ)

✨ Bonus UX : bandeau "Continuer rapide"

Sur le popup choix-mode, si tu as déjà un mode mémorisé, ce bandeau apparaît en haut :

Dernier mode utilisé : 💻 Logiciel → Continuer avec ce mode

Un seul click suffit pour repartir comme avant — sans devoir re-choisir entre les 2 grandes cartes. Si tu veux changer, les 2 cartes Logiciel / Mobile sont toujours là en-dessous.

🎯 Comportement attendu

  1. Tu te connectes → tu vois toujours le popup avec les 2 cartes (Logiciel teal / Action Mobile ambre)
  2. Si tu as déjà choisi avant : bandeau en haut avec ton mode précédent + bouton "Continuer avec ce mode"
  3. Tu peux soit cliquer ce bouton (rapide), soit changer de mode en cliquant l'autre carte
  4. Ton nouveau choix est mémorisé pour le prochain login (mais le popup s'affichera quand même)
