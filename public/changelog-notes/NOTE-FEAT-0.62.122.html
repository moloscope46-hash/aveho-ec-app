Composant RoleBadge

📦 (app/components/RoleBadge.js) : affiche le rôle avec icône + couleur personnalisée. 4 variants : compact (pill avec icône + nom), full (large avec description), minimal (texte coloré), icon (juste l icône dans rond gradient). 3 tailles : sm/md/lg. Hover effects : scale 1.08 + rotate -3deg pour icon, translateY + shadow pour compact. Animation pulse subtle ::after halo 3s ease-in-out infinite. Cliquable optionnellement avec onClick

Déploiement RoleBadge TopBar

🎯 badge variant=icon size=md affiché entre les sélecteurs et NotifBell. Click → navigation vers /utilisateurs. Tooltip sur le nom du rôle. Couleur + icône du rôle (auth.role.icone et auth.role.couleur) déjà disponibles depuis 0.62.121

Déploiement RoleBadge Page Utilisateurs

🎯

  1. Liste membres : RoleBadge icon à côté du select de changement de rôle, dans une div flex gap 6 avec le select à flex 1
  2. Tableau rôles : RoleBadge icon + nom bold + label système éventuel + badge module count avec couleur du rôle (au lieu du fontWeight 600 simple)

FoldableFilters JSX sur /materiels

📦 juste après le toggle Liste/Tuiles. searchPlaceholder=Rechercher un matériel (n° série, parc, libellé…). activeFiltersCount=search?1:0. storageKey=materiels. Children : message info sur la recherche

FoldableFilters JSX sur /signalements

📦 entre le pattern onglets popup et le Panel. searchPlaceholder=Rechercher un signalement (titre, description, auteur…). activeFiltersCount compte fType + fStatut + fCategorie + search. onResetAll reset tous les filtres dont search. Children : select Type + select Statut (les filtres existants extraits du toolbar)
