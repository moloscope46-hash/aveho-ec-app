🐛 1. Fix bug menu profil qui débordait

Bug : sur certaines pages, le menu profil débordait sous l'écran et on ne voyait que "Déconnexion" en bas. Fix : (a) max-height + overflow-y: auto pour scroll interne, (b) auto-flip du menu vers le haut si pas assez d'espace en bas (détecté via getBoundingClientRect()).

// 0.58.55 - JS detection à l'ouverture
useEffect(() => {
  if (!open || !ref.current) return;
  const rect = ref.current.getBoundingClientRect();
  const spaceBelow = window.innerHeight - rect.bottom;
  const spaceAbove = rect.top;
  // ~380px estimé pour le menu
  setFlipUp(spaceBelow < 380 && spaceAbove > spaceBelow);
}, [open]);

// CSS
.um-sheet { max-height: calc(100vh - 110px); overflow-y: auto; }
.um-sheet.um-sheet-up {
  top: auto;
  bottom: calc(100% + 10px);  /* flip vers le haut */
}

☁️ 4. Partage objectifs équipe

SQL à exécuter dans Supabase :

-- A) user_goals : ajout team_id + shared
ALTER TABLE user_goals
  ADD COLUMN IF NOT EXISTS team_id UUID REFERENCES equipes(id) ON DELETE SET NULL,
  ADD COLUMN IF NOT EXISTS shared BOOLEAN DEFAULT FALSE;

-- Nouvelle policy RLS : lecture des objectifs partagés
CREATE POLICY "Read own or shared goals" ON user_goals FOR SELECT
  TO authenticated
  USING (
    user_id = auth.uid()
    OR (shared = TRUE AND team_id IS NOT NULL AND EXISTS (
      SELECT 1 FROM membres_equipe
      WHERE equipe_id = user_goals.team_id AND user_id = auth.uid()
    ))
  );

-- B) partenaires_rpps : badge collaborateur
ALTER TABLE partenaires_rpps
  ADD COLUMN IF NOT EXISTS est_collaborateur BOOLEAN DEFAULT FALSE,
  ADD COLUMN IF NOT EXISTS user_id UUID REFERENCES auth.users(id);
