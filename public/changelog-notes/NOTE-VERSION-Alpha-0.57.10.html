📦 Fix 1 — Extraction NoteModal (-343 lignes page.js)

La modale qui affiche les notes HTML d'une version (avec highlight des mots-clés et navigation F3/n/p) faisait ~250 lignes de JSX + 2 useEffects + 5 fonctions helpers, tout dans page.js. Extraction en 2 fichiers :

app/changelog/NoteModal.js (Client Component)

  • State interne contrôlé via props { noteModal, setNoteModal, onClose }
  • useEffect scroll auto vers le match courant (requestAnimationFrame double pour pas reflow)
  • useEffect raccourcis Escape (ferme) + F3 / n (suivant) + Shift-F3 / p (précédent)
  • Style navBtn défini localement
  • Rendu JSX complet : header avec couleur par kind, navigation matches, bandeau search, contenu HTML scopé, bouton télécharger
  • Lazy-loadé depuis page.js via next/dynamic({ ssr: false })

app/changelog/lib/note-helpers.js (helpers purs)

  • STOPWORDS_FR : Set de 70+ mots vides français
  • scopeHtml(fullHtml) : préfixe .cl-note-scope sur les sélecteurs CSS de la note pour ne pas écraser la page parent
  • extractKeywords(text) : tokenise + filtre stopwords + garde mots ≥4 chars + versions + acronymes
  • highlightInHtml(html, keywords) : tokenise alternativement les tags et le texte pour éviter de matcher dans les attributs, injecte des <mark class="cl-match">
  • escapeRegex(s) : échappe les caractères spéciaux d'un mot-clé

page.js (réduit)

fetchNoteHtml() + openNote() restent dans page.js (utilisent setNoteModal du state local + noteCacheRef). Mais les helpers et le JSX sont externalisés.

🧹 Fix 2 — Nettoyage 69 imports zombies dans 50 fichiers

Un script Python a audité tous les import { X, Y } from "..." dans app/ et lib/, vérifié que chaque nom est utilisé ailleurs dans le fichier (via word boundary regex), et retiré les noms non utilisés.

Logique du script

// Pour chaque fichier .js dans app/ et lib/ :
for each fichier:
  parse les imports `import { X, Y, Z } from "..."`
  for each nom (X, Y, Z) dans l'import:
    rest = fichier sans cette ligne d'import
    if /\bnom\b/.test(rest):  # word boundary
      keep nom
    else:
      remove nom
  
  if all names removed:
    remove l'import entièrement (remplace par commentaire)
  else if some removed:
    reconstruct l'import avec uniquement les noms gardés
