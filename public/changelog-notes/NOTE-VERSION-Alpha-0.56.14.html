🎨 Login : boutons biométriques toujours visibles

Avant la 0.56.14, les boutons "Détection faciale" et "Empreinte" n'apparaissaient que si la méthode était déjà activée pour cet email. Confusion garantie pour les nouveaux utilisateurs qui ne savaient pas que la biométrie existait.

Maintenant : 2 boutons TOUJOURS affichés (si WebAuthn supporté)

Avec état grisé + tooltip explicatif si non utilisable :

🔒 Détection faciale › actif

🔒 Détection faciale ⓘ grisé avec raison

3 raisons possibles de désactivation :

  1. "Ton appareil ne supporte pas la biométrie (ou refusée)"
  2. "Renseigne d'abord ton email"
  3. "Pas encore activée pour cet email — connecte-toi avec mot de passe puis active dans ton profil"

Nouveau composant BioButton réutilisable avec props method/icon/label/busy/bioAvailable/enabled/email/onClick/color. Le bouton garde son icône (ti-face-id violet / ti-fingerprint bleu) avec chevron › si actif, info-circle ⓘ si grisé.

📥 Dump RPPS : liens directs ANS

Sur la page /admin/rpps-dump, ajout d'un panneau bleu avec 2 boutons :

  • 🔵 Ouvrir la page d'extractions ANS → ouvre annuaire.sante.fr/web/site-pro/extractions-publiques
  • 🟢 Télécharger PS_LibreAcces (CSV ZIP) → lance directement le download via l'URL portlet ANS (telechargerCNOM)

Note : ZIP ~150 Mo compressé, CSV ~500 Mo décompressé.

🛠 Google Reviews sync : diagnostic enrichi

Route /api/google-reviews/sync : parse le JSON du body d'erreur et renvoie un champ hint avec un message d'aide contextuel.

Hints supportés

  • API_KEY manquante → "Variable GOOGLE_PLACES_API_KEY non configurée côté Edge Function. Va dans Supabase → Settings → Edge Functions → Secrets et ajoute-la."
  • 404 / not_found → "L'Edge Function n'est peut-être pas déployée. Lance : supabase functions deploy sync-google-reviews"
  • Timeout → "Lance avec etablissement_id spécifique pour tester"

Le hint est affiché en sous-bloc italique avec icône 💡 dans la page Admin → Avis Google sous le message d'erreur.
