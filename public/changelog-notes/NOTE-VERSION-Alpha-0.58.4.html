👤 Composant Avatar

Génère un avatar circulaire ou rounded avec INITIALES (2 lettres max) en cas d'absence d'image. Couleur = gradient déterministe sur 8 (teal/blue/terra/amber/violet/green/red/navy) via hash du nom → même utilisateur = même couleur partout dans l'app.

API

// Simple
<Avatar name="Cédric Mignot" size={48} />

// Avec statut
<Avatar name="Hugo Martin" size={40} status="online" />

// Avec image + halo glow
<Avatar src="/photo.jpg" name="Yassir" size={48} ring />

// Group d'avatars avec overflow
<AvatarGroup
  users={[
    { name: "Cédric Mignot" },
    { name: "Hugo Martin" },
    { name: "Yassir Aouaj" },
    { name: "Corentin David" },
    { name: "Julien Bertrand" },
  ]}
  max={3}
  size={32}
/>
// Affiche : 3 avatars empilés + bulle "+2"
