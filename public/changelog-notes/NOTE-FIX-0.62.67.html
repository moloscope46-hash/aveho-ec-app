🐛 Fix bug (3)

Fix Tabs onglets qui sortent de la bulle

📑 composant Tabs (style pills) passait display: inline-flex sans wrap → 14 onglets sortaient horizontalement. Solution : display: flex + flex-wrap: wrap + maxWidth: 100% + radius standard (au lieu de full-rounded qui jure avec le wrap). Container parent passe aussi en display: flex (au lieu de inline-flex). Maintenant les onglets s'enroulent proprement sur plusieurs lignes si trop nombreux

Fix embed dans onglet : contenu reste dans la bulle parente

🎨 ajout CSS strict .av-tab-content { width: 100%; max-width: 100%; overflow-x: hidden } + contraintes spécifiques sur .bg-dark, .wrap, .page-content (perdent leur padding + max-width). Tableaux : max-width: 100%; overflow-x: auto. Force [role=tablist] { flex-wrap: wrap !important }. La page embed ne déborde plus jamais visuellement de son onglet parent

Fix PWA install banner masqué en mode magasin

📲 le PwaInstallPrompt avait z-index: 1000, et l'OfflineSyncIndicator créé en 0.62.66 avait z-index: 9999 en bas-droite → masquait visuellement le bandeau PWA centré bottom sur les écrans étroits. Solutions

  1. PWA prompt monte à z-index: 10000 (au-dessus de tout)
  2. OfflineSyncIndicator déplacé en TOP-droite (top: 70px right: 12px) au lieu de bottom-droite — n'interfère plus avec le PWA prompt en bas. Z-index abaissé à 9000 (sous le PWA prompt). Note : si Cédric ne voit toujours pas le prompt, c'est que Chrome a stocké un refus récent. localStorage av-pwa-dismissed peut être nettoyé via DevTools Console : localStorage.removeItem('av-pwa-dismissed') puis F5

ℹ Info / Tâche restante (2)

Audit redirection cachée vers /etablissement

🔍 recherche exhaustive de router.push, router.replace, useEffect redirects, middleware.ts, useAuth.js guards. Résultat : AUCUNE redirection automatique cachée trouvée vers /etablissement. Tous les router.push('/etablissement...') sont des actions UTILISATEUR explicites (clic sur tuile, clic sur lien Établissements partenaires, etc.). Si Cédric ressent une redirection : c'est probablement (a) un effet de transition CSS qui donne l'impression de bascule, ou (b) un click involontaire sur un breadcrumb ou tuile
