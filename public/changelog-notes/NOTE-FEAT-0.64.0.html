TVScreenNav (app/components/TVScreenNav.js)

🎯 composant de navigation entre écrans TV. Features

  1. Grosses flèches gauche/droite (80px) fixes centrées vertical avec backdrop-filter blur
  2. Dots de navigation en bas centré avec dot actif élargi + nom écran courant + position N/4
  3. Navigation clavier : ← / → / touches 1-4 pour switch direct
  4. Auto-rotation via param URL ?auto=15 → barre progression haute + switch auto au prochain écran
  5. Conservation params URL (etab, refresh) entre les écrans. Hover : transform scale 1.08 + bordure teal
