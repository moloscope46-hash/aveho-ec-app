🤖Backend / Frontend (5 chantiers)

  • 🐛 Fix erreur 400 sur /magasin/tournees : la syntaxe .or(statut.eq.X,statut.eq.Y,date_tournee.gte.Z) plantait avec un 400 (PostgREST n'aime pas les - de date dans un OR). Fix : remplacé par .in('statut', ['en_cours','planifiee','a_faire']) + filtre client t.statut === 'en_cours' || t.date_tournee >= today. Appliqué dans TourneesMap.js ET app/carte/page.js
  • 🐛 Fix collaborateur user courant invisible : si l'user existe dans auth.users (Supabase) mais a AUCUNE ligne dans membres_structure, le code 0.62.7 ne le trouvait pas. Fix : on crée une 'ligne virtuelle' depuis auth.user.user_metadata (prénom, nom, email) avec flag _virtual: true. console.warn affiche l'anomalie pour debug
  • 🎨 Icônes Administratif + Infirmière fixées : ti-nurse et ti-briefcase ne sont pas dans la version Tabler Icons actuelle. Remplacé par ti-medical-cross (infirmière) et ti-id-badge-2 (administratif) qui existent dans toutes les versions
  • 📦 /depots : sélecteur magasin TOUJOURS visible : avant le sélecteur n'apparaissait QUE si type === 'deporte'. Maintenant visible pour tous types de dépôts. La colonne depots.magasin_id était déjà créée en 0.62.10. Label 'Magasin rattaché'
  • 🏥 /etablissement : nouvel onglet 'Magasins rattachés' : aux côtés des onglets Aperçu/Véhicules/Dépôts. Liste les magasins_rattachements où etablissement_id = courant. Cards avec nom magasin + ville + bât/svc/dépôt précis (s'il y en a) + notes. Bouton 'Rattacher un magasin' ouvre modal avec select des magasins dispo (filtre ceux déjà rattachés). À l'ajout : notification automatique envoyée aux membres du magasin (insert in notifications pour tous les membres_structure.eq(magasin_fournisseur_id))
