✨ PageHero : prop particles

Nouvelle prop particles qui ajoute un canvas de particules en background du PageHero, avec couleur déduite du variant.

// 0.58.22 - PageHero variant-aware particles
<PageHero
  variant="violet"        // → particules violettes (rgba 122,111,176,.65)
  particles               // active le canvas (false par défaut)
  particlesCount={20}     // 20 particules par défaut
  title="Statistiques RGPD"
/>

<PageHero
  variant="terra"         // → particules terra (rgba 201,134,127,.55)
  particles
  particlesCount={30}
  title="Patients hospitalisés"
/>

// Couleurs déduites :
// teal  → rgba(124, 200, 200, 0.55)
// blue  → rgba(124, 200, 200, 0.55)
// violet → rgba(122, 111, 176, 0.65)
// terra → rgba(201, 134, 127, 0.55)
// amber → rgba(239, 159, 39, 0.55)

🎬 Page transitions slide-in direction-aware

Détection forward/back via history stack interne. Slide depuis la droite si forward, depuis la gauche si back.

// 0.58.22 - PageTransition direction-aware
const historyStackRef = useRef([pathname]);

useEffect(() => {
  const stack = historyStackRef.current;
  const previousIndex = stack.lastIndexOf(pathname);
  let dir = 'forward';

  if (previousIndex >= 0 && previousIndex < stack.length - 1) {
    dir = 'back';  // ← l'user revient en arrière
    historyStackRef.current = stack.slice(0, previousIndex + 1);
  } else {
    historyStackRef.current = [...stack, pathname];  // nouvelle route
  }
  setDirection(dir);
}, [pathname]);

const animName = direction === 'back'
  ? 'av-page-slide-in-left'   // depuis la gauche
  : 'av-page-slide-in-right'; // depuis la droite

/* CSS */
@keyframes av-page-slide-in-right {
  from { opacity: 0; transform: translateX(20px); }
  to   { opacity: 1; transform: translateX(0); }
}
@keyframes av-page-slide-in-left {
  from { opacity: 0; transform: translateX(-20px); }
  to   { opacity: 1; transform: translateX(0); }
}
