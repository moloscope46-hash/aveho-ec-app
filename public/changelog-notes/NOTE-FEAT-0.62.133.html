🤖 Backend / Frontend (5)

Auto-trigger workflow templates dans /achats

⚡ à chaque insert d achat, code de détection après save

  1. Calcule totalMontant = sum (quantite × prix_unitaire) sur formLignes
  2. Fetch listTemplatesForResource(achat, structureId)
  3. Boucle templates : filtre auto_trigger=true ET conditions matchant (montant_min, montant_max, urgent)
  4. Premier match → applyTemplate(template, cmdId) + toast info Workflow X déclenché automatiquement. Try/catch pour ne pas bloquer le save si erreur

PlanningCalendar : EventEditModal au click

📅

  1. State editEvent dans le composant principal
  2. Passage onEventClick={setEditEvent} aux 3 grids (Month/Week/Day)
  3. Events ont maintenant onClick={(ev) => { ev.stopPropagation(); onEventClick?.(e); }} en plus du drag&drop, cursor: pointer
  4. EventEditModal : modal fixed inset 0 avec backdrop blur. Header gradient color de l event + icône + type. Champs titre (lecture seule pour interventions/tournées) + description + datetime-local.
