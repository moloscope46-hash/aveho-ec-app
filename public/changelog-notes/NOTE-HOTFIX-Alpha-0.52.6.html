Correction CSS

Ajout d'un padding par défaut à .modal + reset conditionnel via :has() (CSS Selectors Level 4, supporté dans tous les navigateurs modernes depuis 2024) :

.modal {
  /* ... */
  padding: 22px;  /* Alpha 0.52.6 : padding interne par défaut */
}

/* Si la modale a sa propre structure header/body/footer,
   retirer le padding parent pour que ces enfants gèrent leur propre padding */
.modal:has(> .modal-head),
.modal:has(> .modal-body),
.modal:has(> .modal-foot) {
  padding: 0;
}

/* Fallback pour vieux navigateurs sans :has() */
.modal-structured {
  padding: 0 !important;
}

/* Sur mobile, padding plus compact */
@media (max-width: 640px) {
  .modal {
    padding: 16px;
  }
}

Pourquoi cette approche est sûre

Le pseudo-sélecteur :has() permet de cibler une modal en fonction de ses enfants directs. Donc :

  • Les 3 modales sans .modal-body (notre cible) reçoivent padding: 22px ✓
  • Les 11 autres avec .modal-body/.modal-head/.modal-foot reçoivent padding: 0 sur le parent (zero double-padding) ✓
  • Sur mobile, le padding parent passe à 16px (plus compact)
  • Fallback : si une vieille version navigateur ne supporte pas :has(), on peut ajouter manuellement className="modal-structured" pour forcer le reset

Support :has() en mai 2026 : Chrome 105+, Firefox 121+, Safari 15.4+, Edge 105+ — couvre 95%+ des users.
