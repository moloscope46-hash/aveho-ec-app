🎨 Fix bulles pathologies

Avant : grid minmax(280px, 1fr) faisait s'étirer une seule bulle sur toute la largeur. Après : minmax(280px, 320px) + justifyContent: 'start' → les cards font 280-320px max, alignées à gauche.

✅ Établissement OBLIGATOIRE

Le sélecteur Établissement est maintenant toujours visible, marqué d'une étoile *, et le passage à l'étape 2 est bloqué si vide :

  • Bordure verte si rempli
  • Bordure rouge si vide + message ⚠ "Obligatoire pour créer le patient"
  • Bouton "Suivant" affiche une alerte en haut + scroll vers le haut au lieu de naviguer

👨‍⚕️ Section "Médecin & Pathologie"

Nouvelle section qui apparaît dès l'étape 1 (si pathologies/collaborateurs ont été créés) :

  • Pathologie principale : sélecteur dans le référentiel /pathologies (préfixé du code : [PERF], [PPC], [OXY]...)
  • Collaborateur référent : sélecteur filtré automatiquement par service sélectionné. Si aucun collab du service → message d'info "⚠ Aucun collaborateur rattaché à ce service" avec lien vers /collaborateurs
