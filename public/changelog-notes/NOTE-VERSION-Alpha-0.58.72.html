🏭 Fournisseurs multi-sources avec prioritaire

Un article peut avoir plusieurs fournisseurs (pharmacies, partenaires, fournisseurs directs) avec des prix d'achat différents. Un seul peut être marqué prioritaire (contrainte UNIQUE garantie par index partial PostgreSQL).

🏷️ Tags articles (comme matériels) + surcharges prix

Table tags_article parallèle à tags_materiel. Chaque tag peut surcharger les prix : surcharge_prix_vente_pct (+/-%), prix_vente_fixe (override absolu), surcharge_prix_location_pct, prix_location_jour_fixe, prix_location_mois_fixe.
