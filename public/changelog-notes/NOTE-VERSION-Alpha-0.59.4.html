🩹 HOTFIX SQL critique : colonnes chambre_id manquantes + payload ULTRA-minimal défensifTes 400 dans la console viennent de colonnes absentes en DB. Ce SQL + ce code défensif débloquent tout.

Date : 6 juin 2026 Version : v0.59.4-alpha SQL : fix-missing-columns-0.59.4.sql Type : Hotfix critique

🐛 Les erreurs que tu as vues

PGRST204: Could not find the 'chambre_id' column of 'patients' in the schema cache
patients?select=chambre_id&structure_id=...&chambre_id=not.is.null → 400
materiels?select=...&chambre_id=eq.b0ecb317-... → 400
articles?select=...&structure_id=eq.aaaaaaaa-... → 400
services?select=id,nom,batiment_id → 400

Cause : les colonnes chambre_id, service_id, structure_id, batiment_id ne sont pas toutes présentes en DB. Les migrations 0.58.81 / 0.58.85 / 0.58.99 / 0.59.0 auraient dû les créer, mais elles ne sont pas toutes appliquées chez toi.

🔧 La fix : 2 actions

1️⃣ Code défensif (déjà dans le zip)

Payload patient en 3 niveaux :

  1. Full avec tous les champs (chambre_id, service_id, allergies, etc.)
  2. Minimal avec chambre_id (si full plante)
  3. ULTRA-minimal sans chambre_id (juste structure_id, nom, prenom, created_by) — fallback si même chambre_id n'existe pas

Si niveau 3 marche : alert "Patient créé en mode ULTRA-minimal. Applique fix-missing-columns-0.59.4.sql"

2️⃣ SQL fix idempotent

-- Toutes les colonnes manquantes en ADD COLUMN IF NOT EXISTS

ALTER TABLE patients
  ADD COLUMN IF NOT EXISTS chambre_id UUID,
  ADD COLUMN IF NOT EXISTS service_id UUID,
  ADD COLUMN IF NOT EXISTS etablissement_id UUID,
  ADD COLUMN IF NOT EXISTS collaborateur_id UUID,
  ADD COLUMN IF NOT EXISTS pathologie_id UUID,
  ADD COLUMN IF NOT EXISTS allergies TEXT,
  ADD COLUMN IF NOT EXISTS antecedents TEXT,
  ADD COLUMN IF NOT EXISTS traitements TEXT,
  ADD COLUMN IF NOT EXISTS notes TEXT,
  ADD COLUMN IF NOT EXISTS gir INTEGER,
  ...

ALTER TABLE materiels
  ADD COLUMN IF NOT EXISTS chambre_id UUID,
  ADD COLUMN IF NOT EXISTS service_id UUID;

ALTER TABLE articles
  ADD COLUMN IF NOT EXISTS structure_id UUID,
  ADD COLUMN IF NOT EXISTS code TEXT,
  ADD COLUMN IF NOT EXISTS libelle TEXT,
  ...

-- + Indexes appropriés
