Hotfix 0.55.10 — Fix 502 carte FINESS (page_size 200 + garde-fou bbox) Trois fixes empilés : limite page_size de tabular-api, garde-fou zone trop large, et proxy qui ne crash plus en 502

Date : 31 mai 2026 Version : v0.55.10-alpha Type : Hotfix prod Tests : 944 verts
🐛 page_size 300 → 200 (max tabular) ⚠ Garde-fou bbox > 5°lat / 6°lng 🛡 Proxy renvoie 200 vide au lieu de 502 🚀 Carte FINESS fonctionnelle en prod

🐛 Diagnostic — Pourquoi 502 répétés

Symptôme

Sur la 0.55.9 livrée la veille, console F12 montrait :

api/finess?bbox=...&categories=pharmacie&limit=300 : HTTP 502 (Bad Gateway)
api/finess?bbox=...&categories=maison_sante&limit=300 : HTTP 502
api/finess?bbox=...&categories=...&limit=300 : HTTP 502

Tous les fetch FINESS retournaient 502, donc la carte restait sans marqueurs.

Test direct sur tabular-api.data.gouv.fr

page_size=50  → HTTP 200, 133 555 bytes ✓
page_size=100 → HTTP 200, 266 311 bytes ✓
page_size=150 → HTTP 200, 399 277 bytes ✓
page_size=200 → HTTP 200, 532 646 bytes ✓
page_size=300 → HTTP 400 "Page size exceeds allowed maximum: 200" ✗

Cause : tabular-api limite page_size à 200. Notre code envoyait 300. Tabular renvoyait 400. Notre proxy levait une exception → Vercel renvoyait 502.

✅ Les 3 fixes

Fix 1 — limit capé à 200

// app/api/finess/route.js
const limit = Math.min(Number(searchParams.get("limit") || 10), 200);

// app/carte/page.js
fetch(`/api/finess?...&limit=200`)  // au lieu de 300

Fix 2 — Garde-fou bbox trop large

Quand l'utilisateur est dézoomé sur toute la France (latDelta=10°, lngDelta=15°), même avec limit=200 on aurait des résultats incomplets ou problèmes de perf. On bloque côté carte :

if (latDelta > 5 || lngDelta > 6) {
  setFinessCount(-1);  // signal "zone trop large"
  return;  // pas de fetch
}

UI : chip orange "🔍 Zoome plus (zone trop large)" remplace le compteur.

Fix 3 — Proxy plus robuste

Si tabular-api renvoie 400 (page_size trop grand) ou autre, on logge côté serveur mais on renvoie un 200 vide côté client au lieu de 502. Évite le crash visible du SW.

if (!res.ok) {
  console.warn(`[FINESS proxy] tabular-api HTTP ${res.status}: ${detail}`);
  return new Response(
    JSON.stringify({ error: ..., results: [], count: 0 }),
    { status: 200, headers: ... }
  );
}
