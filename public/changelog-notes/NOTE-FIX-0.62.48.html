Fix React #310 sur /achats : hook après early return

⚠️ . Erreur Minified React error #310 causée par const { patientIds, ctx } = useContextPatientIds() appelé APRÈS if (!auth.ready) return null; (ligne 373). React exige que tous les hooks soient appelés dans le même ordre à chaque render. Solution : déplacer l'appel du hook AVANT le return null. Pattern classique : tous les hooks en haut, early returns juste après. La page /achats ne crashe plus

Fix PostgREST 400 : jointure FK demandes_internes → etablissements

🔌 dans /magasin/tournees/nouvelle. La query select('..., etablissements(nom, ville, adresse, latitude, longitude), ...') retournait 400 car la FK demandes_internes.etablissement_id → etablissements.id n'est pas déclarée dans Supabase (pattern récurrent du projet). Solution : récupérer les DI seules sans jointure, puis fetch séparément etablissements filtré par les etablissement_id collectés, puis enrichir via Map lookup O(1). Permet de créer une tournée à partir des SAV/maintenance/retours qui s'affichent avec leur adresse pour le routing

Fix PostgREST 400 : jointure FK commandes_ec → magasins + etablissements

🔌 dans /commandes-validation. La query select('*, magasins(nom), etablissements(nom)') retournait 400 (FK non déclarées). Solution : récupérer les commandes seules, puis 2 queries séparées sur magasins (par magasin_id distincts) et etablissements (par etablissement_id distincts), puis enrichir avec Map lookup. Le workflow validation commande EC → DI magasin fonctionne maintenant

Fix PostgREST 400 : `lits` n'a pas de colonne `etablissement_id` direct

🔌 dans /etablissements (mes tuiles MAX INFO 0.62.40). La table lits est liée via chambre→service→batiment→etablissement. La query from('lits').select('etablissement_id').in('etablissement_id', ids) retournait 400 (colonne inexistante). Solution : approximation du nombre de lits via le nombre de chambres (l = ch) en attendant un compte exact via JOIN backend. TODO future : faire un RPC count_lits_par_etab(ids[]) qui fait le JOIN proprement côté SQL
