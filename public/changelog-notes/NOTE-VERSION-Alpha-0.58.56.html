🪟 1. Raccourcis : option popup plein écran

Dans /profil → Mes 3 raccourcis rapides → éditer, nouvelle coche qui permet d'ouvrir le raccourci dans une fenêtre superposée plein écran avec bouton Retour, au lieu de naviguer normalement. Idéal pour les actions courtes (scan, panier) sans perdre le contexte.

🪟 Scan
[ La page /scan/bulletin-situation s'affiche ici dans un iframe plein écran ] 
// 0.58.56 - app/FloatingActionBar.js
const [popupUrl, setPopupUrl] = useState(null);

function navigate(s) {
  setOpen(false);
  if (!s?.url) return;
  if (s.openInPopup) {
    // Ouvre overlay z-index 99999 avec iframe
    setPopupLabel(s.label);
    setPopupUrl(s.url);
  } else {
    router.push(s.url);  // navigation normale
  }
}

// Overlay : header + iframe full-height
{popupUrl && (
  <div style={{ position: 'fixed', inset: 0, zIndex: 99999 }}>
    <button onClick={() => setPopupUrl(null)}>← Retour</button>
    <iframe src={popupUrl} />
  </div>
)}
