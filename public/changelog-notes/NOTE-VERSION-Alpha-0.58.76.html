🎭 Bug 3 — Playwright fail à 1ms

Cause : la config playwright.config.js lançait npm start (mode prod) qui nécessite npm run build d'abord. Sans build → fail immédiat.

Fix : auto-détection. Si .next/BUILD_ID n'existe pas → bascule automatique en npm run dev.

// playwright.config.js (0.58.76)
const hasNextBuild = fs.existsSync(
  path.resolve(process.cwd(), '.next', 'BUILD_ID')
);
let E2E_USE_PROD_BUILD;
if (process.env.E2E_USE_PROD_BUILD === 'false') {
  E2E_USE_PROD_BUILD = false;
} else if (process.env.E2E_USE_PROD_BUILD === 'true') {
  E2E_USE_PROD_BUILD = true;
} else {
  E2E_USE_PROD_BUILD = hasNextBuild;
  if (!hasNextBuild) {
    console.log('⚠ Pas de build Next détecté — bascule en `npm run dev`.');
  }
}

Désormais :

  • npm run test:e2e direct → mode dev auto (pas besoin de build)
  • npm run build && npm run test:e2e → mode prod détecté
  • E2E_USE_PROD_BUILD=true npm run test:e2e → force prod (CI)
