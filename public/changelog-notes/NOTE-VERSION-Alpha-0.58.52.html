☁️ 4. Sync Objectifs avec Supabase

Architecture hybride : load localStorage immédiatement (offline-first) puis sync Supabase en background. Chaque save pousse vers Supabase + sauvegarde locale (cache offline). Badge visuel du statut de sync.

☁ Sync Mode synchronisé — objectifs sauvegardés sur Supabase et accessibles depuis tous tes appareils
⟳ Sync… Synchronisation en cours (à chaque save)
💾 Local Mode local (offline ou table user_goals non créée)

SQL à exécuter :

CREATE TABLE IF NOT EXISTS user_goals (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  label TEXT NOT NULL,
  target NUMERIC, current NUMERIC,
  unit TEXT, color_id TEXT,
  position INTEGER,
  created_at TIMESTAMPTZ, updated_at TIMESTAMPTZ
);

-- RLS : chaque user voit/édite uniquement ses objectifs
-- Trigger updated_at auto
// 0.58.52 - app/components/DashboardWidgets.js
// Load hybride
useEffect(() => {
  // 1. Local immédiat (offline-first)
  setGoals(getGoals());
  
  // 2. Sync Supabase en background
  (async () => {
    const supabase = createClient();
    const { data: { user } } = await supabase.auth.getUser();
    const remoteGoals = await fetchGoalsFromSupabase(supabase, user.id);
    if (remoteGoals) {
      setGoals(remoteGoals);
      saveGoals(remoteGoals);  // cache offline
      setSyncStatus('synced');
    }
  })();
}, []);

// Save = local + push Supabase (delete + insert, idempotent)
async function pushGoalsToSupabase(supabase, userId, goals) {
  await supabase.from('user_goals').delete().eq('user_id', userId);
  const rows = goals.map((g, idx) => ({
    user_id: userId, label: g.label, target: g.target,
    current: g.current, color_id: g.colorId, position: idx,
  }));
  await supabase.from('user_goals').insert(rows);
}
