TauxPanneCategorieWidget

📊 widget BI avancé. Calcul

  1. Fetch materiels + categorie (ou articles.famille si pas de catégorie)
  2. Fetch interventions 90j et compte par materiel_id
  3. Agrège par catégorie (min 2 matériels pour stat significative)
  4. Taux = interventions / nb_materiels de la catégorie
  5. Top 5 trié par taux décroissant. Affichage : icône package + nom catégorie + count fraction (X/Y) + badge % coloré (vert <50%, ambre 50-100%, rouge >100%) + barres progress proportionnelles. Note explicative en bas
