🗺 vue chauffeur en tracking GPS temps réel

  1. Carte Leaflet plein cadre avec étapes numérotées (markers ronds bleus pour à faire, verts pour livrés)
  2. Routing OSRM : appel automatique à https://router.project-osrm.org/route/v1/driving/{coords}?overview=full&geometries=geojson avec toutes les coords étapes en série, dessine la polyline violette dashed prévue + log distance et durée OSRM
  3. Tracking GPS : bouton 'Démarrer tracking GPS' → navigator.geolocation.watchPosition({enableHighAccuracy: true}) → marker rouge animé pulse en temps réel + insert dans tournees_gps_track à chaque update
  4. Polyline rouge dessine l'historique GPS de la journée (track recorded_at)
  5. Bouton 'Arrêter tracking' : clearWatch + reload

Signature canvas par étape

✍ sur chaque étape, 2 boutons workflow : (a) 📍 Arrivé quand le chauffeur arrive sur place → UPDATE arrived_at. (b) ✍ Signer apparaît → modal avec canvas HTML5 (mouse + touch events touch-action:none), input nom signataire + textarea commentaire (optionnel). Capture via toDataURL('image/png') stocké dans signature_url. UPDATE signature_nom + signature_at + completed_at + commentaire_livraison. L'étape passe au vert avec '✍ Signée par {nom}'

Export feuille de route PDF jsPDF

📄 génération A4 avec header navy AVEHO + titre tournée + métadonnées (date, chauffeur, véhicule, nb étapes) + section 'Étapes dans l'ordre' avec status coloré (✓ vert si done, 📍 ambre si arrivé, ○ gris si en attente) + adresse + heure prévue. Footer 'Généré le {date} · {nb} points GPS enregistrés'. Save direct avec nom de fichier feuille-route-{numero}.pdf
