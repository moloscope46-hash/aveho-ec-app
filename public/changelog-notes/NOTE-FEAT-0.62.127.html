useEscReleaseLocks (lib/useEscReleaseLocks.js)

⌨️ hook global monté dans TopBar qui écoute la touche Esc. Activation

  1. Shift+Esc = libération immédiate de TOUS mes locks
  2. Triple Esc en <800ms = libération (anti-erreur). Ignoré si focus sur input/textarea/contenteditable. Toast success affichant le nombre de verrous libérés ou info si aucun. Permet à l user de débloquer rapidement une situation sans devoir naviguer dans l audit

Panel /audit avec gestion globale des locks

🔒 composant LocksPanel ajouté en haut de la page /audit. Features

  1. Compteur global avec badge amber
  2. Refresh auto toutes 15s + bouton manuel
  3. Bouton "Tout libérer" rouge avec confirm (admin uniquement de fait, page protégée par auth.can("gerer_roles")))
  4. Liste cards par lock : type resource + nom user + temps écoulé + id tronqué + bouton individual unlock ti-lock-open
  5. Empty state vert si aucun lock actif (Tous les utilisateurs sont libres d éditer). Vue admin globale pour superviser les locks et débloquer manuellement si nécessaire
