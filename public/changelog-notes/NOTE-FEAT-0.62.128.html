Themes personnalisables (lib/themeManager.js)

🎨 système complet de thèmes par structure

  1. 7 thèmes prédéfinis : Aveho (défaut), Sombre, Océan, Forêt, Coucher de soleil, Rose corail, Monochrome
  2. 12 couleurs personnalisables : primary, primaryDark, accent, warning, danger, success, info, bg, card, text, textMuted, border
  3. applyTheme() injecte les CSS variables au :root
  4. Sauvegarde localStorage + structures.theme_json (DB)
  5. ThemeProvider boot auto au login : charge depuis localStorage immédiatement puis sync depuis DB si user connecté
  6. Compatibilité : aussi les anciennes vars --navy, --teal, --amber, --coral. Page /parametres/apparence pour personnaliser

SmartInput auto-complétion (app/components/SmartInput.js)

🤖 input intelligent avec suggestions basées sur historique

  1. Sauvegarde localStorage par contextKey (ex: materiel.libelle, patient.commentaire)
  2. Algo de tri : count × 10 + bonus si utilisé dans dernier 24h
  3. UI suggestions : dropdown avec icône history + count si plusieurs occurrences
  4. Navigation clavier : ArrowUp/Down pour parcourir, Enter pour sélectionner, Escape pour fermer
  5. Max 50 entrées par contexte
  6. Drop-in replacement d un input classique. Table autocomplete_history en DB pour version partagée multi-user (TODO)

NotifCenter enrichi (app/components/NotifCenter.js)

🔔 remplacement du NotifBell basique par un centre de notifs complet

  1. 4 onglets : Non lu / Tout / Mes équipes / Archivé
  2. Filtre par recherche dans le titre/message
  3. Compteur non-lu avec badge animé
  4. Marquer tout lu en 1 click avec confirm
  5. Archiver individuellement

  8. Empty state : icône bell-off + message contextuel selon onglet
