🔍 Recherche cross-matériels

La recherche scanne à la fois :

  • Le libellé et le code de l'article
  • Les n° série, n° parc, n° lot et libellé de chaque matériel associé

Cherche AB-1234 → matche l'article qui contient un matériel avec ce numéro de série. Ouvre le `<details>` "Voir les matériels associés" pour voir les détails avec badges d'état colorés.

🎤 Web Speech API

Bouton micro qui utilise window.SpeechRecognition :

  • Langue : fr-FR
  • Mode : single shot (continuous false)
  • Animation pulse rouge quand en écoute
  • Bouton se transforme en stop (📴) pendant l'écoute
  • Si non supporté (Firefox) → bouton caché + message en footer

🔗 Sync localStorage

useCart écoute désormais les events av-cart-change (custom) et storage (cross-tab). Quand tu ajoutes un article depuis la popup dépôt, le badge tb-badge rouge de l'icône panier s'incrémente instantanément sans recharger la page.
