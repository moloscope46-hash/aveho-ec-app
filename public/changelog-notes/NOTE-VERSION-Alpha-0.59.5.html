🔄 Switch Mode dans UserMenu

Dans le menu utilisateur (avatar en haut à droite), nouveau bloc teal qui permet de basculer entre les deux vues :

Click sur Magasin :

🔄 Mode de vue
🏘 EC
🏬 Magasin
Vue Magasin Aveho (côté fournisseur)

Le mode est mémorisé dans localStorage (clé av-view-mode). Plus tard ce sera basé sur le rôle de l'utilisateur (un user créé en tant que "user magasin" sera auto-redirigé en mode Magasin sans switch).

🗄 SQL ajouté

-- Flag fournisseur sur les partenaires
ALTER TABLE etablissements_partenaires
  ADD COLUMN est_fournisseur BOOLEAN DEFAULT false,
  ADD COLUMN magasin_id UUID;

-- Articles peuvent appartenir au catalogue magasin OU
-- être rattachés à un article du catalogue magasin
ALTER TABLE articles
  ADD COLUMN magasin_id UUID,
  ADD COLUMN article_magasin_id UUID,
  ADD COLUMN est_catalogue_magasin BOOLEAN DEFAULT false;

-- Vue v_magasin_di pour les DI reçues côté magasin
CREATE VIEW v_magasin_di AS
SELECT d.*, COUNT(lignes) AS nb_lignes
FROM demandes_internes d ...

💡 Workflow envisagé

ÉtapeAction
1Tu crées un partenaire (formulaire existant /etablissements-partenaires)
2Tu coches "Est fournisseur Aveho" (case à ajouter en 0.59.6)
3Il apparaît dans /magasin onglet "Partenaires"
4Tu bascules en mode Magasin via UserMenu → tu vois les DI reçues de tes établissements EC
5Tu crées des articles dans le catalogue magasin (`articles.est_catalogue_magasin=true`)
6Tes établissements peuvent rattacher leurs articles à un article du catalogue via `article_magasin_id`
