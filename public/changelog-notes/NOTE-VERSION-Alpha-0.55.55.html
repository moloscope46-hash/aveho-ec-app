Date : 31 mai 2026 Version : v0.55.55-alpha Tests : 1599 verts (+22) SQL : 1 patch (3 colonnes)

🎯 Le concept

Saisir une adresse à la main, c'est lent et source d'erreurs. Maintenant tu tapes "12 rue du Lac Paris" → suggestions live → tu cliques → tous les champs se remplissent automatiquement (rue, code postal, ville, code INSEE commune, latitude, longitude).

Source : Base Adresse Nationale officielle (api-adresse.data.gouv.fr), gratuite, illimitée, sans clé API. Mise à jour quotidienne.

📍 Composant AdresseAutocomplete

Techniquement

  • Debounce 300ms avant requête
  • Min 3 caractères avant search
  • Max 8 suggestions affichées
  • Param autocomplete=1 + restriction postcode si fourni
  • Click outside ferme le dropdown
  • Loader spinning pendant fetch

Badges colorés par type

🚀 3 emplacements intégrés

1️⃣ /patients — Modale création/édition rapide

Nouveau bloc "Adresse (recherche BAN)" dans la modale. Si tu sélectionnes une suggestion → tous les champs (cp + ville + code_insee + lat/lng) se remplissent. Les champs séparés cp/ville restent visibles juste après pour ajustement manuel si besoin.

Aide affichée : "Pour l'adresse complète + livraisons, va dans Édition complète".

2️⃣ /patient/[id]/edit — Onglet Identité

Champ lieu de naissance avec autocomplete commune INSEE.

Tape "Paris" → choisis dans la liste → lieu_naissance_ville="Paris" + lieu_naissance_code_insee="75056" remplis automatiquement.

Utile pour les bulletins de situation où le code INSEE de la commune de naissance est demandé par certains organismes.

3️⃣ /patient/[id]/edit — Onglet Adresses

  • Adresse principale : autocomplete BAN principal — remplit adresse + cp + ville + code_insee_residence + lat/lng en 1 clic. Champ code_insee_residence visible (rempli auto, modifiable)
  • Adresses de livraison (1-N) : chaque livraison a son propre autocomplete compact qui remplit son cp + sa ville
