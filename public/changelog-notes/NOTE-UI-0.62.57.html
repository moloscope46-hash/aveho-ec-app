🤖 Backend / Frontend (1)

Auto-upgrade des 70 pages avec PageHead legacy

🪄 modification du fallback dans app/ui.js. Avant : les pages avec <PageHead eyebrow='X' title='Y' icon='ti-Z'> (format legacy) rendaient le rendu plat sans icône colorée. Après : nouvelle branche dans le composant if (icon && title) { return <PremiumLayout/> } qui détecte la présence d'une icône + d'un titre et rend le format premium avec icône carrée gradient 52×52 + shadow couleur + titre Quicksand 24px blanc + textShadow + animation fade-in. L'eyebrow (s'il existe) est rendu en petit chapeau au-dessus du titre (10.5px white/55% uppercase letterSpacing 1). 70 pages d'un coup en visuel premium sans toucher leur code ! Le legacy pur (sans icon) garde son rendu CSS classes pour rétrocompat

📁 Fichiers concernés : app/ui.js

🐛 Fix bug (1)

Fix React #310 sur /signalements

⚠️ même pattern que /achats en 0.62.48. useContextPatientIds() était appelé APRÈS if (!auth.ready) return null; → hook après early return = rendu inconsistant entre les renders = React #310. Solution : déplacer le hook AVANT le early return. Pattern préventif important : tous les hooks toujours en haut, returns conditionnels juste après. Aussi appliqué dans cette session
