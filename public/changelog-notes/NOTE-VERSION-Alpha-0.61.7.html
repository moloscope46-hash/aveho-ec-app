🚨 Erreur SQL fixée

Erreur : 42703: column "se.created_at" does not exist

Cause : la table sav_executions existait déjà sans created_at chez toi.

Fix : pour CHAQUE table je fais ADD COLUMN IF NOT EXISTS created_at TIMESTAMPTZ DEFAULT NOW() explicitement. La vue v_analytics_sav utilise COALESCE(se.executee_at, NOW()) pour ne pas dépendre de cette colonne.

📋 Application auto mercuriale au panier

lib/mercurialeHelper.js — fonctions getPrixMercurialeActif() et appliquerMercurialeLigne().

Logique : recherche dans cet ordre (premier match gagne) :

  1. Rattachement direct article étab → article magasin avec prix négocié override
  2. Mercuriale ACTIVE rattachée à cet étab + ligne sur cet article
  3. Mercuriale ACTIVE générique (pas d'étab) + ligne sur cet article
  4. null → utilise prix public (fallback)

À intégrer dans le panier EC : appel au moment du add to cart pour stocker prix_mercuriale_ht + mercuriale_id sur la ligne.

📷 Scanner code-barres natif in-app

Composant <ScanBarcode onScan onClose />

Utilise BarcodeDetector API native (Chrome/Edge/Opera Android). Plus de redirect vers /scan/article. Affiche vidéo live caméra arrière + viseur teal avec coins + ligne de scan animée. Décode EAN-13/EAN-8/Code128/QR. Haptic feedback à la détection. Code affiché en bas.

Intégré dans /magasin/inventaires : bouton "📷 Scanner" ouvre la caméra in-app au lieu de quitter la page.
