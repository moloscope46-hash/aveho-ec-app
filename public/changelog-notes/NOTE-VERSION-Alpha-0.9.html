1. Résumé exécutif

L'Alpha 0.9 livre quatre chantiers à forte valeur métier : la sélection multiple avec actions en masse dans toutes les listes Crud, un calendrier mensuel des interventions, les étiquettes colorées personnalisables pour catégoriser les patients, et des graphes de comparaison entre établissements d'une même collectivité.

Cette version introduit 2 nouvelles tables SQL (etiquettes et patient_etiquettes). Un script de migration unique (13_etiquettes.sql) à exécuter dans Supabase. Sans ce script, la page Étiquettes ne fonctionnera pas mais le reste de l'app continuera normalement.

3. Sélection multiple + bulk actions NOUVEAU

Dans toutes les listes Crud, une colonne de cases à cocher apparaît en première position. Au moins une coche sélectionnée fait apparaître en haut de la liste une barre noire bulk avec le décompte et les actions disponibles.

Actions disponibles

ActionEffetDisponible pour
Exporter CSVExporte uniquement les lignes sélectionnéesTous les rôles avec accès lecture
SupprimerConfirmation puis suppression définitive en batches de 100Rôles avec droit "supprimer"
DésélectionnerVide la sélection (sans supprimer)Tous

Header "tout sélectionner"

La case à cocher en haut de colonne sélectionne ou désélectionne toutes les lignes visibles de la page courante (pas toute la liste paginée). C'est volontaire pour éviter qu'un clic involontaire embarque 200 lignes invisibles.

Suppression en batches

Pour respecter les limites Supabase, le bulk delete envoie les IDs par tranches de 100 en boucle. Tu peux donc sans risque sélectionner 500 lignes — la suppression se fera en 5 requêtes séquentielles, avec rechargement automatique de la liste à la fin.

4. Calendrier des interventions NOUVEAU

Nouvelle page /calendrier dans le menu Espace Collectivité (icône ). Affiche une vue mensuelle des DI sur 7 colonnes (lundi en première colonne, à la française).

Comportement

  • Le jour aujourd'hui est mis en évidence avec un fond turquoise clair et une bordure
  • Les jours hors mois courant sont grisés
  • Chaque DI apparaît comme une pastille colorée selon son statut (rouge = Nouvelle, orange = En cours, vert = Résolue, gris = Annulée)
  • Max 3 DI affichées par jour avec un compteur "+N autre(s)" si dépassement
  • Clic sur une pastille → redirection vers la page Interventions
  • Tooltip au survol avec numéro de DI, type, statut

Navigation

Boutons Précédent / Suivant pour parcourir les mois, bouton Aujourd'hui pour revenir au mois courant. À chaque changement, on recharge les DI sur la période visible (avec un mois de marge avant/après pour la fluidité).

Positionnement des DI

Une DI est positionnée sur sa due_date si elle est renseignée, sinon sur created_at. Si tu veux une vue purement planning, renseigne les due_date ; sinon le calendrier reste utile en vue historique.

5. Étiquettes patients NOUVEAU

5.1 Architecture SQL

Deux nouvelles tables (RLS activée, scope collectivité) :

etiquettes (
  id, structure_id, libelle, couleur, description
)

patient_etiquettes (
  id, patient_id, etiquette_id, structure_id, created_at
)

La relation est n:n : un patient peut porter plusieurs étiquettes, une étiquette peut être appliquée à plusieurs patients. La contrainte unique (patient_id, etiquette_id) empêche les doublons.

5.2 Page de gestion des étiquettes

Nouvelle page /etiquettes dans le menu Administration. Accessible uniquement aux Administrateurs (un message s'affiche sinon). Permet de créer / modifier / supprimer des étiquettes :

  • Libellé obligatoire (ex: "Chronique", "Sortie prévue")
  • Couleur à choisir dans une palette de 9 couleurs Aveho (cliquables avec aperçu en taille réelle)
  • Description optionnelle
  • Aperçu live de la tag pendant la saisie

5 étiquettes démo sont pré-insérées par le script SQL pour la collectivité de test : Chronique, Sortie prévue, Allergie connue, À surveiller, Isolement.

5.3 Application aux patients

Sur la page Patients, une icône apparaît dans la colonne actions. Au clic, une modale s'ouvre listant toutes les étiquettes de la collectivité. Clic sur une étiquette = bascule (ajoute ou retire) — les changements sont enregistrés immédiatement, pas besoin de bouton "Valider".

Les étiquettes appliquées s'affichent comme des tags colorés sous le nom du patient dans la liste, en utilisant la couleur définie pour chacune.

5.4 Cas d'usage métier

Exemples concrets de ce que ça permet :

  • Marquer les patients en isolement pour limiter les visites
  • Identifier les sorties prévues dans la semaine pour préparer le matériel à reprendre
  • Repérer les allergies connues avant prescription
  • Tagger les patients à surveiller pour les tournées de nuit

Comme les étiquettes sont définies par collectivité, chaque structure peut établir son propre référentiel selon ses procédures internes.

6. Comparaison inter-établissements NOUVEAU

Sur la page Statistiques, un nouveau bloc Comparaison inter-établissements apparaît automatiquement si la collectivité a au moins 2 établissements. Sinon, le bloc reste caché (pas de pollution UI pour les mono-sites).

Deux graphes de comparaison

  • Interventions par établissement — barres rouges, 6 derniers mois, classées par volume décroissant
  • Transferts par établissement — barres bleues, idem

Permet d'identifier rapidement quel établissement génère le plus de DI ou le plus de transferts, pour équilibrer les ressources ou enquêter sur les écarts.

9. Procédure de mise à jour depuis Alpha 0.8

  1. Sauvegarde ton dossier C:\aveho-ec-app.
  2. Décompresse le nouveau zip par-dessus.
  3. Dans Supabase SQL Editor : exécute supabase/13_etiquettes.sql.
    Sans ce script, la page Étiquettes échouera mais le reste de l'app fonctionne normalement.
  4. Dans PowerShell :
    cd C:\aveho-ec-app
npm install
npm run dev
  5. Tests rapides :
    • Va sur Articles : coche 2 lignes → la barre noire bulk apparaît avec les actions
    • Clique Exporter CSV → tu obtiens un fichier avec seulement les 2 lignes
    • Va sur /calendrier : tu vois la vue mensuelle des DI
    • Navigue avec Précédent / Suivant / Aujourd'hui
    • Va sur /etiquettes (si tu es Admin) : 5 étiquettes démo
    • Sur la liste Patients, clique sur un patient → modale d'application
    • Sur Statistiques, scroll en bas : si tu as plusieurs établissements, les graphes comparatifs apparaissent
  6. Mise en ligne :
    git add .
git commit -m "Aveho EC Alpha 0.9"
git push
