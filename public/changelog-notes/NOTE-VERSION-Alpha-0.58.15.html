📅 RangePicker enfin branché sur Supabase

Le RangePicker de /statistiques ne servait à rien avant — les queries restaient sur les 6 derniers mois fixes. Maintenant les bornes range.from / range.to sont injectées dynamiquement dans les .gte() / .lte() et le useEffect re-fetch automatiquement au changement.

✓ Filtre appliqué 
// Calcul dynamique des bornes
let dateFromISO = range.from
  ? new Date(range.from + 'T00:00:00').toISOString()
  : new Date(Date.now() - 6 * 30 * 86400000).toISOString();   // fallback 6 mois
let dateToISO = range.to
  ? new Date(range.to + 'T23:59:59').toISOString()
  : null;

// Helpers : .lte() optionnel seulement si dateTo défini
const applyToISO = (q, col) => dateToISO ? q.lte(col, dateToISO) : q;

await Promise.all([
  applyToISO(supabase.from('interventions').select(...).gte('created_at', dateFromISO), 'created_at'),
  applyToISO(supabase.from('transferts').select(...).gte('created_at', dateFromISO), 'created_at'),
  ...
]);

// useEffect dépend de range.* → re-fetch auto au changement
}, [auth.ready, auth.structureId, auth.etablissements, range.from, range.to]);
