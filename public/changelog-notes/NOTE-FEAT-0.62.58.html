Carrousel météo 7 jours scrollable

🌤️ (TODO depuis 0.58.39 mentionnée 6x). Avant : 3 jours en grid 3 colonnes fixe (limité par forecast_days=4 dans l'API Open-Meteo). Après : forecast_days=7 + carrousel horizontal scrollable avec overflow-x: auto, scroll-snap-type: x mandatory, scroll-behavior: smooth, scroll-snap-align: start sur chaque jour. Chaque tuile fait 70px de minWidth pour donner un look 'cards' homogène. Le swipe horizontal mobile (touchStart/touchEnd) déclenche le changement de jour focus (gauche/droite). Scrollbar cachée via ::-webkit-scrollbar { display: none } (en CSS séparé .av-weather-carousel) + scrollbarWidth: none Firefox + msOverflowStyle: none IE/Edge. Animation focus existante conservée (scale 1.04 + gradient + shadow)

Bilans SAV : section pièces détachées enrichie

  1. pieces_detachees (JSONB array) : liste [{designation, ref, quantite, prix_unitaire, fournisseur, num_commande}]
  2. cout_pieces_total (NUMERIC) : total HT pièces
  3. duree_intervention_min (INTEGER) : durée en minutes pour facturation
  4. cout_main_doeuvre (NUMERIC) : coût main d'œuvre HT
  5. cout_total_ht (NUMERIC) : total facturable au client (pieces + MO). Initialisation à [] / 0 / null à la création d'un bilan dans startBilan()
