LockBanner /transferts

🔒 hook useEditLock("transfert", modal?.id, !!modal?.id && modal?.mode !== "new") + JSX dans la Modal. Imports useEditLock + LockBanner via sed. Anti-collision sur édition d un transfert

LockBanner /depots

🔒 hook useEditLock("depot", modal?.id, !!modal?.id && modal?.mode !== "new") + JSX dans la Modal édition. Couvre les dépôts et sous-emplacements

LockBanner /magasin/fournisseurs

🔒 hook useEditLock("fournisseur", form?.id, modal === "edit" && !!form?.id). Note : le state modal ici est une string ("new"/"edit"), pas un objet, donc on utilise form?.id et la condition modal === "edit"

EditingIndicator (app/components/EditingIndicator.js)

🟠 pill visible dans la TopBar quand l user courant détient au moins 1 lock actif. Fetch dans edit_locks where user_id=auth.user.id et locked_at récent (<2 min). Refresh toutes les 20s. UI : gradient amber/teal + border amber/45 + icône pencil amber + label "Édition {type}" caché en mobile + badge compteur cercle. Animation pulse 2.5s scale + shadow ring. Hover tooltip : liste détaillée des verrous avec icône + type + id tronqué + footer info 2 min. Plus de doute sur ce qu on est en train de verrouiller
