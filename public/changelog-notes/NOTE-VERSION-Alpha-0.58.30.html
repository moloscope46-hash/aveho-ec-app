🔕 Mode focus : option "masquer les notifs aussi" — DÉMO LIVE

Sous-option dans /profil → Sécurité → Mode focus zen. Active uniquement si le mode focus est ON. Cache la cloche de notifs + les toasts pour les sessions de concentration intense.

/* app/globals.css - cache UNIQUEMENT si focus ON + sous-option active */
html.av-focus-mode.av-focus-hide-notifs .notif-wrap,
html.av-focus-mode.av-focus-hide-notifs #av-toast-container {
  display: none !important;
}

/* lib/focusMode.js - nouveaux exports */
export function isFocusHideNotifs() {
  return localStorage.getItem('av-focus-hide-notifs') === 'true';
}
export function setFocusHideNotifs(on) {
  localStorage.setItem('av-focus-hide-notifs', on ? 'true' : 'false');
  if (on) {
    document.documentElement.classList.add('av-focus-hide-notifs');
  } else {
    document.documentElement.classList.remove('av-focus-hide-notifs');
  }
  window.dispatchEvent(new CustomEvent('av-focus-hide-notifs-change', { detail: { on } }));
}
