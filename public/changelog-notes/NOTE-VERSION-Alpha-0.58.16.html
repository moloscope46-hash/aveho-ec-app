🐛 Bug 1 — Profil coupé

1

Le bas du Profil (et d'autres pages longues) était coupé

🔴 Symptôme : sur la page Profil et autres pages avec contenu long, le bas était masqué par le viewport, surtout sur iPhone avec home indicator
✓ Cause : .wrap avait padding-bottom: 110px (desktop) / 130px (mobile) — insuffisant quand widgets fixed (BulkToolbar, ProgressBar) flottent en bas. Fix : passage à 140px / 160px + env(safe-area-inset-bottom) pour gérer auto le notch iOS
/* AVANT 0.58.16 */
.wrap { padding: 30px 24px 110px; }              /* desktop */
@media(max-width:760px) {
  .wrap { padding: 18px 12px 130px; }            /* mobile */
}

/* 0.58.16 - safe-area-inset pour iPhone */
.wrap { 
  padding: 30px 24px calc(140px + env(safe-area-inset-bottom, 0px)); 
}
@media(max-width:760px) {
  .wrap { padding: 18px 12px calc(160px + env(safe-area-inset-bottom, 0px)); }
}

🐛 Bug 2 — Menu burger masqué hors accueil

2

Clic sur le burger → flou visible mais menu invisible

🔴 Symptôme : sur /interventions, /statistiques, etc. quand on clique sur le burger, on voit juste le flou (l'overlay sombre) mais le menu drawer ne s'affiche pas
✓ Cause : z-index trop bas du menu (overlay 48, drawer 49) → masqué par BulkToolbar (70), ProgressBar (75), Modal (80), Drawer backdrop (85). Fix : passage à 9998 / 9999

🐛 Bug 3 — Dropdowns coupés en bas

3

Select / TimePicker / RangePicker / Combobox s'ouvraient toujours vers le bas

🔴 Symptôme : quand on cliquait sur un Select en bas d'écran ou dans une modale, le dropdown débordait du viewport et était coupé. Si deux dropdowns dans une rangée, le 2e était parfois invisible
✓ Cause : hardcodé top: calc(100% + 6px) sans détection de débord. Fix : nouveau hook useDropdownPosition qui calcule via getBoundingClientRect() si flip vers le haut nécessaire

import { useDropdownPosition, dropdownPositionStyle } from './useDropdownPosition';

const [open, setOpen] = useState(false);
const flipUp = useDropdownPosition(rootRef, open, { maxHeight: 320 });

<div style={{
  position: 'absolute',
  ...dropdownPositionStyle(flipUp),  // ← top OU bottom selon position
  left: 0,
  right: 0,
  ...

// Logique du hook :
