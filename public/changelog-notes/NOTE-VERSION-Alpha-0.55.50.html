🎯 Le but

Avant : créer un patient = saisir manuellement 40+ champs depuis le bulletin de situation. 5-10 minutes par patient, erreurs fréquentes.

Maintenant : 1 photo du bulletin → patient créé en 15 secondes. L'IA lit tout, identifie automatiquement la caisse et la mutuelle dans nos référentiels, et tu valides en 2 clics.

📸 Workflow 4 étapes

1
Upload · drag&drop ou clic, ou photo directe sur mobile (l'appareil photo s'ouvre automatiquement)
2
OCR IA · Claude Sonnet 4 Vision lit le document (5-15 secondes)
3
Vérification · les 40+ champs apparaissent éditables à côté de l'image, badge confiance affiché
4
Création · patient créé, caisse/mutuelle auto-liées si dans nos référentiels → bouton "Compléter la fiche"

🤖 Architecture technique

Route /api/ocr/bulletin-situation

  • Reçoit image base64 + media_type (jpg/png/webp/pdf, max 8 Mo)
  • Appelle https://api.anthropic.com/v1/messages
  • Modèle : claude-sonnet-4-20250514
  • max_tokens : 4096 (pour la réponse JSON large)
  • maxDuration Vercel : 60s (OCR + extraction)

Prompt structuré (190 lignes)

Demande à Claude d'extraire 40+ champs en JSON strict :

  • Identité : nom, prenom, nom_naissance, sexe, date naissance, lieu naissance ville/code_insee/pays, nationalité
  • Sécu : numero_secu (NIR 13 ou 15 chiffres), cle_nir, code_organisme, nom_caisse, centre_paiement, regime, qualite_assure, rang_naissance, dates droits, ALD/CMU/C2S/AME
  • Mutuelle : mutuelle_nom, mutuelle_numero_amc, mutuelle_numero_adherent
  • Adresse : adresse complète, complement, cp, ville, pays
  • Contact : téléphones, email
  • Médecin : nom, prenom, RPPS
  • Hospit : etablissement, date_emission, date_entree, date_sortie, service
  • Audit : ocr_text_brut (tout le texte visible), confiance (haute/moyenne/faible)

Anti-hallucination

Prompt explicite : "Ne devine PAS, mets null si pas sûr". Cleanup automatique des ```json ... ``` au cas où. Si l'image n'est pas un BS, Claude retourne {erreur, ocr_text_brut}.

Réponse enrichie

{
  "ok": true,
  "data": { /* 40+ champs */ },
  "ocr_text": "texte brut pour audit",
  "confiance": "haute",
  "model": "claude-sonnet-4-20250514",
  "duration_ms": 8430,
  "tokens": { "input": 1850, "output": 620 }
}

🔗 Auto-link caisse + mutuelle

Route /api/patients/from-ocr

Caisse : recherche par code_organisme (3 premiers chiffres) puis fallback ilike sur nom_caisse.

Mutuelle : recherche par numero_amc exact puis fallback ilike sur raison_sociale.

Exemple : si l'OCR sort code_organisme: "751010101" → match exact CPAM Paris (code court "751").

Si mutuelle_nom: "MGEN" → fallback ilike → trouve MGEN (27977927).

📋 Configuration requise

⚠️ Variable d'environnement Vercel

Pour que l'OCR fonctionne en prod, il faut ajouter dans Vercel → Settings → Environment Variables :

ANTHROPIC_API_KEY = sk-ant-...

Si pas configurée, la route retourne 500 avec message explicite.

Clés API → console.anthropic.com. Coût ~0,01 € par OCR (1800 tokens IN + 600 OUT).
