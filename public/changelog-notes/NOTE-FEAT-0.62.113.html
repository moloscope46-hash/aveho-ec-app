CSS pop-ups mobile premium

📱 tous les boutons dans modal/dialog/data-modal en mobile ≤768px ont min-height 44px (Apple HIG tap target) + padding 12-20 + font-size 15 weight 700 + radius 12 + min-width 100px. Bouton primary : width 100% margin-top 8 (plein-largeur). Inputs : width 100% + min-height 44 + font-size 16 (évite zoom iOS) + padding 12-14 + radius 10. Rien ne déborde : max-width: 100% !important + box-sizing border-box + word-wrap break-word sur tous les enfants

Tables responsives → cards empilées CSS

📱 règles pour table.responsive, table[data-responsive=true], .table-responsive table en mobile. Thead caché. Chaque tr devient une carte : display block + margin-bottom 12 + background #fff + border + radius 12 + padding 12 + box-shadow. Chaque td : display flex + justify-content space-between + text-align right + padding 6 0 + border none. Label : td[data-label]::before = content: attr(data-label) en uppercase font-weight 700 color #5a6878 (le data-label devient le titre de chaque ligne dans la carte)

Listes scroll horizontal → wrap vertical

📱 règles pour .scroll-x, [data-scroll-x=true], .horizontal-scroll en mobile : overflow-x visible + display flex + flex-direction column + gap 8 + width 100%. Les enfants : width 100% + min-width 0 + max-width 100% + flex-shrink 1. Plus de scroll latéral sur mobile, tout s empile verticalement

TopBar mobile icônes ALIGNÉES (pas empilées)

📱 .topbar en mobile = flex-wrap: nowrap !important + overflow-x: auto (scroll horizontal possible si trop d icônes) + gap: 8px + height 56px + padding 0 10px. Scrollbar masquée (scrollbar-width none + webkit display none). Burger toujours visible : display inline-flex !important 40x40 + background blanc/8 + border teal/25 + radius 10 + flex-shrink 0. Tous les enfants directs ont flex-shrink: 0 (ne se compressent pas, ne se wrappent pas)

Composant AccordionTable

📦 (app/components/AccordionTable.js) : transforme une table à scroll horizontal en accordéon empilable. Props : columns (avec primary/secondary/icon par colonne), rows, onRowClick, keyField, emptyLabel, rowAccentColor. Rendu : pour chaque row, une card avec colonne primary (bold) + secondary (subtle avec icon) + bouton chevron 36x36 qui dépile. Au dépliage : détails sous forme de paires label→value avec borders dashed entre. Animation av-accordion-down 280ms cubic-bezier. Empty state avec icône database-off. À utiliser sur les pages qui ont des tables longues (interventions liste, signalements liste, etc.)

ℹ Info / Tâche restante (2)

Comment utiliser AccordionTable

💡 import AccordionTable from app/components/AccordionTable. Exemple : <AccordionTable columns={[{key:nom,label:Nom,primary:true},{key:ville,label:Ville,secondary:true,icon:ti-map-pin},{key:tel,label:Téléphone,icon:ti-phone}]} rows={data} onRowClick={r => router.push(/patient/${r.id})} keyField=id />. Sur mobile, chaque ligne devient une carte tappable avec chevron dépliant. Sur desktop : à wrapper avec un classique tableau ou utiliser tel quel
