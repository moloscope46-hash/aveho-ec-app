ℹ Info / Tâche restante (3)

Cas d'usage marketplace pièces

💡

  1. Magasin A a des joints toriques inutilisés → propose 'OFFRE' avec date_dispo
  2. Magasin B cherche un module GPS pour AirSense → 'DEMANDE' avec urgent=true + date_besoin = J+2
  3. Tous les magasins voient l'annonce, peuvent y répondre via pieces_marketplace_reponses avec quantite_proposee/prix_propose
  4. Le créateur accepte/refuse les réponses → statut passe à 'reservee' puis 'cloturee'. Évite le gaspillage de stock + accélère les SAV urgents. Index GIN full-text français sur designation+reference+marque+modele_compat pour recherche tolérante
