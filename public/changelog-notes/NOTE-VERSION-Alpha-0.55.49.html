Accès depuis la fiche patient : bouton "Édition complète" en haut.

📋 Détail des onglets

🪪 Identité

Nom, prénom, nom de naissance (jeune fille), sexe (M/F/X), date naissance, lieu de naissance (ville + code INSEE + pays), nationalité, n° dossier interne.

🛡 Sécu & Mutuelle

Section AMO (Sécu obligatoire) :

  • NIR 15 chiffres en mono
  • Régime (général/agricole/militaire/fonctionnaire/spécial)
  • Qualité (assuré / ayant droit)
  • Rang naissance, centre paiement
  • Date début/fin droits
  • Toggles colorés : ALD (rouge), C2S (ambre, ex-CMU-C), AME (violet)
  • Commentaire ALD apparaît seulement si ALD activé
  • CaisseSearch live : tape un nom ou un code, sélectionne → card bleue affiche nom + code + type + dept

Section AMC (Mutuelle) :

  • MutuelleSearch live avec badges couleur (mutuelle/assurance/IP) + badge C2S
  • N° AMC 8 chiffres mono, n° adhérent, dates début/fin
  • Toggle "Tiers payant actif" (vert)

📍 Adresses livraison (1-N)

Adresse principale (sociale) en haut : rue, complément, cp, ville, pays.

Section verte "Adresses de livraison" : tu peux ajouter autant que tu veux (Domicile, Maison campagne, Chez sa fille…).

Pour chaque adresse :

  • Libellé personnalisé en gros (ex "Maison de campagne du Lot")
  • Destinataire si différent du patient (ex "Mme Dupont, sa fille")
  • Téléphone contact
  • Adresse + complément + cp + ville
  • Code porte / digicode mono
  • Instructions livraison : "Sonner 2× au fond de la cour"
  • Case Principale
  • Boutons Sauv. par adresse + bouton × suppression

📞 Contacts urgence

3 sections :

  • Contact patient : tel fixe + portable + email
  • Personne à prévenir (urgence) en ambre : nom, prénom, lien de parenté, téléphone
  • Personne de confiance (loi 4 mars 2002) en violet : nom, prénom, téléphone + bandeau pédagogique sur son rôle

🩺 Médecin traitant

Nom, prénom, téléphone, RPPS 11 chiffres mono, FINESS établissement mono. Bandeau pédagogique sur le parcours de soins coordonné.

📄 OCR & audit

  • Source de création : Saisie manuelle ✍️ / OCR bulletin 📄 / Import CSV 📊
  • Created at / Updated at
  • Si bulletin scanné : lien vers le fichier + date OCR
  • Si OCR effectué : texte brut dépliable en pre dark (pour audit)

🐛 FIX critique — Carte recherche libre "visibles 0"

Le bug

Tu tapais "orthopediste" dans la recherche libre carte. Console : RPPS 0 / SIRENE 20 / FINESS 8 / visibles 0. 28 résultats trouvés, 0 affichés !

La cause

Les résultats SIRENE/FINESS n'ont souvent pas de coords directes — il faut les géocoder via BAN. Si le géocodage est lent ou que le résultat est hors de la bbox visible, le filtre x.latitude >= bounds.getSouth() && ... les éliminait tous.

La correction

  • Filtre bbox RETIRÉ sur la recherche libre — on affiche TOUS les résultats avec coords
  • Auto-fit de la carte sur les résultats trouvés (la carte se positionne automatiquement où sont les résultats)
  • Console log enrichi : [Recherche libre] orthopediste → RPPS 0 / SIRENE 20 / FINESS 8 / total avec coords 28 / affichés 28

Maintenant tu vois tout, où qu'ils soient en France.

⚠️ Avertissement API ANS sur la carte
