🩺 1. Cascade pathologies du service

Quand l'utilisateur sélectionne un service dans la création patient, les pathologies rattachées à ce service apparaissent en haut du select avec une étoile ★ :

Pathologie principale (★ = recommandée pour ce service)
★ Pathologies de ce service
★ [PERF] Perfusion à domicile
★ [CICA] Cicatrisation
Autres pathologies
[PPC] PPC (Apnée du sommeil)
[OXY] Oxygénothérapie
[NED] Nutrition entérale
[VPH] VPH

Le rattachement est lu depuis services_pathologies (table 0.58.99) via un useEffect sur form.service_id. Sans service sélectionné, liste classique.

🔔 3. Notifications auto sur actions DI

Quand l'user magasin valide ou refuse une DI :

  • INSERT auto dans table notifications
  • Destinataire : created_by de la DI (l'user EC qui a fait la demande)
  • Type di, titre + message contextuel, URL vers la DI
  • Apparaît dans la cloche de la TopBar (composant NotifBell existant)
  • Try-catch défensif si table notifications absente
// Côté magasin après valider/refuser
await supabase.from("notifications").insert({
  user_id: di.created_by,
  structure_id: di.structure_id,
  type: "di",
  titre: `DI ${di.numero} validée`,  // ou "refusée"
  message: `Le magasin a validé ta demande.`,
  url: `/demandes-internes/${id}`,
  lu: false,
});

🔄 Boucle complète EC ↔ Magasin

1️⃣ EC crée des pathologies (/pathologies)
       ↓
2️⃣ EC rattache pathos aux services (/etablissement/edition modal service)
       ↓
3️⃣ EC crée un patient mobile → sélectionne un service
       → Pathologies du service en ★ en haut du select  [NEW 0.59.7]
       ↓
4️⃣ EC envoie une DI au magasin
       ↓
5️⃣ Magasin clique sur la DI → page détail → Valider/Refuser
       → INSERT notification pour l'EC                  [NEW 0.59.7]
       ↓
6️⃣ EC voit le badge sur la cloche TopBar
       → Click cloche → voit la notif
       → Click notif → arrive sur la DI mise à jour
       OU
       → EC va sur /mes-demandes                        [NEW 0.59.7]
       → Voit tous ses DI avec leurs statuts
       ↓
7️⃣ Magasin génère le BL → DI passe en "livrée"
       → INSERT notification
