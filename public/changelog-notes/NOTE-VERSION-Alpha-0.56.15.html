🎯 Nouveau : module Équipes

Une équipe regroupe plusieurs utilisateurs travaillant ensemble. Elle est rattachable à 1 bâtiment (ou transversale) et à N services. Création automatique d'une équipe par défaut à chaque nouveau bâtiment via trigger SQL.

Modèle de données

equipes (
  id uuid, structure_id, batiment_id (nullable),
  nom, description, couleur, est_par_defaut, archive
)

equipes_membres (
  equipe_id, user_id, role_dans_equipe (responsable|membre)
)

equipes_services (equipe_id, service_id)

Trigger create_default_team

À chaque INSERT dans la table batiments, le trigger crée automatiquement une équipe nommée Équipe {batiment.nom} avec est_par_defaut=true.

3 RPC

  • equipes_avec_stats(p_batiment_id) : liste équipes filtrable par bâtiment, avec compteurs (nb_membres, nb_services, services_noms[])
  • equipe_detail(p_equipe_id) : détails d'une équipe avec membres (jointure membres_structure pour les noms d'affichage)
  • mes_equipes() : équipes du user connecté (pour fiche profil)

2 nouvelles pages

  • /equipes : liste filtrable par bâtiment, recherche texte, groupée par bâtiment avec compteur, création avec couleur picker, archivage soft
  • /equipe/[id] : détail avec header gradient à la couleur de l'équipe, gestion membres (ajout/retrait, toggle responsable ↔ membre via icône crown), gestion services rattachés

RLS sécurisée

4 policies sur chaque table (select/insert/update/delete) qui filtrent sur structure_id in (membres_structure where user_id = auth.uid()). Sécurité multi-tenant garantie.

📐 TopBar réorganisée en 6 sections workflow métier

Anciennement le menu avait 7 sections en ordre arbitraire (Mon espace, Outils scan, Établissement, Stock, Commandes, Groupement, Administration). Maintenant l'ordre suit le workflow métier réel :

Mon espace→Collectivité→Scan→Commande→Livraison→Administratif→Administration

3. Pour bénéficier de la création auto : à la prochaine création d'un bâtiment via /etablissement/edition, une équipe par défaut sera créée automatiquement et visible sur /equipes.

4. Pour les bâtiments existants : tu peux créer manuellement les équipes via le bouton "Nouvelle équipe" sur /equipes, ou jouer ce SQL one-shot :

-- Création rétroactive des équipes par défaut pour les bâtiments existants
insert into equipes (structure_id, batiment_id, nom, est_par_defaut, couleur)
select structure_id, id, 'Équipe ' || nom, true, '#185FA5'
from batiments
where not exists (
  select 1 from equipes where batiment_id = batiments.id and est_par_defaut = true
);
