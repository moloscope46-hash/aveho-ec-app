🔒 Type d'établissement verrouillé après création

Le problème

Avant 0.55.47, dans /etablissement/fiche on pouvait re-cliquer sur "Mon collectivité" / "Partenaire" et basculer le type en édition. Risque : un étab géré devient soudain partenaire et perd l'accès patients/matériel (ou inverse).

Le verrouillage

  • Boutons remplacés par divs non-clickables (cursor: not-allowed)
  • Opacity 0.55 sur l'option non sélectionnée — visuellement désactivée
  • Badge ambre "🔒 Verrouillé après création" à côté du label
  • Tooltip au survol : "Le type d'établissement ne peut pas être modifié après création"
  • Bandeau d'info en bas : "Pour changer un partenaire en étab géré, il faut supprimer puis recréer la fiche"
  • Backend : est_partenaire RETIRÉ du payload update — impossible même via DevTools

🗺 Carte — icône voyante pour mes étab

Avant : tous les étab étaient des cercles uniformes 38px bleus/turquoise. Difficile de repérer ses propres étab parmi 50 partenaires.

Maintenant

  • Mes étab : 🏥 taille 48px, gradient bleu→vert, halo pulsant vert 2s, ring blanc
  • Partenaires : 38px, gradient turquoise (inchangé)
  • Badge popup : ★ Mon étab en vert (au lieu de "Géré" en bleu)

Sur une carte zoomée à mi-distance, les mes étab sortent immédiatement grâce au halo pulsant et la taille +25%.

🔍 Recherche libre sur la carte

Le besoin

Tu tapes "orthopédiste" → tu veux voir tous les orthopédistes (RPPS + SIRENE) sur la carte. Tu tapes "pharmacie" → toutes les pharmacies. Tu tapes "Mayrinhac" → tout ce qui se trouve à Mayrinhac.

L'implémentation

Une seule barre de recherche en haut du panneau filtres carte, dans un Panel violet "Recherche libre sur la carte". Quand tu tapes (debounce 600ms) :

// 3 appels en parallèle
[Promise.allSettled]
├── GET /api/rpps?q=orthopédiste&ville=<centre>&limit=60
├── GET /api/sirene?q=orthopédiste&commune=<centre>&limit=40
└── GET /api/finess?q=orthopédiste&limit=40

→ Merge ~30-150 résultats
→ Géocodage BAN INSEE pour les manquants
→ Filtre par bbox carte visible
→ Markers colorés par source

Markers colorés par source

  • 🩺 RPPS violet · praticiens libéraux
  • 🏪 SIRENE vert · entreprises (pharmacies, magasins, etc.)
  • 🏥 FINESS bleu · établissements de santé

UI

  • Input avec loupe à gauche
  • Bouton × à droite pour clear
  • Loader pendant la recherche
  • Badge "X résultats" quand prêt
  • Min 3 caractères avant de chercher
  • Console logs détaillés : [Recherche libre] orthopédiste → RPPS 23 / SIRENE 12 / FINESS 4 / visibles 28
