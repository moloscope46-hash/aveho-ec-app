Notes techniques

Leaflet via CDN — pourquoi pas npm install ?

Leaflet pèse ~150 KB et n'est utilisé que sur /carte. L'installer en npm le ferait charger sur toutes les pages (même si tree-shaké, le code dynamic import reste à gérer). Via CDN unpkg :

  • Pas de poids dans le bundle initial
  • Chargement uniquement à l'ouverture de /carte
  • Cache navigateur partagé entre tous les sites utilisant Leaflet
  • SRI (Subresource Integrity) hash inclus pour la sécurité

API Base Adresse Nationale (BAN)

L'API api-adresse.data.gouv.fr est :

  • Officielle (data.gouv.fr / Etalab / IGN)
  • Gratuite sans clé API
  • Limites : usage raisonnable (50 req/sec recommandées max, ce qui est largement suffisant ici avec debounce 250ms)
  • Couverture : 100% des adresses France métropolitaine + DOM-TOM
  • Précision : score 0-1 dans chaque résultat (transparent sur la qualité du match)
