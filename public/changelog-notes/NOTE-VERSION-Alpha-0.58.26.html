🔁 Bouton "Rejouer la visite guidée" dans /profil

Nouveau panel bleu dans /profil → Sécurité. Permet à l'user de relancer le tour onboarding à tout moment (utile pour re-découvrir les nouveautés après une mise à jour).

// 0.58.26 - app/profil/page.js
import { resetOnboarding } from '../OnboardingTour';
import { useRouter } from 'next/navigation';

function ReplayTourButton() {
  const router = useRouter();
  function handleReplay() {
    resetOnboarding();  // reset legacy storage
    try { localStorage.removeItem('av-onboarding'); } catch {}
    router.push('/accueil');  // démarre auto à l'arrivée
  }
  return (
    <NeonButton variant="blue" icon="ti-route" onClick={handleReplay}>
      Rejouer la visite guidée
    </NeonButton>
  );
}

<Panel style={{ borderLeft: '4px solid #185FA5' }}>
  <h2>🛣 Visite guidée</h2>
  <p>Vous voulez (re)découvrir les fonctionnalités principales ?</p>
  <ReplayTourButton />
</Panel>

💀 Skeleton premium dans TabPanel

Le composant <TabPanel loading={true}> affiche désormais un skeleton structuré (header + 3 fields + grid 2 cards + 2 boutons). Pratique quand on charge le contenu d'un onglet en async.

// 0.58.26 - app/components/ui-premium/Tabs.js
export function TabPanel({ active, id, children, loading = false }) {
  return (
    <div key={active}>
      {loading ? <TabPanelSkeleton /> : children}
    </div>
  );
}

// Usage :
<TabPanel active="general" loading={loadingTab}>
  <RealContent />
</TabPanel>
