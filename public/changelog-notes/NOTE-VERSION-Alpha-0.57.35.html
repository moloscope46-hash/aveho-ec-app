🚨 Le problème : devices partagés (poste de soin)

Sur les devices partagés (poste de soin, tablette commune entre membres d'équipe), le logout user A laissait des traces accessibles à user B :

VecteurContenuSensibilité
localStorage "aveho:search-history"Patients recherchés via Cmd+K (nom, prénom, ID)🔴 PII forte
localStorage "aveho_dashboard"Config widgets accueil user A🟡 PII faible
SW DATA_CACHERéponses API Supabase mises en cache (patients, DI, prescriptions...)🔴 PII forte
SW PAGE_CACHEPages HTML rendues avec données user A🔴 PII forte
localStorage "etab-photo-*"Cache photos établissement🟡 PII faible
localStorage "ville:*"Cache géocodage ville → coords🟢 Aucune

Scénario d'attaque

  1. Infirmière A se connecte sur le poste de soin, recherche le patient "DUPONT Jean" via Cmd+K → entrée dans aveho:search-history
  2. Infirmière A se déconnecte (signOut Supabase)
  3. Infirmière B prend le poste, se connecte avec son propre compte
  4. Infirmière B ouvre Cmd+K → voit "DUPONT Jean" dans l'historique alors qu'elle n'a jamais cherché ce patient

CVSS estimé : 5.5 MEDIUM (exploitation locale uniquement, device partagé)

SW handler CLEAR_USER_CACHE

// public/sw.js — handler ajouté à la fin
self.addEventListener("message", (event) => {
  if (!event.data || event.data.type !== "CLEAR_USER_CACHE") return;

  event.waitUntil((async () => {
    try {
      // Vider DATA_CACHE (réponses Supabase REST/RPC)
      const dataCache = await caches.open(DATA_CACHE);
      const dataKeys = await dataCache.keys();
      await Promise.all(dataKeys.map((k) => dataCache.delete(k)));

      // Vider PAGE_CACHE (pages HTML)
      const pageCache = await caches.open(PAGE_CACHE);
      const pageKeys = await pageCache.keys();
      await Promise.all(pageKeys.map((k) => pageCache.delete(k)));

      // STATIC_CACHE conservé : assets immutables, partagés entre tous
    } catch {}

    if (event.ports?.[0]) {
      event.ports[0].postMessage({ ok: true, deleted: { data: N, pages: N } });
    }
  })());
});

Logout modifié dans UserMenu.js

async function logout() {
  setOpen(false);
  try {
    const { clearUserData } = await import("../lib/clearUserData");
    await clearUserData();  // ← purge AVANT signOut
  } catch {
    // graceful fallback : continue le logout même si erreur
  }
  await supabase.auth.signOut();
  router.push("/login");
}

🔒 18e LINT anti-régression critique

Garantit qu'aucun futur dev ne créera une clé localStorage qui ne serait pas purgée au logout :

it("Toutes les clés localStorage commencent par un préfixe purgeable", () => {
  const violations = [];
  // Scan app/ + lib/ pour localStorage.setItem("xxx", ...)
  for (const m of file.matchAll(/localStorage\.setItem\(\s*["']([^"']+)["']/g)) {
    const key = m[1];
    const isPurgeable =
      key.startsWith("aveho:") ||
      key.startsWith("aveho_") ||
      key.startsWith("ville:") ||
      key.startsWith("etab-photo-");
    if (!isPurgeable) violations.push(key);
  }
  expect(violations).toEqual([]);
  // ← FAIL si "patient-history" ou autre clé sans préfixe purgeable
});
