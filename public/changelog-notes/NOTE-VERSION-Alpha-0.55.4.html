🏢 Chantier 1 — Recherche SIRENE

Source officielle

API Recherche d'Entreprises (DINUM/INSEE) — https://recherche-entreprises.api.gouv.fr/search

  • Volume : ~40 millions d'entreprises et établissements français
  • Mise à jour : quotidienne (synchronisé Sirene INSEE)
  • Rate limit : 7 requêtes/seconde (très large)
  • Gratuit sans clé API
  • Licence : Licence Ouverte 2.0 (Etalab)

Stack technique

  • Route serveur app/api/sirene/route.js — proxy Next avec cache 1h, gère 3 modes :
    • ?q=... : recherche full-text (nom, raison sociale, sigle)
    • ?siret=14digits : récupération par SIRET exact
    • ?siren=9digits : récupération par SIREN exact (toute l'entreprise)
  • Composant frontend app/SireneSearch.js :
    • Détection automatique du format (9 chiffres = SIREN, 14 chiffres = SIRET, sinon nom)
    • Debounce 350 ms, minimum 3 caractères
    • Icône ti-building-store (différencie visuellement de FinessSearch)
    • Couleur ambre #EF9F27 pour le loader et le bandeau

Tabs dans le modal d'import

Le modal d'import (clic sur "+ Importer (FINESS/SIRENE)") propose maintenant 2 onglets en haut :

  • FINESS (établissements santé) — bord vert, icône ti-building-hospital
  • SIRENE (entreprises) — bord ambre, icône ti-building-store

Le bandeau d'aide en dessous change de couleur (vert pour FINESS, ambre pour SIRENE) et explique le contenu de chaque base. Le composant d'autocomplete affiché en dessous change selon l'onglet actif.

📞 Chantier 2 — Plugins ligne d'appel

Chaque ligne du tableau /etablissements a maintenant une rangée d'icônes d'action dans la colonne de droite. Chaque icône est cliquable indépendamment et s'adapte aux infos disponibles :

  • 📞 Téléphone (chip vert) — tel: link : sur mobile, déclenche un appel direct. Sur desktop, ouvre Skype/Teams/FaceTime selon config. Visible seulement si l'étab a un numéro renseigné.
  • 📧 Email (chip violet) — mailto: link : ouvre le client mail par défaut avec l'adresse pré-remplie. Visible seulement si email présent.
  • 🗺 GPS (chip bleu) — nouveau ! Ouvre l'itinéraire dans l'appli GPS par défaut. Visible seulement si GPS dispo. Ctrl+clic pour ouvrir le modal de choix d'appli.
  • 📄 Fiche (bouton outline) — Ouvre la fiche détaillée de l'étab.

Les boutons sont en grille 28×28 px avec hover, tous sur la même ligne. Tous ont leur title pour l'accessibilité. onClick stopPropagation pour éviter de déclencher la navigation parente du tr.

Détection auto au premier passage

  • Si iPhone/iPad détecté via UA → Plans (Apple) par défaut
  • Sinon → Google Maps par défaut

Modal de choix

2 façons d'ouvrir le modal :

  1. Cliquer sur le bouton "Appli GPS" dans la barre de filtres en haut → mode configOnly=true : juste enregistrer un défaut, ne pas ouvrir d'itinéraire
  2. Ctrl+clic (ou Cmd+clic sur Mac) sur l'icône GPS d'une ligne → mode nav : choisir + ouvrir l'itinéraire dans la foulée

Le modal affiche les 4 providers, chacun avec :

  • Icône colorée 36×36 px dans pastille arrondie
  • Nom + description courte
  • Badge "DÉFAUT" sur l'option active
  • Bouton (épingle) pour définir comme défaut sans ouvrir
  • Bouton "Ouvrir →" coloré pour utiliser + définir comme défaut

Helper réutilisable

Le fichier lib/gpsProvider.js expose :

import { openItinerary, openPin, getGPSProvider, setGPSProvider, GPS_PROVIDERS } from "@/lib/gpsProvider";

// Itinéraire vers un lieu (avec navigation)
openItinerary(48.8534, 2.3488, "Hôpital Cochin");

// Juste afficher un pin (sans nav)
openPin(48.8534, 2.3488);

// Récupérer le provider actif
const provider = getGPSProvider();  // { id, name, icon, color, urlNav, urlPin }

// Forcer un provider
setGPSProvider("waze");

Utilisable partout dans l'app : sur la carte, dans les fiches étab, partout où on veut un itinéraire.
