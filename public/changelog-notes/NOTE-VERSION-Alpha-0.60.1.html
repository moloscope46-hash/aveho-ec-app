🔗 3. Rattachement user magasin avec lock

Dans `/collaborateurs` édition, si rôle = "🏬 Utilisateur Magasin", nouveau bloc teal apparaît :

🏬 Magasin fournisseur rattaché
🔒 = magasin déjà rattaché à un autre utilisateur (un magasin = un user fournisseur)

Garanti par UNIQUE INDEX uq_ms_magasin_four en SQL : un magasin ne peut être lié qu'à un seul user. Save : magasin_fournisseur_id mis à null si rôle ≠ utilisateur_magasin.
