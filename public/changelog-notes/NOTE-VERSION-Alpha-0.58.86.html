🔗 Modèle relationnel

Le modèle gère 3 types de relations :

  • Véhicule → Établissement : vehicules.etablissement_id indique quel établissement possède le véhicule
  • Dépôt → Véhicule : depots.vehicule_id (0.58.85) indique si un dépôt mobile est installé sur un véhicule
  • Dépôt → Établissement : depots.etablissement_id (existant)

Permet de modéliser : "Une ambulance appartient à l'EHPAD X et embarque une réserve mobile Y" → visible dans les 2 onglets de l'établissement avec liens croisés.

🚛 Page /vehicules CRUD complète

Modal de création/édition avec champs :

  • Nom, couleur picker (intégré au card)
  • Type (Sanitaire / Ambulance / VSL / Taxi / Utilitaire / Autre)
  • Statut (Disponible / En mission / Maintenance / Hors service)
  • Établissement de rattachement
  • Immatriculation (auto-uppercase, mono) + N° agrément ARS
  • Marque, modèle, année
  • Capacités : personnes, brancards, kilométrage
  • Prochaine révision + Prochain CT
  • Notes

Consomme `?new=1&etablissement_id=X` depuis l'onglet Véhicules : le modal s'ouvre directement pré-rempli avec l'établissement courant
