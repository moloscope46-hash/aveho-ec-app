Comment utiliser la fiche HAD

📋

  1. Aller dans /had → liste tuiles
  2. Click sur une tuile → fiche détail
  3. 7 onglets accessibles via barre Tabs en haut
  4. Bouton 'Modifier' en haut-droite → bascule edit mode pour modifier les infos
  5. Pour chaque onglet (collab/vehic/garage/etab) : bouton 'Ajouter/Rattacher' ouvre une modal picker
  6. Onglet Carte : nécessite latitude/longitude de la HAD remplies (sinon message orange)
  7. Click sur patient → fiche patient classique
