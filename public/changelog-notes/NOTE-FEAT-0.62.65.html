ℹ Info / Tâche restante (2)

Workflow réception fournisseur en pratique

📋

  1. Magasin reçoit BL papier
  2. Va sur /magasin/receptions → clique sur la commande
  3. Saisit le N° BL fournisseur + date
  4. Pour chaque ligne : scan code-barres ou bouton 'Tout OK' pour réception conforme rapide, ou expand → saisit lot/série/péremption + conformité
  5. Si anomalie : sélectionne le type (Casse/Mauvaise ref/Périmée) + observation libre
  6. Prend des photos preuve (cam mobile direct ou fichier)
  7. Clique 'Valider' → BL créé en base + lignes traçabilité + qté commande mise à jour + statut auto. Tout est tracé pour audit qualité ISO
