🩹 1. Fix : tuiles "Vue d'ensemble" disparues sur /accueil

Bug : les tuiles 'Promotions actives', 'Commandes passées', 'En cours', 'À régler' (et la section 'À traiter en priorité') disparaissaient quand tu désactivais les widgets 'KPIs' OU 'À traiter' dans la personnalisation. Le HeroDashboard tout entier était englobé dans une condition qui le masquait totalement.

🎨 2. Cadre global sur toutes les pages

Délimitation visuelle subtile autour du contenu de chaque page — fini l'impression que les tuiles flottent sur du noir. Effet 'glassmorphique' avec backdrop-filter blur, bordure teal très discrète, border-radius 22px. Désactivé automatiquement en mode focus zen et présentation pour rester immersif.

🚀 3. Migration UI premium — 4 pages

Total cumulé : ~30 pages utilisent maintenant les composants UI premium (vs 26 avant). Migration de 4 pages cette release :

  • /journal (timeline activité) → SkeletonRow + EmptyState ti-history
  • /panier → EmptyState ti-shopping-cart-off avec bouton CTA "Voir les promotions"
  • /collectivite → SkeletonRow + EmptyState ti-building-skyscraper
  • /audit (RGPD) → SkeletonRow + EmptyState ti-search-off avec description détaillée
