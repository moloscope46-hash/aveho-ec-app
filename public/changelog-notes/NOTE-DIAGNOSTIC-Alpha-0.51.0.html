Les comportements observés sont volontaires :

Pourquoi le toast VersionCheck ne s'affichait pas

Le composant <VersionCheck /> ne montre un toast que quand il détecte un changement de version par rapport à ce qui est stocké en localStorage. Comportement :

  • 1er passage sur une nouvelle version : enregistre silencieusement la version dans localStorage["aveho_app_version"], sans afficher de toast (sinon faux positif à chaque connexion)
  • Passages suivants : compare la version récupérée via /api/version avec la stockée. Si différentes → toast

Donc une fois la 0.51 chargée et enregistrée, plus de toast jusqu'à la prochaine montée (0.52).

Pour tester :

localStorage.setItem("aveho_app_version", "0.50.0-alpha");
location.reload();
// Attendre 10 secondes après le reload → toast vert apparaît

Pourquoi la bannière annonce n'était pas visible

La bannière EST présente dans le DOM avec le contenu "FSFS— FFQS" (titre + message de l'annonce de test créée). Si elle n'apparaît pas à l'écran, c'est probablement parce que :

  1. La page est scrollée : la bannière est en position: sticky; top: 58px — elle se colle sous la TopBar. Mais sur certaines pages avec contenu long, si on a scrollé loin dans la page, il faut remonter en haut pour la voir.
  2. Un modal ou overlay est ouvert au-dessus (z-index supérieur).
  3. Le titre est petit et discret — la bannière niveau "info" est bleu pâle, peu contrastée. Elle peut passer inaperçue.

Pour la rendre flagrante visuellement :

const banner = document.querySelector('[role="alert"]');
banner.style.outline = "4px solid red";
banner.scrollIntoView({ behavior: "smooth", block: "center" });
setTimeout(() => { banner.style.outline = ""; }, 5000);
