Architecture défensive

🛡️ toutes les boucles dans DO blocks PL/pgSQL + détection présence tables (information_schema.tables) + détection colonnes nom/libelle (information_schema.columns) + format() + EXECUTE pour SQL dynamique + BEGIN/EXCEPTION/END pour ignorer colonnes manquantes + ON CONFLICT DO NOTHING partout. Compteurs RAISE NOTICE pour suivre l avancement dans les logs Supabase. Audit final : SELECT UNION ALL sur 9 tables clés avec leurs counts pour vérification visuelle
