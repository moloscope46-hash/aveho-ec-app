🐛 L'erreur webpack qui bloquait le déploiement

./app/materiel/[id]/page.js
Error: x Unexpected token. Did you mean `{'>'}` or `>`?
    ,-[C:\aveho-ec-app\app\materiel\[id]\page.js:502:1]
499 | {!mat.immobilisation_active ? (
500 | <div style={{ padding: "16px 18px", ... }}>
501 | <p style={{ margin: 0, fontSize: 13, color: "#1c5454" }}>
502 | Ce matériel n'est pas immobilisé. Pour les DM ≥ 500€ HT avec durée de vie > 1 an, l'immobilisation comptable permet l'amortissement linéaire ou dégressif.
    :                                                                                        ^

Cause : dans du texte plain JSX (entre `<p>` et `</p>`), le caractère `>` est interprété par le compilateur SWC comme une ouverture de tag JSX. Il faut soit l'échapper en entity HTML (`&gt;`), soit l'embarquer dans une expression JSX (`{'>'}`), soit réécrire le texte sans le symbole.

✅ Le fix appliqué

Option choisie : réécriture en texte humain (la plus claire pour les lecteurs)

// ❌ AVANT 0.58.73 — webpack crash
<p style={{ margin: 0, fontSize: 13, color: '#1c5454' }}>
  Ce matériel n'est pas immobilisé. Pour les DM ≥ 500€ HT
  avec durée de vie > 1 an, l'immobilisation comptable
  permet l'amortissement linéaire ou dégressif.
</p>
// ✅ APRÈS 0.58.73 — texte humain naturel
<p style={{ margin: 0, fontSize: 13, color: '#1c5454' }}>
  Ce matériel n'est pas immobilisé. Pour les DM ≥ 500€ HT
  avec durée de vie supérieure à 1 an, l'immobilisation
  comptable permet l'amortissement linéaire ou dégressif.
</p>

3 options équivalentes pour échapper `>` ou `<` dans du JSX text :
• durée de vie supérieure à 1 an (texte humain, choix retenu)
• durée de vie &gt; 1 an (entity HTML — fonctionne mais moins lisible)
• durée de vie {'\u007b\u0027>\u0027\u007d'} 1 an (expression JSX — verbeux)
