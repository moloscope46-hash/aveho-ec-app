AutoCompleteList composant générique

🔍 (130 lignes) : input + dropdown qui apparaît au focus avec liste cliquable. Features : (a) renderItem custom + getKey + filter custom, (b) maxResults configurable, (c) navigation clavier (Arrow Up/Down + Enter + Escape), (d) hoverIdx pour mise en évidence à la souris, (e) close on click outside (mousedown listener), (f) animation av-autocomplete-fade 200ms, (g) emptyText configurable, (h) accentColor pour personnaliser le hover, (i) borderLeft 3px coloré sur item hovered + background gradient subtle. À utiliser partout où on a un champ avec suggestions
