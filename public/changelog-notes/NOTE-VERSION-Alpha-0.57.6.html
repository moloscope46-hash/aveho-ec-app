⚡ Fix 1 — Lazy load CodeViewer + SqlModal (next/dynamic)

Les modaux CodeViewer (popup de code snippet) et SqlModal (popup de SQL) étaient importés statiquement dans app/changelog/page.js. Résultat : leur code était inclus dans le bundle initial de /changelog, même si l'utilisateur ne cliquait JAMAIS dessus.

Avant 0.57.6

import CodeViewer from "./CodeViewer";
import SqlModal from "./SqlModal";

// → ces 2 composants (~10 kB combinés) sont dans le bundle
//   initial de /changelog dès le premier chargement

Après 0.57.6

import dynamic from "next/dynamic";

// 0.57.6 : lazy-loadés (chargés à la demande)
const CodeViewer = dynamic(() => import("./CodeViewer"), { ssr: false });
const SqlModal = dynamic(() => import("./SqlModal"), { ssr: false });

// → ces composants sont dans des chunks séparés que webpack
//   ne télécharge QUE quand l'utilisateur ouvre une modale

L'option ssr: false est cohérente car ces modaux utilisent useState, useEffect, navigator.clipboard, document.addEventListener (ESC) — du code purement navigateur sans rendu serveur utile.

🚀 Fix 2 — smoke-tests-index : badge léger + lazy load 92 KB

Le fichier app/changelog/smoke-tests.js fait 92 KB (56 versions avec leurs tests in-browser). Il était importé statiquement juste pour faire VERSION_TESTS[v.v] dans le rendu — un simple "boolean lookup" pour afficher un badge "tests dispo".

Solution : nouveau fichier app/changelog/smoke-tests-index.js (~3 KB) :

  • Export VERSION_TESTS_KEYS : un Set JS avec juste les clés de versions. Léger.
  • Export runTestsForVersionLazy(version) : wrapper qui charge smoke-tests.js en await import("./smoke-tests") et exécute les tests. Appelé seulement quand l'utilisateur clique sur "Tester".
  • Export runAllTestsLazy(onProgress) : pareil pour "Tester tout".
// smoke-tests-index.js (3 KB)
export const VERSION_TESTS_KEYS = new Set([
  "0.55.18", "0.55.24", ..., "0.57.6",  // 56 clés
]);

export async function runTestsForVersionLazy(version) {
  const mod = await import("./smoke-tests");  // 92 KB chunk
  return mod.runTestsForVersion(version);
}

Dans page.js

// Avant 0.57.6
import { VERSION_TESTS, runTestsForVersion, runAllTests } from "./smoke-tests";
// → 92 KB chargés à chaque visite de /changelog
// ...
background: VERSION_TESTS[v.v] ? "#5aa05a" : "#8a98a8",
const results = await runTestsForVersion(version);

// Après 0.57.6
import { VERSION_TESTS_KEYS, runTestsForVersionLazy, runAllTestsLazy } from "./smoke-tests-index";
// → 3 KB pour le badge
// ...
background: VERSION_TESTS_KEYS.has(v.v) ? "#5aa05a" : "#8a98a8",
const results = await runTestsForVersionLazy(version);
// → 92 KB téléchargés UNIQUEMENT au moment du clic

Économie nette : 89 KB sur les visites sans interaction de test.
