🚨 1. FIX build Vercel (régression 0.58.59)

Symptôme : build Vercel échouait avec Expected sur DashboardWidgets.js:2414.

Cause : un str_replace antérieur a injecté un nouveau backdrop dans le modal sans retirer l'ancien → 14 <div> ouverts pour 13 </div> fermés → parser SWC perdu.

// AVANT 0.58.60 (cassé)
{teamPickerOpen && (
  <div onClick={...} style={{...}}>          ← backdrop #1
    <div onClick={...} style={{...}}>        ← backdrop #2 DUPLIQUÉ
      <div>modal content</div>
    </div>                                    ← ferme #2
  </div>                                      ← ferme #1
)}
// = 1 div manquant → parser explose

// APRÈS 0.58.60 (fixé)
{teamPickerOpen && (
  <div onClick={...} style={{...}}>          ← backdrop unique
    <div>modal content</div>
  </div>
)}

👥 3. Filtre Équipe dans la TopBar

À la suite des sélecteurs Bâtiment et Service, nouveau dropdown Équipe avec icône ti-users-group dans la couleur de l'équipe sélectionnée. Charge automatiquement les équipes du bâtiment courant. Persisté en localStorage et propagé via l'event av-current-context-change avec le nouveau champ equipeId.

🏢 4. Icônes personnalisées pour bâtiments + services

SQL à exécuter dans Supabase :

ALTER TABLE batiments ADD COLUMN IF NOT EXISTS icone TEXT;
ALTER TABLE services ADD COLUMN IF NOT EXISTS icone TEXT;

COMMENT ON COLUMN batiments.icone IS '0.58.60 - Nom Tabler (sans ti-) ex: building-hospital';
COMMENT ON COLUMN services.icone IS '0.58.60 - Nom Tabler (sans ti-) ex: stethoscope';

Dans /etablissement/edition, le modal de création/édition d'un bâtiment ou service inclut maintenant un IconPicker avec auto-suggestion basée sur le nom. L'icône choisie remplace l'EntityIcon générique dans la liste et apparaît dans le sélecteur de la TopBar.
