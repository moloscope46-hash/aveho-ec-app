🔍 Chantier AF — Recherche globale ⌘K avec chips de filtre

Avant

La palette ⌘K / Ctrl+K permettait déjà la recherche multi-table (patients, matériels, DI, signalements, achats, transferts, maintenances, consents, fournisseurs) via préfixes au clavier (p:, m:, d:, etc).

Mais ces préfixes étaient peu découvrables, surtout pour les utilisateurs occasionnels.

Après

Une barre de chips visuels apparaît directement sous l'input de recherche. Chaque chip = une catégorie cliquable (couleur thématique + icône) :

  • Chip "Tout" (sombre) — pas de filtre, recherche dans tout
  • Chip "Patient" (bleu), "Matériel" (teal), "DI" (rouge), "Signalement" (violet), "Achat" (ambre), "Transfert" (vert), "Maintenance" (sombre teal), "Consentement" (vert), "Fournisseur" (terra)

Clic → la recherche se restreint à cette catégorie. Re-clic sur le même chip → désactivation (retour à "Tout").

Les préfixes au clavier (p:dupont) fonctionnent toujours en plus — la chip override le préfixe si les deux sont actifs.

Implémentation

// Nouveau state
const [activeFilter, setActiveFilter] = useState(null);

// La recherche : chip override préfixe
if (activeFilter) filterType = activeFilter;

// UI chips juste après input
<button onClick={() => setActiveFilter(activeFilter === key ? null : key)}>
  <i className={`ti ${t.icon}`} /> {t.lbl}
</button>

📊 Chantier AI — Export Excel sur les listes principales

Helper générique exportRows()

Nouveau helper dans lib/exportExcel.js à côté du exportBilan() existant. Utilisable depuis n'importe quelle page :

const { exportRows } = await import("../../lib/exportExcel");
await exportRows(filtered, {
  filename: `etablissements_${new Date().toISOString().slice(0,10)}`,
  sheetName: "Établissements",
  columns: {
    "Nom": "nom",
    "Type": (r) => r.type || "",
    "Adresse": "adresse",
    "Partenaire": (r) => r.est_partenaire ? "Oui" : "Non",
    "Latitude": (r) => r.latitude ?? "",
  },
});

Features : auto-width des colonnes (basé sur le contenu max), nom de feuille tronqué à 31 caractères (limite Excel), filename auto-suffixé avec date ISO.

Bonus — Migration CDN → npm (Réflexe 19)

L'ancien exportExcel.js chargeait SheetJS depuis cdn.jsdelivr.net. Mais Edge/Brave bloquent ce CDN via "Tracking Prevention". Migration vers npm xlsx + dynamic import.

// Avant : CDN script tag (bloqué par Edge)
script.src = "https://cdn.jsdelivr.net/npm/xlsx@0.18.5/...";

// Après : dynamic import npm (bundlé par Next)
const XLSX = await import("xlsx");

👁 Chantier UI — Tooltip hover preview HTML sur changelog

Le concept

Sur la page /changelog, quand tu passes la souris sur :

  • Le titre d'une version (h3 avec badge v0.xx.x)
  • Une évolution de la timeline (li avec code "AF", "FE", etc.)

… un popup flottant 250ms après le hover apparaît juste à côté du curseur, affichant le rendu HTML complet de la note de version.

Détails techniques

  • Cache : le HTML d'une note n'est fetché qu'une seule fois (puis stocké dans noteCacheRef). Re-survol → instantané.
  • Délai 250ms avant fetch pour éviter de spammer si la souris passe vite sur plusieurs items.
  • Scoping CSS : on extrait <body> et <style> de la note. Les sélecteurs body sont réécrits en .hover-note-scope pour ne pas casser le layout de la page changelog.
  • Positionnement intelligent : à droite du curseur si y a la place, sinon à gauche. Idem haut/bas. Boîte 460×460 max avec scroll interne.
  • pointer-events:none sur le popup → ne bloque pas la souris, on peut continuer à naviguer.
  • Suit la souris via onMouseMove pour rester collé.

Indicateur visuel

Au survol, le li de l'évolution prend un fond jaune doux (#fef9ed) et le curseur passe en mode help (point d'interrogation) pour indiquer qu'il y a quelque chose à voir.

🧹 Chantier OPS — Cleanup dossier dupliqué

Pendant la session marathon de la nuit précédente, le robocopy avait foiré et créé un sous-dossier aveho-ec-app/aveho-ec-app/ dans le repo (701 fichiers committés au lieu de ~350).

Vercel s'en foutait (build OK car le package.json à la racine était correct), mais c'était sale et alourdissait le repo.

Procédure de nettoyage

cd C:\aveho-ec-app
# Supprime le sous-dossier dupliqué
Remove-Item -Recurse -Force aveho-ec-app -ErrorAction SilentlyContinue
git add -A
git commit -m "Cleanup - retire dossier duplique aveho-ec-app/aveho-ec-app/"
git push origin main

~350 fichiers en moins dans le repo, build Vercel plus rapide.
