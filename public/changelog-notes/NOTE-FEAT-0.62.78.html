PageHead MOBILE GLASSMORPHISM

✨ sur <768px le PageHead devient une bannière premium edge-to-edge (margin -12 -12) avec gradient animé linear-gradient navy→teal→light-teal (background-size 200%, animation av-hero-gradient-shift 8s ease-in-out infinite). Pseudo-element ::before radial-gradient ellipse top teal/15 (effet halo). Border-radius 0 0 22px 22px + box-shadow 6px navy. Icône bulle gradient teal-navy avec shadow teal 45% + inset shine + backdrop-filter blur. Titre background-clip text gradient blanc→bleu pâle + text-shadow noir 30%. Subtitles passent en rgba(255,255,255,.85) avec text-shadow. Effet wow : surcharge mobile sans toucher au desktop

🐛 Fix bug (1)

Sidebar magasin mobile : titres des sections visibles

🔧 la prop collapsed était persistée localStorage et appliquée même en mobile, ce qui cachait les section headers (Tableau de bord, Stock, Catalogue, etc.). Fix : detection isMobile via window.innerWidth <= 900 + force collapsed=false en mobile. Les titres apparaissent maintenant correctement dans le burger menu mobile avec leurs icônes + chevrons repli/déplie individuels

ℹ Info / Tâche restante (2)

Usage des composants graphiques

🎨 import { ChartCard, BarChartPremium, DonutChartPremium, StatCardPremium, SparklineMini } from 'app/components/ChartCard';. Exemple stats SAV : <ChartCard title='Top 5 SAV' icon='ti-tools' accent='#e35d5b'><BarChartPremium data={[{label:'Pompes',value:23,color:'#185FA5'},{label:'Lits',value:18,color:'#7CC8C8'}...]}/></ChartCard>. Exemple taux dispo : <DonutChartPremium value={87} label='Dispo' color='#5aa05a' icon='ti-check'/>. Exemple KPI : <StatCardPremium label='Patients' value='124' icon='ti-users' color='#7a6fb0' trend='+12%' trendDir='up'/>
