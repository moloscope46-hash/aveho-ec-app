workflowHelpers (lib/workflowHelpers.js)

  1. listTemplatesForResource : récupère les templates filtrés sur resource_type ET resource_type=*
  2. applyTemplate : applique un template en créant les workflow_steps. Match role_label → role_id via fetch roles. Supprime les anciens steps avant insert pour éviter doublons. Retourne {ok, stepsCreated} ou {ok:false, error}

TemplatesSelector dans WorkflowApproval

🎯 quand un workflow n existe pas encore pour la ressource, affiche une grille de templates disponibles avec icône + nom + description + nb_étapes. Click → apply (avec confirm via toast). Visible UNIQUEMENT pour admin (canTrigger). Style premium cards 220px avec hover lift + shadow color du template

SLARespectWidget

📊 gauge circulaire SVG du pourcentage d interventions résolues dans les délais SLA. SLA défini par urgence : Critique=4h, Élevée=24h, Normale=72h, Faible=168h. Gauge animée : circle stroke vert/ambre/rouge selon pct (>=90% / >=70% / <70%) + stroke-dasharray transition 1s cubic-bezier. Stats : 2 cards Dans les délais (vert) / Dépassement (rouge)

ChargeEquipesWidget

📊 top 5 équipes avec le + d interventions en cours (Nouvelle/En cours/Planifiée). Bullet coloré : vert <5, ambre 5-10, rouge >=10. Barres progress proportionnelles à la charge max + transition cubic-bezier 800ms. Permet de voir d un coup d œil les surcharges et déséquilibrer la charge

PlanningCalendar drag&drop WeekGrid

📅 ajout des handlers HTML5 dans WeekGrid identique au MonthGrid. Events draggable avec onDragStart sérialise event en JSON. Days droppables avec onDragOver preventDefault + change background + onDrop calcule nouvelle date (préserve heure) + update DB selon préfixe (intv-/evt-/tour-) + toast + reload. Maintenant les 2 vues Mois et Semaine supportent le drag&drop

useRealtimeNotifs log dans notifs_log

🔔 modification de la branche DI urgentes pour insérer dans notifs_log à chaque notif émise. Permet de garder une trace consultable de toutes les notifications auto envoyées (qui, quand, quoi, niveau). Insert silencieux dans try/catch pour ne pas bloquer en cas d erreur SQL

Page /audit/notifs

📋 historique complet des notifications auto. 5 stat cards : Total + DI urgentes + Workflows + Signalements + Non acquittés (highlight rouge si >0). Toolbar : recherche titre/message + filtre type + filtre niveau + bouton Acquitter tout. Liste cards : icône type + titre bold + message + date + 3 badges colorés (type, niveau, non acquitté) + bouton Voir si link. Empty state si vide ou recherche sans résultat. 500 dernières notifs chargées
