Fallback générique

Pour chaque version sans tests dédiés, on génère automatiquement :

  • Entrée présente dans versions-data (intégrité du changelog)
  • Note HTML accessible via fetch /changelog-notes/{noteFile}
  • Fichier SQL accessible via fetch /changelog-sql/{sqlFile} (si applicable)
  • Description chantiers présente (au moins 1 chantier décrit)

Suffisant pour valider qu'une release ancienne reste intègre après les changements récents.

  • Bouton "Relancer tout" en bas pour ré-exécuter

Code

export async function runAllTests(onProgress) {
  const versions = ALL_VERSIONS.map(v => v.v);
  const report = { versions: [], totalOk: 0, totalFail: 0, completed: 0, total: versions.length };

  for (const version of versions) {
    onProgress?.({ ...report, current: version });
    const results = await runTestsForVersion(version);
    const ok = results.filter(r => r.ok).length;
    const fail = results.length - ok;
    report.versions.push({ version, results, ok, fail });
    report.totalOk += ok;
    report.totalFail += fail;
    report.completed++;
  }
  onProgress?.({ ...report, done: true });
  return report;
}
