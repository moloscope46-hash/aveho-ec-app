🗄 1. SQL — Compteur de requêtes API

Table api_usage_log

  • id, structure_id, user_id : qui a fait l'appel
  • api_name : 'google_places', 'rpps', 'finess', 'sirene', 'ban_insee'
  • endpoint : 'findplacefromtext', 'details', etc.
  • status : 'ok' / 'error' / 'no_key' / 'cache_hit'
  • http_status, error_message, duration_ms
  • created_at

Vue v_api_usage_current_month

Agrégat par api_name pour le mois en cours : calls_ok / calls_error / calls_no_key / calls_cached / calls_total + avg_duration_ms.

3 RPCs

  • get_api_usage_stats() — récupère les stats (admin uniquement)
  • log_api_call(api_name, endpoint, status, http_status, error_msg, duration_ms) — utilisé par les route handlers
  • cleanup_old_api_logs() — supprime les logs > 90 jours

RLS

  • INSERT pour tous les authentifiés (via RPC log_api_call)
  • SELECT uniquement pour parametres_admin
