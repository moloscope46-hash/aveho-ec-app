⚠ ACTION REQUISE : ajouter la clé Google Places API

Pour avoir les vraies photos qui correspondent à l'adresse, les horaires d'ouverture, les étoiles et les avis Google, il faut une clé Google Places API.

Procédure (5 min, ~$0 si peu d'utilisation)

  1. Aller sur console.cloud.google.com/google/maps-apis
  2. Créer un projet si besoin
  3. Activer Places API (la nouvelle ou l'ancienne, l'ancienne est utilisée ici)
  4. Créer une API Key et la restreindre par référent HTTP (aveho-ec-app.vercel.app/*)
  5. Sur Vercel, ajouter dans Settings → Environment Variables : 
    GOOGLE_PLACES_API_KEY=AIzaSy...
  6. Redeploy

Tarification : 1000 requêtes gratuites/mois (les appels sont cachés 24h côté serveur + 7 jours côté client). Au-delà : ~$17/1000 req.

Sans la clé : l'app continue de fonctionner, juste avec le fallback gradient propre. Aucun crash.

2. Nouveau composant EtabPhoto basé sur Google Places

Le composant fait 1 seul appel à notre proxy /api/place qui :

  1. Appelle findplacefromtext avec nom + adresse complète → garantit la correspondance géo
  2. Récupère le place_id du résultat
  3. Appelle details pour récupérer en 1 fois : photo, rating, user_ratings_total, opening_hours, formatted_phone_number, website, url

Le proxy serveur cache la clé API (jamais exposée au navigateur). Cache Next.js 24h + localStorage 7 jours côté client.

4. Système d'alertes commentaires Google

SQL : table user_review_alert_prefs

Stocke les préférences par utilisateur ET par établissement :

  • enabled : on/off
  • min_rating / max_rating : seuils (ex : alerte si rating ≤ 2 pour les mauvais avis)
  • etablissement_kind : 'mine' ou 'partner'

Table google_reviews_seen

Historique pour ne pas re-notifier le même avis. Index unique sur (structure_id, etablissement_id, google_review_id).

RPCs

  • get_my_review_alert_prefs() : récupère les préférences du user courant
  • set_review_alert_pref(etab_id, kind, struct_id, enabled, min, max) : upsert

5. Popup d'alerte 20s (AlertToast)

Composant global AlertToast.js avec API showAlert() utilisable de n'importe où :

import { showAlert } from './components/AlertToast';

showAlert({
  type: 'google_review',
  title: 'Nouvel avis 5⭐ sur EHPAD Les Tilleuls',
  message: 'Marie D. : "Personnel formidable…"',
  rating: 5,
  onClick: () => router.push('/etablissement/fiche?id=...'),
});

Caractéristiques

  • Apparaît en bas à droite, animation d'entrée slide-in
  • Disparaît automatiquement après 20s (configurable via duration)
  • Barre de progression du timer en bas (s'amenuise)
  • Couleur selon rating : vert ≥4★, ambre 3★, rouge ≤2★
  • Plusieurs alertes empilées si besoin
  • Click → action custom (redirection vers fiche etab)
  • Bouton ✕ pour fermer manuellement

Note : la sync réelle des avis Google nécessite un job cron (Edge Function) qui sera ajouté en 0.55.39 quand la clé Google sera configurée. Pour l'instant, tu peux déclencher des alertes manuellement via showAlert().
