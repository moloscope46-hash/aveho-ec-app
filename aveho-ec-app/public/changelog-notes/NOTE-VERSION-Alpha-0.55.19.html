🎯 Le concept

Une barre de statut dans la TopBar pour voir d'un coup d'œil ce qui est activé / autorisé / dispo sur l'appareil courant. Comme la barre de statut système d'un téléphone mais pour Aveho EC.

Chaque icône a une petite pastille colorée en bas à droite :

  • Vert — feature active / autorisée / OK
  • Rouge — feature refusée / bloquée / KO
  • Gris — feature non configurée / indéterminée

👆 Au clic sur une icône → popover détail

Largeur 280px, ancré sous l'icône. Contient :

  1. Header coloré avec icône grande taille + libellé + état (✓ Activé / ✗ Refusé / ○ Non configuré)
  2. Description contextuelle (ex. "Notifications bloquées (réglages navigateur)")
  3. Bouton d'action selon état :
    • Notification "default" → bouton Autoriser qui appelle Notification.requestPermission()
    • Géoloc "prompt" → bouton Autoriser qui appelle geolocation.getCurrentPosition()
    • Empreinte/Face inactive → bouton Gérer qui redirige vers /profil
    • Si denied : pas de bouton (impossible de re-demander, il faut passer par les réglages navigateur) — info donnée dans la description

📱 Responsive mobile

Sur écran ≤ 520px, on cache les icônes secondaires (Service Worker, Empreinte, Face) pour ne pas saturer la TopBar. Les 4 plus importantes restent visibles :

  • Réseau (critique en mobile)
  • Notifications
  • Géolocalisation
  • PWA installée

Les autres restent accessibles via le menu Profil → Connexion biométrique.

🛠 Architecture

Composant app/StatusIcons.js

  • State status avec tous les flags
  • useEffect au mount qui calcule l'état initial + écoute online/offline events
  • Construction d'un array features[] avec { id, icon, label, ok, ko, desc, action }
  • Render : boutons avec icône + pastille colorée. État ouvert = popover affiché en dessous
  • Backdrop transparent pour fermer le popover au clic en dehors

Intégration TopBar

{mounted && auth && <StatusIcons auth={auth} />}
{mounted && auth && <UserMenu auth={auth} />}

Monté juste avant UserMenu (les 3 points), donc apparaît à gauche de celui-ci dans le flow horizontal.
