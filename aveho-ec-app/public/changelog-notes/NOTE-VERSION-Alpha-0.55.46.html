📋 Audit & cible : un bulletin de situation hospitalier

Sources consultées : service-public.fr, ameli.fr, drees.solidarites-sante.gouv.fr, transformation.gouv.fr, annuaireamc.fr.

Un bulletin de situation contient :

  • Identité : nom, prénom, nom de naissance, sexe, date et lieu de naissance, nationalité
  • N° de sécurité sociale (NIR — 15 chiffres dont la clé)
  • Caisse d'affiliation + code organisme de rattachement (9 chiffres)
  • Régime (général / agricole / militaire / spécial)
  • Mutuelle (AMC) avec n° AMC (8 chiffres) + n° adhérent
  • Adresse sociale + adresses de livraison séparées si besoin
  • Téléphones (fixe + portable) + email
  • Personne à prévenir (urgence) + personne de confiance
  • Médecin traitant (nom, prénom, tel, RPPS, FINESS étab)
  • Droits : date début/fin, ALD, CMU-C / C2S, AME

Tout est dans la nouvelle fiche.
