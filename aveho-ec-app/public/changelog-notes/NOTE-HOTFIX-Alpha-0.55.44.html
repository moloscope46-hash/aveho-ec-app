❌ Le bug

ERROR: 42703: column "rpps" does not exist
LINE 26: create index if not exists idx_etab_part_rpps on etablissements_partenaires(structure_id, rpps) ...

La table etablissements_partenaires n'avait jamais eu de colonne rpps (elle n'a été utilisée par RppsAutocomplete que récemment). Le patch 0.55.43 tentait de créer un index dessus sans d'abord créer la colonne.

✅ La correction

Patch 0.55.44 — ordre correct

  1. 1) ALTER TABLE etablissements_partenaires ADD COLUMN IF NOT EXISTS rpps text, adeli text, profession text, specialite text
  2. 2) Recrée les colonnes traçabilité doublon (doublon_force_*)
  3. 3) Crée les 5 index (FINESS, SIRET sur les 2 tables + RPPS)
  4. 4) Recrée la RPC check_etab_doublon
  5. 5) Recrée la vue v_doublons_forces

Patch 100% idempotent

Toutes les instructions utilisent IF NOT EXISTS / OR REPLACE. Tu peux le rejouer même si le 0.55.43 a partiellement échoué.
