❌ Les 2 bugs

Bug 1 : Géoloc bloquée sur Lagny au lieu de Mayrinhac

Le code lisait toujours la dernière position depuis localStorage avec un TTL de 24h. Donc quand tu te déplaçais d'une journée à l'autre (ou même quelques heures), la map affichait toujours ta position d'hier.

De plus, enableHighAccuracy: false → utilisait la triangulation IP (souvent imprécise au km près) plutôt que le GPS Windows.

Bug 2 : Filtres RPPS/SIRENE vides sur la carte

L'API FHIR ANS renvoie l'adresse texte mais pas de lat/lng. L'API SIRENE renvoie les coords seulement quand l'INSEE les a calculées (~70% des entreprises).

Résultat : filter(p => p.latitude && p.longitude) excluait tous les résultats → 0 marker sur la carte.

✅ Fix 1 : Géoloc fresh + GPS

Bouton "Ma position" refondu

navigator.geolocation.getCurrentPosition(
  success, error,
  {
    enableHighAccuracy: true,   // ← GPS si dispo (était false)
    timeout: 15000,              // ← 15s (était 8s)
    maximumAge: 0,               // ← JAMAIS de cache (était 60s)
  }
);

Nouveau bandeau indicateur

Sous le bouton "Ma position" :

  • "Localisation…" avec spinner pendant la requête
  • "±50m · maj à l'instant" en vert si précision GPS (<1km)
  • "±2500m · maj à l'instant" en rouge si précision IP (>1km) → indique qu'il faut activer le GPS Windows

Messages d'erreur enrichis

  • Permission refusée : instructions précises par navigateur (Chrome cadenas, Edge permissions, mobile paramètres)
  • Timeout : "vérifie que la géolocalisation est activée dans Paramètres → Confidentialité → Localisation"

Comment activer le GPS Windows

  1. Touche Windows → "Paramètres de confidentialité"
  2. Confidentialité → Localisation
  3. Activer "Service de localisation" + "Autoriser les apps à accéder à votre position"
  4. Dans Chrome/Edge : icône cadenas dans la barre d'adresse → Géolocalisation → Autoriser
  5. Recharger la page /carte et cliquer "Ma position"

✅ Fix 2 : Géocodage BAN INSEE pour la carte

Nouveau pipeline pour RPPS + SIRENE

  1. API renvoie résultats avec adresse + cp + commune
  2. Pour chaque résultat sans lat/lng → on construit la query "12 rue X 75011 Paris"
  3. Appel à api-adresse.data.gouv.fr/search/?q=...&limit=1 (gratuit, sans clé)
  4. Extraction features[0].geometry.coordinates → [lng, lat]
  5. Cache localStorage par query (jamais regéocodé tant que l'adresse change pas)
  6. Filtre bbox côté client → markers visibles

SIRENE recherche par proximité

L'API SIRENE supporte ?lat=X&long=Y&radius=50. Désormais la requête est centrée sur la zone visible de la carte → meilleur ratio résultats/bbox.

Hints quand 0 résultat

Si après recherche tu as 0 marker → bannière ambre : "Aucun praticien trouvé dans la zone visible. Zoome plus large ou déplace la carte vers une grande ville."
