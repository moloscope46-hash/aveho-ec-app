Résumé

La PWA Aveho EC existait depuis la 0.16 avec service worker, manifest minimal et 4 icônes basiques. La 0.36 finalise tout l'écosystème PWA pour une installation propre sur tous les devices : iPhone, iPad, Android, Windows, Mac.

Tout est généré côté Aveho. Aucune dépendance externe ni service tiers. Les icônes et splash screens sont produits à partir d'un script Python (PIL + DejaVu fonts) embarqué dans le repo. Reproductible à volonté si on veut rebrander.

1. Génération d'icônes (script reproductible)

Le script Python /tmp/gen-icons.py produit toute la collection. 13 tailles standard couvrant tous les contextes :

  • 16 / 32 px : favicons navigateur
  • 72 / 96 / 128 / 144 px : Android petit, Windows tile
  • 152 / 180 px : iPad + Apple touch icon
  • 192 / 384 / 512 px : standard PWA + stores
  • 192 / 512 px maskable : safe zone 80% pour le clip masque Android

Le design : fond navy #142131 coins arrondis size/8, lettres "av" centrées en blanc + teal (le "v" en accent teal #7CC8C8 conforme à la charte Aveho).

3. Manifest enrichi

Nouveaux champs

  • lang: "fr-FR" + dir: "ltr" — pour les stores et a11y
  • categories: ["medical", "productivity", "business"] — classification stores
  • prefer_related_applications: false — on est la version officielle, pas de redirection
  • id: "/accueil" — identifiant unique de l'app (recommandation W3C 2023)
  • 12 icônes référencées au lieu de 4

3 shortcuts (raccourcis app)

Affichés en appui long sur l'icône Android et dans le menu contextuel Windows :

  • 🏥 Patients → /patients
  • 🔧 DI → /interventions
  • 🛒 Achats → /achats

4. InstallBanner contextuel

Logique d'apparition

// Apparition différée 30s après le chargement
// Conditions : pas déjà installé, beforeinstallprompt dispo OU iOS
// Stockage localStorage : aveho:install-banner
//   - { dismissed: "forever" }  → jamais plus
//   - { snoozedUntil: timestamp } → masqué jusqu'à cette date

3 actions utilisateur

  • Installer (Chrome/Edge/Brave) → prompt natif du navigateur
  • Plus tard → snooze 7 jours puis ré-apparition
  • × en haut à droite → "ne plus afficher" définitif

Mode iOS Safari

Safari ne supporte pas beforeinstallprompt. Détection via UA (et exclusion de Chrome iOS, Firefox iOS, Edge iOS qui passent leurs propres params). En iOS Safari, le banner affiche un encart d'instructions :

Sur iOS, appuie sur 🔗 dans Safari puis sur « Sur l'écran d'accueil ».

Style

Bandeau navy en bas, max 420px de large, centré sur mobile, slide-up animé à l'apparition. Évite d'être intrusif.

5. CSS PWA

Mode standalone (app installée)

@media all and (display-mode: standalone) {
  body { 
    padding-top: env(safe-area-inset-top);     /* notch iPhone */
    padding-bottom: env(safe-area-inset-bottom); /* home indicator */
    overscroll-behavior-y: contain;             /* pas de pull-to-refresh */
  }
}

Touch optimizations (mobile/tablette)

@media (pointer: coarse) {
  .tb-icon, .burger { min-width: 44px; min-height: 44px; }  /* spec Apple */
  input, select, textarea { 
    min-height: 40px; 
    font-size: 16px;  /* évite zoom auto iOS au focus */
  }
}

Smoothing

  • -webkit-tap-highlight-color: transparent en mode app
  • -webkit-font-smoothing: antialiased

Procédure d'application

  1. Pas de SQL à appliquer.
  2. Pas de redéploiement Edge Function.
  3. Décompresser le zip par-dessus C:\aveho-ec-app\. Inclut 26 nouveaux PNG (icônes + splash).
  4. Nettoyer le cache + npm install + tests + dev : 
    cd C:\aveho-ec-app
Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
npm install
npm test       # 478 passed
npm run dev
  5. Important : forcer le rafraîchissement du Service Worker pour qu'il prenne en compte les nouveaux assets :
    • F12 → Application → Service Workers → Unregister
    • F12 → Application → Storage → Clear site data
    • Ferme l'onglet, rouvre
  6. Tester :
    • F12 → onglet Application → Manifest : vérifier que les 12 icônes sont listées, les 3 shortcuts présents
    • F12 → onglet Lighthouse → audit PWA → devrait passer à 90+/100
    • Attendre 30s sur la page → l'InstallBanner doit apparaître en bas (Chrome desktop ou Android)
    • Clic "Installer" → fenêtre native d'installation → l'app apparaît dans la liste des apps installées de l'OS
    • Sur iPhone Safari : ouvrir l'app, attendre 30s, voir le banner avec instructions iOS
    • Une fois installée : icône Aveho brandée sur l'écran d'accueil, lancement avec splash screen

Validation PWA Lighthouse

Pour valider l'installation correcte, exécuter un audit Lighthouse :

  1. Chrome → F12 → onglet Lighthouse
  2. Cocher uniquement Progressive Web App
  3. Mode : Mobile
  4. Clic "Analyser le chargement de la page"

Critères couverts par la 0.36 :

  • ✅ Installable
  • ✅ Has a viewport meta tag

  • ✅ Themed for splash screen
  • ✅ Web app manifest meets the installability requirements
  • ✅ Contains a maskable icon
