🩺 1. Annuaire RPPS — page dédiée

Le FINESS ne couvre que les établissements. Pour les professionnels libéraux (médecin de ville, IDE libéral, kiné, sage-femme, pharmacien d'officine, etc.) il faut le RPPS (Répertoire Partagé des Professionnels de Santé).

Nouvelle page /annuaire-rpps

Accessible depuis le menu TopBar → section Établissement → Annuaire RPPS (libéraux)

Champs de recherche

  • Nom de famille (recherche dans le nom d'exercice)
  • N° RPPS (11 chiffres exactement, recherche exacte) — désactive les autres champs
  • Profession : Médecin / Infirmier(ère) / Kinésithérapeute / Pharmacien / Sage-femme / Chirurgien-dentiste
  • Code postal (5 chiffres)

Affichage des résultats

  • Carte cliquable par praticien (icône ti-user-circle dans cercle bleu)
  • Nom + prénom + civilité (Dr, Mme, M.)
  • Profession + spécialité en bleu
  • Adresse + CP + commune + téléphone en gris
  • Ligne mono : RPPS + ADELI
  • Au clic → modale détails avec téléphone cliquable (tel:) et email (mailto:)

🔌 2. API /api/rpps — proxy serveur

Endpoint

GET /api/rpps?q=DUPONT&profession=Médecin&cp=75011
GET /api/rpps?rpps=10000000001
GET /api/rpps?profession=Infirmier&cp=46500

Source

Proxy vers tabular-api.data.gouv.fr sur le dataset "Annuaire ANS". Cache revalidate: 3600 côté serveur (1h). Tronque à 100 résultats max par requête.

Format de retour

{
  "ok": true,
  "count": 4,
  "mock"?: true,  // si fallback mock
  "results": [
    {
      "rpps": "10000000001",
      "adeli": "751234567",
      "civilite": "Dr",
      "nom": "DUPONT",
      "prenom": "Marie",
      "profession": "Médecin",
      "specialite": "Médecine générale",
      "mode_exercice": "Libéral",
      "adresse": "12 rue de la République",
      "cp": "75011",
      "commune": "Paris",
      "telephone": "01 23 45 67 89",
      "email": null
    }
  ]
}

Normalisation

La fonction normalizeEntry() mappe les colonnes du CSV de l'ANS (qui ont des noms verbeux comme identifiant_pp, nom_d_exercice, libelle_profession...) vers notre format propre.

⚙ 3. Configuration optionnelle

Mode démo (par défaut)

Si RPPS_DATASET_RID n'est pas configurée en variable d'environnement, l'API retourne un mock avec 4 praticiens fictifs :

  • Dr DUPONT Marie — Médecin (Paris 11)
  • Dr MARTIN Jean — Cardiologue (Paris 16)
  • Mme BERNARD Sophie — IDE (Paris 11)
  • M. PETIT Lucas — Kiné (Gramat 46)

Bandeau jaune "Mode démonstration" affiché sur la page tant que ce mode est actif. Les filtres mock sont fonctionnels (par nom / RPPS / profession / CP) pour permettre les tests.

Activer la vraie source

  1. Aller sur data.gouv.fr — Annuaire ANS
  2. Récupérer le resource ID (UUID) du fichier CSV des praticiens libéraux
  3. Dans Vercel → Project Settings → Environment Variables → ajouter RPPS_DATASET_RID = <uuid>
  4. Redéployer (ou attendre le prochain commit)

L'API utilise ensuite l'endpoint https://tabular-api.data.gouv.fr/api/resources/{RID}/data/ avec les filtres appropriés.
