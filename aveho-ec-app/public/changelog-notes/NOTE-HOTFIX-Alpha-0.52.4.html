Classes CSS responsive ajoutées dans app/globals.css

/* Tables scrollables horizontalement sur mobile */
.panel-table {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
  /* edge-to-edge scroll */
  margin: 0 -16px;
  padding: 0 16px;
}
.panel-table table {
  min-width: 600px;
}

/* Grilles 1fr 1fr → 1 colonne sur très petit écran */
@media (max-width: 640px) {
  .grid-2-mobile-1 {
    grid-template-columns: 1fr !important;
  }
}

/* Chips qui réduisent leur taille de police sur mobile */
.chip-row {
  display: flex;
  flex-wrap: wrap;
  gap: 6px;
  align-items: center;
}
@media (max-width: 480px) {
  .chip-row button {
    font-size: 11px !important;
    padding: 4px 9px !important;
  }
}

/* Bannière fixed en bas : réserver place pour ne pas masquer contenu */
@media (max-width: 768px) {
  .has-bottom-banner main,
  .has-bottom-banner .wrap {
    padding-bottom: 100px !important;
  }
}

/* Modal padding réduit + max-height sur très petit écran */
@media (max-width: 640px) {
  .modal-bg { padding: 12px; }
  .modal { max-height: 95vh; }
}

/* Inputs date pleine largeur sur mobile */
@media (max-width: 640px) {
  input[type="date"],
  input[type="datetime-local"],
  input[type="time"] {
    width: 100%;
  }
}

Wrapper automatique des tables

Script Python qui parcourt les 3 pages avec tables et enveloppe automatiquement chaque <table> dans un <div className="panel-table"> :

pattern = re.compile(r'<table\s+[^>]*>.*?</table>', re.DOTALL)
text = pattern.sub(lambda m: f'<div className="panel-table">{m.group(0)}</div>', text)

Appliqué à /annonces, /app-logs, /digest-dashboard.

Bannière mobile — toggle dynamique body class

Le composant AnnoncesBanner ajoute maintenant la classe has-bottom-banner au document.body uniquement quand :

  1. L'écran est en mode mobile (window.innerWidth < 768)
  2. Et qu'il y a au moins une annonce visible (non dismissée, non snoozée)

Le CSS global réserve alors 100px de padding-bottom sur la zone de contenu. Sur desktop ou si la bannière est masquée, la classe est retirée → pas d'espace inutile.
